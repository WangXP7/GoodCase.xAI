# 第三题：可复制的 Agent 对话

这是课前练习模板。考场只通过对话改现有项目，不把独立演示当原项目直接覆盖。

## 第一轮：阅读后实现

请先阅读题面与现有数据、渲染、事件代码，在现有结构上完成科目、交集筛选、可见移动和刷新保存。仅改允许的index.html/src/assets，保留入口、离线资源、许可证和所有题面定位控件，不改测试和启动脚本，不联网。

全清单是唯一数据源；每项独立持久id、title、completed、subject。同名不合并。新增trim后非空才加入，一律未完成、未分类、追加全清单末尾。

科目筛选和完成筛选取交集，筛选不改全清单。修改科目只改当前id；不再匹配就立即消失。未完成计数和清理已完成始终基于全清单。

移动先找当前可见邻居，再交换这两条在全清单的两个位置，其他位置不变。例：[A数学,B英语,C数学,D未分类]中C上移，得到[C,B,A,D]。交换完整对象，属性跟随身份。

每次变更重新计算可见列表与上下移disabled；空视图保留筛选。localStorage保存全部字段、顺序和稳定id，刷新后追加不会撞id。正常操作1秒内更新。

完成后按题面检查，简短说明实际改动、检查结果和剩余项。不要把整份文件重复输出。

## 第二轮：按真实缺陷选用

移动错误：只看数学时A、C可见，C上移后全清单应为C、B、A、D，隐藏B必须仍在下标1。请检查是否错误地做了删除插入，改成两位置交换；不要改科目或完成状态。

同名错误：两个“朗读”有不同id。只改第二条为数学，第一条必须保持未分类；只删除一条不能删全部。请检查事件定位是否使用标题或旧索引，改用当前行data-id。

筛选错误：数学+未完成只显示未完成数学。把可见项标完成应立即消失，但全清单仍保留，切到已完成可再看到。剩余数量从全清单统计。

保存错误：移动、改科目、勾选、删除、清理都须保存。刷新后完整数组顺序与属性不变，新条目id不与旧条目冲突。请补齐遗漏的保存路径并核查加载顺序。

## 最后一轮：提交前审查

请依据题面审查实际代码：定位控件；同名独立；新项未分类；交集筛选；按可见邻居交换全局位置；隐藏项位置不动；动态disabled；全清单计数与清理；每次变更保存；刷新追加不撞id。只报告具体未满足项与已做检查，不虚构正式测试分数。若有问题，先在允许文件内修复，结束时列剩余问题。

提交是锁定操作。平台公开结果在提交后展示，不能据此再改作品。这里不安排“提交看分后继续修复”的无效流程。
