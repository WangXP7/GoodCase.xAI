# 枪王 GunKing · 独立优化版

本案例在中文还原版的独立副本上持续优化。原案例 `codex/gunking/` 保持不变，新入口为 `codex/gunking-optimized/index.html`。

## 本次新增

- 设置 → 任务配置：初始子弹总数（含弹匣与备弹，0–999999 发）与无限弹药开关。无限模式不消耗子弹，无需换弹，HUD 显示 ∞。
- 无人机、机器狗、履带哨兵分别设置非负整数数量，不设固定数量上限；0 可关闭该类敌人。
- 数量代表部署目标和同时存活上限，大批敌人分批生成；任务增援只补充空缺。实际可运行数量取决于机器性能，50 名敌人的验证不代表任意数量都能流畅运行。
- 配置自动保存于本机浏览器，开始行动或重新开始任务后生效；暂停中修改不会立即重置当前任务。
- 全新履带哨兵：橙色宽装甲、双履带、路轮、独立炮塔与前部感应镜。240 点耐久，移动较慢、短点射，不使用机器狗的冲撞攻击；支持寻路、命中、摧毁和残骸回收。

## 本地运行与构建

双击 `启动.cmd`，或执行：

```powershell
node tools/build.mjs
node tools/build.mjs --check
node tools/serve.mjs --open
```

默认构建已改为从 `src/` 生成优化版 `index.html`，不会用旧还原版覆盖改动。编辑 `src/game.js`、`src/ui.css`、`src/page.html` 后重新构建。

`GunKing_中文还原版.html`、`reference/`、`localization/`、`source-audit.json` 为固定历史来源证据。`tools/verify-source.mjs` 仅验证该还原基线，不代表优化版仍与原程序相同。当前修改改变了玩法和敌人逻辑。

原始来源、原作者署名和许可范围见 [原案例说明](原案例说明.md)。Three.js 许可见 `vendor/THREE-LICENSE.txt`；不把第三方原作声称为本次原创。
