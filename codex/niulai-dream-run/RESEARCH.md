## 设计边界

- 仅学习抽象的美术语言、轮廓规律和叙事母题。
- 没有把检索到的海报、剧照、角色贴图、影片音频或模型放入游戏。
- 游戏角色、关卡、UI、音景和文案均从零创作；道路纹理和声音在浏览器中实时生成。
- 运行目录不请求上述资料站点，也不依赖任何外网资源。

## Context7 API 核对

通过 Context7 查询 `/mrdoob/three.js`，核对了以下官方实现要点：

- `WebGLRenderer` 的阴影开关和 `shadowMap` 配置
- `setAnimationLoop` 驱动渲染循环
- `PerspectiveCamera` 响应式宽高比与投影矩阵更新
- `FogExp2`、方向光、半球光和阴影相机范围
- 实例与低多边形场景的性能实现思路

Context7 返回的原始资料保存在 `.firecrawl/context7-three-search.json` 与 `.firecrawl/context7-three-api.json`。
