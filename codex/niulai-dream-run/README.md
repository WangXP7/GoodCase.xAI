# 牛来：梦野逐风

一款致敬国产独立动画电影《牛来》创作气质的原创 3D 网页跑酷冒险游戏。游戏以“草原初醒 → 荒漠问心 → 墨云天关”三重梦境展开，围绕担当、选择与勇气完成一段约 3 分钟的完整旅程。

> 本项目是非商业同人致敬作品。角色模型、场景、界面、音乐与全部运行素材均为本项目原创或程序化生成；未使用、复制或分发电影原始剧照、海报、模型、音频或贴图。

## 本地运行

### Windows 一键启动

双击根目录下的 `start-game.bat`。浏览器会自动打开：

```text
http://127.0.0.1:4173
```

保持命令窗口开启；按 `Ctrl+C` 可停止本地服务器。

### 命令行启动

只需要 Node.js 18 或更高版本，不需要联网，也不需要安装依赖：

```bash
npm start
```

随后打开 `http://127.0.0.1:4173`。

Three.js 的运行文件已经存放在 `vendor/`，字体、音效与纹理均使用本地或程序化方案；断网后游戏仍可完整运行。

## 操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 左右换道 | `A` / `D` 或方向键 | 左右按钮 / 横向滑动 |
| 跃起 | `空格` / `W` / `↑` | 上按钮 / 向上滑动 |
| 踏风冲刺 | `Shift` / `J` | “风”按钮 / 向下滑动 |
| 暂停 / 继续 | `Esc` | 右上角暂停按钮 |

- 收集云羽可增加印记，并缩短踏风冷却。
- 朽木与山石可以跳过。
- 暗影无法用普通跳跃跨越；换道躲避或用踏风击碎。
- 三点勇气耗尽时梦境结束；抵达 `820 丈` 即完成旅程。

## 功能

- 完整的三线 3D 跑酷系统：换道、跳跃、冲刺、碰撞与短暂无敌帧
- 三类障碍与程序化安全路线，包含可收集云羽和粒子反馈
- 三重梦境、章节过场、色彩与雾效渐变、通关及失败结算
- 原创拟人小牛与云雀程序化模型、低多边形国风场景、宣纸与水墨视觉语言
- Web Audio 实时合成五声音阶氛围、操作音效与静音控制，无音频文件依赖
- 键盘、触屏滑动和触控按钮；桌面与竖屏手机自适应镜头
- 页面失焦自动暂停、语义化按钮、键盘焦点与屏幕阅读器状态播报
- 测试模式、状态快照与 Playwright 自动化回归接口

## 验证

本地资源完整性检查：

```bash
npm run check
```

Playwright 回归测试覆盖核心渲染、控制、碰撞、章节、结算、音频、竖屏布局和零外网请求。先启动本地服务器，再运行：

```bash
pnpm install
npm run test:e2e
```

测试默认调用 Windows 的 Microsoft Edge；可通过 `NIULAI_BROWSER` 指定 Chromium 系浏览器可执行文件。

```text
├─ vendor/                    # 本地 Three.js 运行文件与 MIT 许可证

│  └─ check.mjs               # 离线完整性检查
├─ tests/                     # 五阶段 Playwright 回归测试
├─ assets/favicon.svg
├─ RESEARCH.md                # Firecrawl 调研与视觉转译记录
└─ start-game.bat             # Windows 一键启动
```
