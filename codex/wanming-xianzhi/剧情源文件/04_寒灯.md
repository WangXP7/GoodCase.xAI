# M07
入冬后的第一场霜落在衙门阶前。程守义没站在惯常的位置，他坐着补靴，见你过来才起身。针还连在鞋底，走一步，线便牵一下。
欠饷册里有十四名差役，实际当差的十一名。三处空名未必全是冒领：一个病了仍等看好，一个被借往别处却未转籍，一个已经离开，家里还拿他的半饷抵旧债。若一刀将空名划去，账最明白，接下来无人承担的病、调遣与债也最明白。
程守义说差役们开始在送票时私收脚钱。不是人人都收，有人不肯，便被同伴埋怨断了活路。他承认自己此前让他们按远近酌取，却未给上限，更没让收钱的人开凭。一句体恤下属，出了衙门就变成村户无法核实的价。
{a06 == 1:逃役案追出的茶资已让人议论县里将清差费，程守义必须回答自己当时知道多少。他没有再说全是门口中人的事。|逃役案得到个别调整，门外代办的风声却未全止。程守义承认，只给一个杜成找办法，不足以让其他人不再花钱求同样的办法。}
你让他说若今天付清，能不能从明天绝无私取。他摇头：“能下禁，能查。不能担保每只手。”至少这不是一个便于你落印的保证。
那根补靴的线仍拖在地上，程守义弯身把它收起来，像终于想起这不是一件能始终藏在桌下的公事。
## a
欠饷按实清偿，送票、拘传与差旅可收不可收的项目同时张示，投诉不得交回被投诉者自查。程守义领到自己的钱，先把旧准脚钱的批示附卷。你没有因付过饷就把往后一切过失简单称为贪心，也没有因他们辛苦便免去约束。靴底补好了，走向村里的每一步仍须有人愿意来问。
## b
半饷先发，公食补上，轮休名单由差役自行商议后核定。程守义提出最远的差务两人轮换，不再让同一个人一月不归。余饷期限写在众人能看的地方，他提醒你，到时还不上，今日所有体恤便都会像哄话。你把这句提醒留在案头。暂缓让衙门继续转，也向以后借了一次必须兑现的信用。
## c
你先清空名，病役与借调分别核实，不以不在眼前就认冒领。实际当差者领到一部分，余数等清点后发。程守义照办，脸上有些疲惫：清理确实必要，等待也确实落在还在走路的人身上。你让每次查到的新数当日公布，不许把核查变成没有期限的理由。整齐的名册要靠真实的速度换来。

# V06
魏廷章送来一册新修族谱，请求为族中义行申报旌表。谱里记借粮、修桥、济贫，纸白得与县衙旧卷不像同一种东西。你翻到义田沿革，发现目录有一页，正文却空缺。
那页涉及一位出嫁女留下的田。捐给族中时约定供养孤老，近年租入逐渐并作族学费用。管事说族学同样是善事，没让粮进谁的私袋。受供养的老人却不一定有子弟在学，善事换成另一件善事，并不意味着原受益者还能活得一样。
魏廷章没有否认。他解释族产紧，族学又不能断，原想待收成好再补。他说许多地方都这样挪用，账面上不算有人占为己有。你问那几位老人在哪里，他报出住处，没有漏掉一个；这让事情更难简单归于糊涂。
{v03 == 1:春借的本金与折息已在秋闸时偿清，魏氏族内也核过销账凭据。公家履了自己的约，才能在今日要求他们别将旧用途留作含混。|春日捐粮或采买已经各自结清，但魏氏为公共事务付出过多少，族人记得清楚。他提醒你这一点，不是要抵掉老人的份额，而是请你看见账下还有别的压力。}
你把族谱合上，说县衙不宜代修别人祖先的故事，却必须问公产用途。魏廷章沉默了一阵，终于去掉了口中的“大人”：“若把每个错都写进去，还有谁愿把谱送给你看？”
他翻开那处缺页，等你回答。
## a
族谱由族内讨论补记，义田用途另案核查，不把祖辈评价与眼前受益人的供养混作一题。魏廷章接受，要求自己到场说明租入流向。他不再能用一本谱代替公产账，也不必被迫当众否定一切祖业。被改过用途的粮须安排归还，至于那一页如何写，县衙留下事实，未替家族写好结论。
## b
旌表暂缓，你先核名册中实际受益的人，允许魏氏在补足安排后重呈。魏廷章拿回红封，不再争申报时间。几位老人第一次被逐户问到实际领过多少，有人替族中说好话，有人只报数字。你要求两样都照记。暂缓不是把请求无声搁死，下一步要做什么必须清楚，否则审慎也会成为另一种拖延。
## c
你退回旌表请求，要求先安置被挪去供养的佃户与孤老，再谈功名上的褒奖。魏廷章脸色发白，仍收下批语。他出门后，族里会有怎样的争执，你不能替他承受。你让书吏另发安置期限与复核方式，免得惩下体面之后便不再问那些真正缺粮的人，是否确实得到了应有的一份。

# A07
夜航失舟，报案人却不肯说是谁害的。她是船工的妻子，抱着丈夫留下的饭罐来，只求先找人。渡口已经替她找好凶手：有的说掌舵醉了，有的说县里催粮太急，有的说船东偷减木料。
{m07 == 2:差役余饷本月到期，本次批复另付公银五份结清；程守义把收条放下，才领人去查船。}
{m07 == 3:空名与借调已核清，本次批复另付公银七份补足余饷。经手者将名册送来，不许把查案繁忙又当作拖延发放的理由。}
桑九去过现场，带回的船板有一道旧裂，不能单凭它断定翻覆原因。当晚风急，船确实超了原定装量；岸上催送的人说自己只催时辰，没有叫他们多装；船东说船工愿多跑一趟挣脚钱。每一句都能把一部分责任推到不在这里答话的人身上。
程守义想把几名经手人一并拘来。桑九拦着说先别把熟水的人全带走，江汊还有两处没搜。你让搜救继续，堂上的问话分批进行。饭罐口磕掉了一角，妻子用布裹着，怕孩子以后还要用。
{v05 == 1:此前补齐的船工名单让这回能较快找到同班者，不必先等船东报出愿意承认的名字。|赏帖与修船料留下了一部分用船记录，但临时接班的仍须逐户寻访，搜救者带着名单边走边问。}
几日过去，找到一名幸存者，仍有人未归。幸存者说自己劝过少装，却又收下了多装的工钱。他既是受害的人，也不是完全没参与的人。要为这场事写一个单一凶手，或写成单纯风浪，都能让县衙快速结束；你需要的却是既不延误家属眼前生活，又不让不同过失互相抵消的处置。
## a
你把船况、催送、装量与操舟分别记证，家属急需先行救济，不以签结案书为条件。失踪者的搜寻与身份处理另留期限。妻子领到米时问收了是否便算认丈夫已死，沈砚明确写上不作此意。过失须慢慢查，活着的人不能以继续挨饿来证明自己还没放弃寻找。
## b
险渡暂封，熟手继续搜救，其余人共同重定载量、风候与夜航安排。船东抱怨生计受损，桑九说自己也靠船吃饭，更不想用下一个人去证明旧规有问题。你让新规限期复查，不把一次事故变成永久封死水路。家属的索赔仍另查，修了规矩不等于旧损便无需承担。
## c
经手人逐项说明，证据不足的不先归罪，差役不得用传讯家属逼人作证。程守义接受，并派熟水者回去继续寻人。堂上的结论来得慢，外头开始说县里偏袒船东，你把已查和未查分开公布。失踪者家属的生活与问讯进度，也有专人按期回报。

# A08
南坊墙上忽然多了一个大大的“药”字。写的人本想指明许照微暂借的诊处，传到巷尾便成了这条街全是病家，卖菜人不肯进去，收粪的人也不来了。
许照微没有先去擦字。她把这几日的问诊按水源排开，发现数家都用同一口井，但也有井边人家未病。病者多呕泻，有老弱脱水，来势很急。她不能据此断言唯一病因，却知道不洁的水与缺少照护会让处境更坏。
一个井主坚称水清得照得见人，愿自己喝给众人看。许照微说看得清不等于没有问题，让他先别以身体赌这一口气。旁人听成她说井有毒，争论又向另一头跑去。
药铺后院只有两间空屋，能安置几人，不能安置一坊。把病家集中，照护较方便，也可能让不同病况挤在一起；逐户巡诊，需要足够的人与柴水；只封可疑井、不封整坊，生活影响较小，却要求居民理解观察并非已经找到所有缘由。
何素娘送来几只干净木桶，说不收钱，归还时洗净就行。程守义问是否要先登记她的善举，她催他先把桶拿走，桶放在门外不会自己进巷。
你看到墙上那个字下面，孩子又添了两点，像画出一双眼睛。整个坊开始被一个字盯住。你要安排的既是水、柴、屋子，也是让人愿意报病而不必因此失掉所有来往的办法。
## a
空屋分隔安置，先照看最弱者；可疑井暂停使用，另运洁水，清理与观察同步进行。许照微逐日记录症状变化，不把所有好转都算作某一味药的功劳。井主起初守着井骂，后来自己去抬了两桶替代水。安置花了钱，也避免让“离开原井”变成一句只有有钱买水的人才能执行的话。
## b
巡诊按巷分班，煮水柴与照护单一并发，许照微特意教家属识别何时必须再叫人。有人说家里锅已典掉，登记人这回没有只勾一项“已告知”，而是补送器具。病家仍在原处生活，需求更分散，回访不能省。你让巡诊者最后查的，是屋里有没有真正能把说明做出来的人。
## c
可疑井封起，邻井增设取水时段，坊内不一概断绝往来。自报点不当众宣读病名，先问所需照护。街上仍有猜疑，许照微每天把能确认的变化说明，连同尚不能确认的一起说。保留生活的通路，也要求更仔细地观察。你准役人维持取水秩序，不准借查病翻检与病无关的家物。
