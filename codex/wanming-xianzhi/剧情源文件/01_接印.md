# M01
驿船靠岸时，下过一夜的雨还挂在乌篷檐口。临溪县的迎接只有两个人：抱着印匣的典史程守义，以及提一盏白昼也没吹熄的灯的书吏沈砚。后者解释，库房窗小，验印要用。你接过灯，才看见他袖口蹭了一道新墨。
县衙前的照壁缺了一角，补墙的砖搁在路边，已经长出细草。程守义让跟来的脚夫绕过去，没有喝斥。一个脚夫问工钱在哪领，他指了指账房，又把手收回来：“今日先记下名字。”这句话，你在来路上已听过三次。
印是完整的，匣上的铜扣却缺了半片。沈砚将交接册展开，指甲停在“仓储足额”四字旁边。你问实仓何在，他说就在后院；你问既然就在后院，何必写“候验”，他停了一瞬：“前任也是这样接的。”
仓门并不难开。门后有一排粮囤，最前两个装得满，后面几个底下垫着空竹筐。鼠迹清楚，粮味却不浓。程守义蹲下捡起一粒发白的米，说去年冬天曾在这里给逃荒的人煮粥。交接册没记粥棚，只记损耗，损耗又被记在下一任的待核项里。
沈砚问你是否先用饭。厨下已把鱼蒸了，再等要冷。你还没正式接印，照规矩，这册纸不归你负责；而一旦落印，县里明早用什么开仓、差役今晚去哪领饷，就都开始与你有关。门外那个脚夫仍在等，一只脚已经踩进修墙用的灰槽。
## a
你让厨下把鱼留着，另请守仓人和两名里老到场，实称、记数、画押。沈砚写到缺额时抬了一次眼，你没有替他报一个好看的数。程守义把粮囤底下的竹筐挪出来，逐个标号。当天的迎任文书迟了半日，府里的催问很快会来；但你签下的第一页，终于写的是眼前这座仓。
## b
正册照常交接，你在旁边另立实点清单，嘱沈砚每日以原始凭单相校。程守义提醒，两册若有出入，日后总得解释为什么不当场说。你将这句话也写在清单末尾。午后衙门得以如期开门，等候的人没有散去。暗查给了你时间，也给了所有知情者一个共同保守的秘密。
## c
印落下去时，纸没有发出什么异样的声音。沈砚熟练地压上镇纸，程守义去安排明日开门。你准备用接任后的积余慢慢补仓，至少今天不要让新衙门第一日便停摆。临出库房，你看见那个空筐被塞回粮囤底下，动作很轻。你知道是谁放的，也知道此刻若叫住他，刚签的那页就要重写。

# V01
沈砚给县里的公文写两种字。呈上的端整，催人的急促。今晚拿来的小簿上，却是第三种：横画挤得极紧，每一个数字旁都有一个小得像蚁足的名字。
“大册记哪天出了多少粮，小册记粮到谁手里。”他说。有的名字旁画着碗，有的画着一扇门。你问何不写清，他答，守仓的老陈识不得许多字，画碗是熟食，画门是送到不能出门的人家。最末一页沾着油，摸上去比其他纸厚。
你找到一笔日期，墨比周围更新。沈砚没有等你询问：“那天已经封仓。前任叫先发，再找一日补进账里。”实际领粮的人能对上，日期却提前了七天。若照公文追问，便像有人在灾情尚未报到时，擅自动用了留存的仓粮；若承认是后来补的，签字的每个人都要解释。
簿中夹着一根麻线，是当时扎粮袋的。线头黏着泥。沈砚说收着不是为了作证，只因那晚回家，女儿误当成他替她买的头绳，拿起来嫌脏，又搁回桌上。他如今讲这件小事，像在努力说明，一页经手的账怎样跟着一个人走出衙门。
{m01 == 1:你让实点缺额入册的消息已经传到刑房。他说原以为你会先追问谁动了粮，没有想到你先问粮去了哪里。|他看了一眼你接任时签下的册子，说新旧两任的印很容易挨在一起，挨久了，纸上就难分先后。}
把这本小簿收进正式卷宗，会留下查清旧事的可能，也会把这个主动送簿的人放在最显眼的位置。沈砚把手从纸边移开，等你决定，他今天要写哪一种字。
## a
你让他另纸写明补记的缘由，连同原簿一起封存，封口由他自己签名。你不能保证一份说明足以免责，便没有许这样的诺。沈砚写得慢，写到“奉口谕”时停笔，将四字划去，改成自己亲耳听见的原话。最后他取走那根麻线，留下可以核查的名字与日期。
## b
你挑出能当场查证的几笔抄在工作簿上，原册仍归刑房。沈砚说这样暂不惊动旧人，办事会方便些。你要求每月核对一次，他在封面写了提醒。那页被油浸透的纸没有抄全；你保存了继续查的入口，也把原件能否继续存在，交给了一个仍须在旧同僚之间做事的人。
## c
你将簿册推还，请他先整理本任要办的案件。沈砚点头，没再解释那根线。他出门后，桌上留着一点纸灰，不知来自灯芯还是旧封套。你没有因此少掉一座空仓，只是决定往后的公文不再从这一本开始。这样的界线很利落，利落到连主动开口的人也知道该在哪儿停下。

# A01
何素娘来告状，带来的第一件东西不是契纸，而是一扇小木门。她和帮忙的邻妇抬着门，在县衙台阶下站了很久。程守义问为何不拿契来，她说：“契说屋，门说我在里头住过。”
铺面是亡夫生前盘下的，前房主收了银，白契上按了半枚手印，没办完验契便病故。如今其侄儿拿着册籍索回房屋，说那份纸连印都没有，不足为凭。他提出退还原银，却要先扣十多年的租。如此一扣，何素娘不仅要搬走，还得补钱。
木门内侧有几道刀刻的横痕。最低一道旁写“阿荞”，是她女儿五岁量的身高。侄儿承认母女住过，却说借住同样能刻门。围观的人想笑，何素娘先把门转回去，免得女儿的小名一直朝着堂上。
你请她说付款时在场的人。一个已死，一个去了外县，还剩当年替两家写纸的卖药翁，眼睛已坏。他记得那天买主付的是散银，称了三遍，因为末一块夹了铅；卖主还当场骂过兑换铺。侄儿听到兑换铺的名字，突然说多年旧事，老人怎会记得如此清楚。
册籍确实仍写前房主。纸也确实不是凭空捏造。若轻易许任何一张白纸推翻在册权利，往后同样有人能造纸占屋；若只认留下印记的那一本，没能力补手续的人已经住过的十多年，便可以在一句“无据”中消失。何素娘握着木门的边缘，说她不求你认那些刻痕，只求听完称银的三遍。
## a
你传四邻与兑换铺后人，核对旧银账、修屋出资和历年使用。侄儿改口愿重议，你却让询证做完，免得今天的让步成了明天的翻供。几日后，各项相互印证，白契副本入卷。何素娘领回门时问女儿的小名要不要擦掉；你说那不是官文上的错误，不用为了进过县衙便擦掉。
## b
你先禁双方擅自拆门夺铺，限期以现有证据另议租用与价款。何素娘暂时保住生计，侄儿也没有立即丧失全部主张。她说至少明日还能磨豆，又问限期以后呢。你把下一次到堂的日期写给她。暂缓不是一份永久的契，却总要有可再走回来的一天，才不至于只是换一种赶人。
## c
你依现册确认房主的权利，同时不准追索此前并未约明的租欠。何素娘可以带走器具，限期腾屋。侄儿向堂上作揖，她没有哭，也没有把门留下。程守义帮忙抬下台阶时，她请他轻一点，门还要装在别处。纸上的房产归了原主，纸外的人则得从另一个清晨重新开灶。

# V02
陆青禾进衙门，先把鞋底的河泥刮净。她没带贺礼，将一把绳尺放在桌上，说这东西借给县里用过一年，如今想讨回来。绳结已经磨得发亮，末端缺了一小截。
东堤上季工钱拖了七个月。名册上是二十六人，她另列了五个：两人半途伤病，三人接替家中老人，算工时被并在父辈名下。你问为何此前不来，她说前任准过三次，每次准得很有道理，冬粮急，解银急，新年又要清账。她怕再来一次，大家会觉得是她把钱私吞了。
图上东堤像一道细线。陆青禾用尺压住一个转弯：“这里下头是沙，去年只换了表皮。修堤的若连饭钱也没拿到，今年你叫他往水里探脚，他会先想着岸上有没有人替他讨账。”她没说工人一定不来，正因为有些人仍会来，事情才更难办。
她父亲曾在旧堤下落水。名册写病故，家里一直收着那张纸，免得母亲再领不到最后一笔工钱。她提起父亲时，声音并没变，只把绳尺缺的那端往掌心收了收。
陆青禾只请你说定第一笔何时、由谁、在何处交到工人手上。
## a
你拨出旧工钱，逐人领取，不让工头代领全部。陆青禾把五个漏名者叫来，先解释各自该算多少。验工表由她写，修过与未修分成两栏。领到钱的人没有齐声道谢，有人先去买米，有人算着欠药铺的债。绳尺留下了，作为公家借用的物件，另开收条，不再算她的无偿报效。
## b
你把分期写成两张可带走的凭条，第一笔先付，余款约在下一季清点后。陆青禾要求验工也分段，不许完了一段又拿全堤未完作借口。你同意。四十丈险处先动工，其他地方仍须等。她走前量了一次衙门台阶，说若第二笔拖了，至少知道这些工人该站在哪一层向你开口。
## c
你命按役额集人，旧工钱留待查明经手后支付。陆青禾收起绳尺，说她会把险段指出，但不能替新来的人担保。几日后，人手在册上齐了，有两个才第一次下水。程守义请求多派熟工带领，额外工钱又回到了桌上。你已经发出的命令能让人来到河边，不能让他们立刻听懂水的声音。

# A02
渡口的争执起于一块木牌。牌上新写了缴税期限，桑九说期限能认，下面的户名不认。他指着“桑福生”三字问，死人还能撑船吗？管渡税的役人答，册子一直如此，若要改，先证明桑福生已死。
桑福生是桑九的父亲，死在三年前的冬夜，尸身没寻着。家中有丧，有邻人，唯独没有一具可验的遗体。其兄又去外埠谋生，现有两条船都由桑九和几户伙伴合撑。公册却把税、渡役、修桥摊派一并记在父名下，任何一项没清，其他人的工役抵扣也不能算。
他将十多根刻痕不同的竹签倒在堂前，说这些人轮班做过多少次官渡，签上有数。役人说竹签也能自刻。桑九便找来当时坐船的老妇，老妇不识日期，只记得去看儿子时，桑九的手还被缆绳勒出血。她说得很慢，慢得旁人开始不耐烦。
你让人把税册和役册分开，才发现同一趟渡送，有时算役，有时既收税又不抵役。旧年欠额滚进新年，船户越做越欠。里甲担保能让核验快些，但不在其名下的人会继续依附一个肯替他作保的名字。
桑九笑说，水上不查你是不是好户，落水都要喝一口。他见程守义没笑，便正经起来：“大人，我不求少记我的欠，求把欠与做过的事摆开。我能看懂几道刻，不大会看懂一页总数。”木牌靠在门边，尚未干的墨蹭黑了他的肩。
## a
你将税与役分册，准实际撑船者到场报名，由同船人与渡送记录交叉核实。竹签不能单独作凭，却也不再因不是公纸便一概作废。桑九学着写下自己的名字，最后一笔歪了。役人要替他重写，他把纸按住：“这个认得。”核查费了一些工夫，留下的名册开始能找到正在河上的人。
## b
你暂以里甲担保确认船户，减免一季渡税，同时要求担保人不得另取费用。老妇替桑九求的那次官渡被补记。桑九领回竹签，问若里长不肯保的人怎么办。你让其单独具名待核。他说好，笑了一下；那笑里有松气，也有对下一道门槛的盘算，事情尚未完全离开人情的岸。
## c
你保留现税额，准分期清缴，官渡另由役人按次补记。催缴得以继续，船户眼前少了一次卖船的风险。桑九把木牌扛回渡口，在父亲名字下面用炭写了自己的小名。雨一下便能冲掉。他说等下一季来缴时再重写，仿佛只要能一直写，册上的人终有一天会长成今日的样子。

# R01
桑九第二次来，袖中藏着一张船底拆出的纸。纸边被桐油浸黄，中间留了粮袋压过的方痕。它不是县衙发的正单，是船户怕交粮时少算，自己抄存的副单。
{a02 == 1:新名册把他的名字写进去以后，几个老船工才承认各家也藏过这样的纸。能以自己名义作证，使他们敢把东西从船缝里取出来。|此前的渡税处置让他暂时能继续撑船，却没让他完全信服。他说此次来是为纸上的粮数，税上的不服，日后还要再说。}
副单记载的运粮数量，少于仓册上的发运量。沈砚拿来原册，指着其中一趟说，途中曾改道接人，前任批了另补舟费。粮可能在起运时便少，也可能在改道后分给了乘船的人。两份账之间缺的，不只是一个数字，还有谁有权下那道命令。
你问桑九为何不早拿。他从怀里又取出一张更窄的纸，上面记着两包私盐。他替外乡商人夹带过，为的是付母亲治病的钱。盐未必与失粮有关，但副单一旦正式入卷，经手的人也会被问到船上还有什么。
沈砚把两张纸分开放。桑九看着这个动作，说希望也能把两件事分开，却不要因此把自己说成全然无辜。他的指头来回摩挲油纸，像在寻找一道已经摸熟的缝。
窗外有来报渡役的人喊他。你若保留副单，旧仓缺额多了一处可追的线索，也多了一位有过失的证人；若只结清数字，事情很快能回到平静。桑九没有替你说哪个更好，他只是问，交出纸以后，能不能领一张收据，免得往后连交过都说不清。
## a
你分别记录运粮见闻与夹带自认，不许用其中一项预先否定另一项。副单封存，收据交给桑九；私盐之事仍按事实另行处置，没有以作证换免罪。沈砚注明哪些是目睹，哪些是转述。桑九把收据折得比旧纸还小，贴身收好。县衙从此有了一份不完全光彩、却能与别的证据相互校验的实话。
## b
你先校粮数，将能核明的一段附入账务说明，夹带另交查办。桑九配合画押，只在离开前问那张原副单将收在哪里。沈砚说照程序归并。公事被分进合适的抽屉，办理也快了；但将来要重连这趟船的全部行程，便须有人知道抽屉之间曾经相通，而不只是各取一个结数。
## c
你准以船户旧欠与争议差额相抵，船户不再追工，县衙不再追该项粮差。役人称这样两清最便当。桑九问，是不是纸也不用留了。得到答复后，他将油纸带走，没有当堂撕毁。账面确实平了，却是靠把两种性质不同的欠放在同一边。往后若再有人追问，今日每个人都得记住同一种解释。

# M02
开粥棚的消息比公文走得快。天还没亮，仓门外已经排了两列人。一列拿着户帖，一列什么也没有。负责登记的役人把没帖的指向墙根，说等在册的发完再问。
许照微从人群里扶出一位老妇。老妇没晕，只是一直把外孙举在肩头，怕孩子被挤走。她说原乡的户帖丢在过河时，若必须回去补，便领不到这里的饭；若留在这里等饭，又无法证明自己为什么不能回去。程守义让她先坐，身后的人立刻问，坐下是不是便能先领。
沈砚拿来仓底数目。留作籽种的粮不能随意煮尽，今日多发的一瓢，可能让开春少一块能播的田。可面前有人既没有田，也没有锅，给生粮还要换柴，领到十份，真正进嘴的不到十份。
{m01 == 1:你接任时写明的实数让今日的用粮格外醒目，府里已知道仓并不满，之后每次开支都得说明。|交接册仍把足额写在纸上，真正掌勺的人却只能舀眼前的米。沈砚请你决定，要不要让今日的登记成为第一笔改正。}
许照微建议把不能自炊的、能自行做饭的、仍有田待种的分开，至少别让一种救济把三种困境混成一列。程守义说分得越细，登记越慢，门外已有人起争执。你听见锅盖被揭开，粥尚未熟，热气先越过仓墙。
掌勺的人捏着木柄，正看你。
## a
你先按在场实际人口发熟食，再逐项补录，另设一栏接受冒领与漏领的具名异议，不准役人私自划掉。第一天发得较多，记录也乱些，沈砚忙到灯尽。老妇终于把外孙放下来，两人轮着喝一碗。你在支出末尾签名：先吃到了饭的人，之后仍须说明来历；没有先备齐纸的人，今天也有一顿饭。
## b
你先依户帖发放，在墙侧设补录桌，明确三日内给无帖者答复，并每日留出一份应急熟食。程守义维持了队伍，许照微在补录桌旁看护最弱的人。许多人仍要等，但知道该带哪位证人、哪天再来。秩序省下了争抢的消耗，也要求县衙认真履行那个三日；否则，等候只会变成另一种拒绝。
## c
你把籽种封存，熟食优先给不能自炊者，有田可种的另给耕作登记。有人抱怨凭什么自己有一口锅反而领得少，你请登记人将这项理由写明。仓粮耗得慢了，能熬到下一季的把握多些。门外并未因此人人满意。你保存的是后来可能长出的粮，也得承担眼前有人只能缩减一顿饭的事实。
