# V08
程守义来请辞，递的却先是下季差役值表。替谁轮休、谁熟东乡路、谁不宜独自押送易激动的当事人，全写得比辞呈细。
他母亲的眼睛渐坏，家里要有人陪她走熟从床到门的路。他说自己做典史多年，替全县安排过许多人的去处，回家却总叫母亲再等一季。如今她已经开始把他回家的日子记错，错得他不敢再纠正。
{m07 == 1:欠饷与差费规矩整过以后，他不必为离任时还有人拿不到钱羞愧，却仍须把旧准脚钱的做法向新人说明。|此前饷额与人员清点虽有安排，他离开前仍要确认哪些承诺尚未履行，不能让下任只拿到一张看似齐备的表。}

程守义看见你在读值表，指着一名新役说，此人写字不好，认路很准，不必让他因为怕写错就只听老役人的。他在为一个自己未必在场的冬天作安排。你这才发现，请辞并不总是把一份担子推回来，有时也是请求把肩上的位置交给另一个能接住的人。
## a
你准卸去领差，改在约定日子训练新人，实际拘传由继任经手。程守义先问教习是否也须留记录，你答要，尤其要写清旧办法为什么不能照用。他回家能多陪母亲几夜，经验也没有被简单丢掉。值表末尾补了交接日，不再写由他随时补缺；一份有限的职责终于有了有限的边界。
## b
你请他再留一季，将余饷、差费与惩戒全部交清，明确届时不再用另一次临时困难续留。程守义答应，要求允许固定归家日。你批了，值表也随之重排。衙门得到平稳的过渡，同时欠下对一个家庭的最后期限。这一次，不能再因公事总有下一件，就让承诺永远没有到的一天。
## c
辞呈照准，程守义交牌回家，旧经手与处分留档，新差役依法接任，不由他在家遥管。临走他将熟路标记教给新人，没把全部关系都作为私人门路带走。你安排后续问卷用正式通知，不让旧同僚随意把他叫回顶班。县衙失去一位熟手，也承认人不能因熟练就被公事永久占有。

# A10
清理旧物时，刑房柜底落出一捆家书。有封写给母亲，有封只写一个村名，最薄的一封里夹着半张没画完的木工尺寸。写信的人都曾在县狱，有些早已解送，有些仍因案情未决羁押。
沈砚对照收发簿，发现不能只说是一个役人忘送。有人没交出邮脚，有人地址不清，有人被认为写得不像家书而搁下；每次搁置都各有一句理由，理由叠久了，便没人再问信应该去哪。
{v08 == 3:程守义已辞役回家。他先前交接的送信办法仍可查，新任差役照卷承办，没有为了省事又将人叫回衙门。|程守义尚在交接或教习职责内，指出最容易失落的是中途转押的那一封：原处以为已解走，接收处以为信会随人来。}
牢中有一人见到自己的信，先问母亲是否回过，听见从未送出，许久才说那她可能以为自己不想写。他仍有应受审的事，信没送到却不因此成为额外应受的惩罚。
你不能自行将所有久悬之案一放了之，也不能用案件未结解释一切等待。复核羁押期限、催结、依程序报请会审、让符合条件的家属探视，各有适用范围，都需要实际的人手与费用。
那张木工尺寸是给儿子的，父亲想教他修一只凳脚。沈砚说尺寸少了一边，即使送到也做不成。你请他不要因此再搁，把可以补问的问清。一个人坐在哪里等候，有时不是大案里的问题，却是那个人一整日的生活。
## a
羁押期限逐案复核，需上报的依权限上报，不能即时变更的说明原因；合规探视同时安排，迟送书信单列追查。公支付出必要传递费用，不让家属再为旧疏漏交一次钱。木工尺寸终于补齐，信仍不保证一定赶得上收信人的等待。至少从今日起，等待开始有一份可问的时间表。
## b
能确认地址的先补送，地址不清的请原乡协寻，案件逐项催结而不把送信与判决捆在一起。新役人第一次按完整收发链签名，知道自己的任务要到交接给下一人才能算完。沈砚在柜旁贴了复核日期。许多伤害并不来自一道恶意命令，而来自“稍后再办”被所有人同时忘记；如今这个稍后终于有人认领。
## c
久悬之案按程序请求会审，材料与疑点整理齐全，必要费用列公支。你明言会审是继续核查，不预许每人改判。家书先依法传送，不等会审结果。那封给母亲的信添了一张迟送说明，写的不是寄信人忘了，而是衙门曾经搁下。公家失误没有再借一个不能自由出门的人承担解释。

# R07

## b

## c

# R08
桑九送来最后一份修订船册，最末一条船没有船主姓名，只写“待认”。那是夜航失舟后封存的残船余款，至今有人失踪，家属之间也未完全理清份额。
管渡税的新役人建议结清本任时暂归一户，往后若有异议再改。桑九不同意。暂写进去的名字日后最容易被认作原来就是如此，到时要求纠正的人反而得先证明那张新纸错了。
册中还并列着几个旧名、小名和后来学会写的大名。何素娘帮忙核字，发现一个船工每次都把同一笔写倒，却彼此认得这就是他的写法。她说可以在旁另注正字，不必把本人的全抹掉。桑九听完，找出当初在木牌上用炭写过的小名，认真加在自己名下。
{a02 == 1:新的实际渡籍经过两年核验，不再只依父辈与里甲姓名。仍有漏名，但来要求补记的人已经知道该带什么证据、去找哪张桌。|旧渡籍的框架还在，后来逐次补报让许多真实船工终于有了可查的旁注。它未变成完全的新册，桑九仍坚持每一条旁注都应随正册一起移交。}
名册不只是认出谁还欠县里钱，也该让人证明县里还欠他什么。无主款封存能留出等待，副单发给船户能避免只有县衙保存唯一说法，互证能让变化中的姓名仍接得上本人。
你问桑九最后这条要等多久。他说不知道，也许迟到的家属会来，也许一直不来。“不知道就先写不知道。”他说。两年前那个怕报名字的人，如今在要求一页公册学会保留空白。
## a
旧名、小名与现名在互证后并列，不因不合书手习惯便一概重写。待认款保留原状，继续受理后来的证据。何素娘替每一处改字标注缘由，桑九逐条读给不识字的人听。册面没那么整齐了，找到自己的人却多些。县里承认了名字会变、记录会错，而同一个人不必因此一次次从头证明自己存在。
## b
你发给每户一张新旧名并列的副单，注明已缴、已役与待结事项。船户带走一份可与公册对读的记录，县衙不再独占解释。桑九将副单包进油纸，教年轻船工别塞在易进水的板缝。纸可能仍会坏，至少坏的不会永远只有他们自己手上那一种证据。
## c
无主余款封存，来源与未决争议公开，准遗属以后凭证来领，不为结清本任而替它仓促找一个主人。罗问渠提醒这会在交接表留下未结项，你照列。桑九按印时没再说笑。空白有时出于漠视，有时出于对尚未来得及开口者的等候，这一条须把缘由写得足够清楚，免得后来人把两者混同。

# M12
去留文书到了，印匣仍是你接任时那一只。铜扣已经补好，照壁也修去缺口，但衙门里还有未完的案，堤上还有来年要换的木，几户人家依旧在等外县回文。你忽然发现任期可以有最后一天，县里的事没有。

{has_pact == 1:相济约副本在案边，保管人本月已经轮换。你若不再是知县，也只能按约参与，不能因为当初批过便永远坐在首位。|县务互助尚未形成那份自愿相济约。你可以支持现有安排继续，却不能忽然将仍依官衙的事务称为自己辞官后可直接接管的私事。}

## a
你申请留任，附上下一季的安排与仍需资源，不以百姓挽留作唯一凭据。罗问渠请你亲自确认待核事项仍随卷，你说应当。沈砚换了一页新纸，第一行不是庆贺，写着开春要查的井。你接着往下批，这一次没有再把任期的继续误认为事情已经得到圆满的证明。
## b

## c
你呈辞缴印，不删自己的批语，也不替继任承诺他尚未答应的事。沈砚按未结事项排交接顺序，你与他核到最后一项。离任可以结束你坐在这张桌前的资格，不能撤销你在这里做过的决定。空纸留给后来者，你只在交接处写明，哪些尚须继续听门外的人说。
## d
三份原始凭据连同来源与争议封妥，副本留县，你申请循程序上呈复核。罗问渠提醒可能久候，也可能先受问责，你没有要求他预许胜诉。沈砚的说明与自己的批语都随行。你带走的不是一份能证明所有人清白的答案，而是使某些事仍有机会被准确问起的材料。
## e
你呈辞，另向相济约提出按普通成员身份参与，不沿用官署命令。何素娘拿来入约条款，要求你也读完退约与查账一节。你笑着照读，读到自己当初批过的句子，却第一次从须遵守它的人这一边理解。印留在匣里，明天若要开仓，你得先去找掌另一把钥匙的人。
## f
你接受修订后的考语，争议账目依新总纲结案。纸上的临溪秩序清明，旧欠渐消，连几次迟误也变成随机应变。沈砚替你磨好最后一次墨，没有说这全是假话。正因里面有那么多真的事，你更清楚哪些未被写出的细节，将从此失去与它们并排被看见的位置。
