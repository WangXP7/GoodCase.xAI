# M03
开春后第一次上堤，岸边的柳枝还没有展开。陆青禾将一只竹篮沉进水里，提上来，里面不是淤泥，是细细的白沙。堤面看着结实，脚下却在慢慢漏。
她用木桩标出旧河道，桩越过魏家一片新垦的桑地。魏廷章随即拿出祖上传下的图，图上田界恰在河边。他没有说不准修，只问县衙究竟以哪一年的河为界。两张图都能找到保人，水却已换过几次路线。
{v02 == 2:分期旧工钱的余款已经到期，本次批复将另付公银七份结清。陆青禾将领款名单交来，说明新工与旧欠须分列，不会因为今日又要开工就再续一个“以后”。}
{v02 == 1:领到旧钱的工人已分组探过险段，图上每个记号都有实测。陆青禾说可以动工，只须县里说清谁来承担占地损失。|陆青禾身后的人不多。有的在等余款，有的被役额临时召来。她把可确定的地方画实线，其余留空，说没探过便不敢替他们画满。}
站在桑地旁的佃户始终不插话。你问桑树砍了对谁影响最大，他看了魏廷章一眼，说地归魏家，树归自己养，蚕要在他屋里吃叶；赔一份田价，不一定能同时赔回这三件事。
魏廷章蹲下捏了捏沙，不再只谈图。他愿让出部分田，却要求补偿从公项出，不能让别人以为魏氏的地任人画一根线就能拿走。陆青禾说钱从哪里出可以议，水下一场雨何时来不能议。
你沿堤走了一段，鞋尖陷进一个看不见的软处。程守义伸手扶住你，才发现自己也正站在同样的土上。修一条堤需要石、木、工钱，还需要有人相信修堤不会只意味着自己的损失被一句公事省略。你回头看那两张图，纸被风吹得贴在一起，河道却没有重合。
## a
你以实测确定险线，同时分别登记土地、树木与佃作损失，允许各方查阅。魏廷章签字时写了保留意见，没有被迫装作欣然献地。陆青禾带人按新线下桩，留下一份两岸水尺图。公银少了一笔，县里多了一段可能挡住水的堤，也多了一份明确说明钱付给谁、为什么付的账。
## b
围堰先沿险处立起，争议地留到双方会勘。工人有了能立即做的段落，魏家也得到整理旧契的时间。陆青禾提醒，临时工程过一季就得再花钱，不能把“暂且”两个字刻进石里。你在卷宗上注明复勘日期。争议缓下来，水下的沙仍在流，下一次议事须赶在围堰变成唯一防线之前。
## c
你依旧图加高，不动新垦地。魏廷章当场答应供几车木料，公文也好写。陆青禾把白沙倒在新线旁，说明水可能从下头穿过去，然后按令施工。你没有听见反对声，只有打桩一下一下传来。堤面会比去年高，是否更稳，还要等看不见的那一部分在雨里怎样回答。

# V03
魏宅的茶用了去年存下的梅花。魏廷章说今年花开得早，却没顾上收。案上摆着借粮约，没有摆捐粮的红帖。他先说清楚，是借，要还，省得县里误以为一顿茶便换来一仓粮。
粮来自几处义田，其中有给族学的，也有给孤老的。若全数拿去赈济，族内会问自己的旧约谁来履行。魏廷章愿代为周转，条件是秋后偿还，并请魏家的管事参与运输。他说熟路、熟仓，可以少损耗。你也知道一旦长期参与，许多本应公开的交割就会先经过魏家的门。
屋外有个年轻管事正在擦一块尚未题字的匾。魏廷章见你看过去，咳了一声，说原准备修祠使用。匾是真为修祠，还是为今日可能得到的名目，你无法仅凭一眼判断。
{m03 == 1:东堤占地让族中已有人指责他过于退让。他说自己肯认公用，仍希望县衙肯认这回借粮不是应当。|春堤处置暂时给魏家保住了回旋余地。他愿再向前走一步，却希望你的下一步也能让族人看见彼此有约。}
你问能否题捐粮姓名，却不许借题名包揽工程。他放下杯盖，说可以，无息捐的数目自然少些。
临走前，一名佃户送来新磨的米，魏廷章让管事记入收粮册。那人站着看记完才走。你忽然明白这里每一份体面底下，也有人在等一个足够准确的数字。
## a
借约写明偿期、利息上限、验收和不得独占运送的条款。魏廷章读了两遍，划去一处容易被理解成担保全部亏损的字。他要保障，你也要边界。粮很快入仓，秋天的压力同时落在纸上。你没有把别人的借粮写成自己的功德，县里也不能在偿还时突然声称当初不过是一场善举。
## b
你收下较少的无息粮，准在仓旁题名，明言工程仍须另验，不因捐粮免审。魏廷章让人把匾收回，改写一张简短红纸。红纸能让族中看见他的付出，却换不到独占河工的凭据。仓粮比所盼少些，约束也少些。茶凉以前，两人总算把感谢与权利分别放妥。
## c
你谢过借粮，另派人赴外乡采买，费用列入公项。魏廷章说县里既有余力，他便不再多言。临溪少了一笔欠魏家的债，多花了运费；以后的议事也少了一层情面可借。管事仍替你开门，礼数并未减少。你走过那块空匾，想到不欠人的办法有时很贵，贵的部分也得有人承担。

# A03
许照微带着药渣来县衙时，外面已传了三个说法：她用错药，药铺换了药，病家为了索赔故意多服。真正躺在床上的孩子，在三个说法里都只剩下“那病儿”。
她把药渣铺在素纸上，拣出一截颜色略深的根。药铺掌柜说进货一直由同一个客商，孩子的父亲则坚持按医嘱煎过。许照微先问水烧开后又煮了多久，父亲答不上来，是孩子的姐姐看火。姐姐在旁边站着，手臂上有被蒸汽烫出的水泡。
你让人请姐姐坐下，她才说当天怕误了洗衣的差事，火灭过一次，后来又添。旁人立刻把责任推给她。许照微拦住：“她是照护的人，不是方便抓来的答案。药材、用法、病情都没核完。”她承认自己的交代可能不够清楚，没问这家里究竟是谁能守着火。
掌柜愿赔些银子，求不要封铺。他有一屋药，其中不少病家赊着，封一天，有人便断一天。可疑药材若继续卖，又可能多出另一个孩子。程守义请你先决定查哪一条，以免听着听着，围观的人把药铺砸了。
孩子已经醒转，仍需照护。许照微说自己可以留诊，却不要县衙因她肯留，就认定那截根必然无错。
## a
涉案批次暂停出售，其余药另验后照常供应。你派人逐户追访，把已知与待查分别张示，不许先将过失写死在一人名下。几日后发现同批药确有混杂，煎法也有偏差，责任分项处理。许照微重新写了交代单，特意多留一行：家里实际照看的人是谁。孩子的姐姐第一次在纸上有了姓名。
## b
你先从公项垫付病户急需，再请两位医者与药铺共同验核。赔付不作认罪依据，结果出来后再分担。父亲终于能回家陪床，掌柜也不能用收了钱便结案堵住后问。许照微在会验时被指出一处交代含混，认真改了。用钱缓住了最急的困境，但要让缓解不等于掩埋，后面的核验仍须做完。
## c
你从进货来源、煎服过程与病情变化逐项问起，禁以流言先断医者有罪，也不免除药铺留样的责任。街上的喧闹渐渐散了。结论来得慢些，各方都须忍受一段尚无定论的时间。许照微离衙时没有向你谢清白，只说希望以后问案也能这样：先把一个人经历过的事拼完整，再决定哪里出了错。

# A04
两岸为水争了三日，第四天却一同来到县衙。上游说下游夜里掘埂，下游说上游先堵旧口。证物是一把湿锄，双方都说不是自己的。
陆青禾请你暂不问锄头，先看两处田。上游的新桑怕涝，下游的秧田缺水；河道被一条后来加厚的私埂拦住，雨一急，上游也会遭淹，只是现在还未到那一刻。魏廷章承认埂在魏氏地旁，却说几年前修时，附近住户也出过力，为的是保一条通往集市的路。
那条路如今有摊棚，拆埂放水，摊贩就得搬。下游佃户愿帮忙搬棚，摊主问搬去哪。他张了张口，说田若死了，还谈什么做生意。两人各自说着不能再等的理由，谁也没有替对方找到地方。
{m03 == 1:春日实测的水尺图摊在桌上，至少哪一段低、哪一段后来填高，已无需重争。魏廷章只要求这一次也分别计损，不能把以前赔过当作以后都可动。|春堤仍循临时或旧界，私埂与公共河道的界线未曾完全说清。陆青禾补了一张现场图，明确标出自己的判断尚有哪些没验过。}
上游愿按时开口，下游担心夜里没人守。陆青禾提出轮守水尺，留下交班记录。那把湿锄逐渐干了，决定仍不能只落在拿过它的人身上。
## a
你判私埂侵阻公共水路，拆除并分别补偿可核的摊棚、通行和作物损失。魏家不满意，却不能再把多项利益混在一个“祖界”里。水缓缓进下游田，工人同时在高处铺了临时路。公银付得痛快，后续安置不能一样草率；你让每一户领过什么、还差什么都列在拆埂簿后。
## b
分水口立了两根刻度木，两岸每班各出一人，水位与开闭都要留记。第一夜双方仍带着锄头来守，第二夜开始有人带热茶。埂没有全拆，冲突也未凭空消失，但争论终于有了一份能共同指认的记录。魏廷章派来的管事不再独握钥匙，陆青禾把这件事写得比开口尺寸还醒目。
## c
小渠从争议外绕过，能引来的水不多，先救最急的秧。摊棚和原路保住，上游松了口气。下游的人仍来追问余下田怎么办，你将不足明写，不把通渠画成全解。陆青禾验完说，渠有用，但它替你买的是一段时间。等水再涨，旧埂的责任仍会在那里，不会沿着新渠流走。

# V04
何素娘的女儿阿荞会写自己的小名，会算一桶豆换得多少浆，却不认识母亲契上的“永”字。她以为那个字是衣架，问屋子为什么要挂在纸上。
{a01 == 1:白契有了可核的副本，铺面暂安，母亲才抽得出晚间两个时辰。她不是来谢判，而是问这份纸若将来只剩女儿一个人，女儿能不能自己读懂。|铺面的争议让母女比以前更常计算日子。何素娘说无论以后住在哪里，女儿至少该知道一张纸是留她、借她，还是要她走。}
南街几个孩子也想认字。有的是女孩，有的是来往船户的孩子，有的白天须做工。现有义学白日开门，报名又要保结，不能自然容纳这些人。老塾师愿教几个，却说夜里点灯费油，男女混坐也容易惹议论。
沈砚提出先教算账和契约常用字，免得被说另立一个规制不明的学馆。何素娘听完问，学馆叫什么她不争，只是若开始只教有用的字，谁来决定她女儿往后一生什么算有用？她说这话时仍低头搓着围裙，并不像预备了什么高论。
县衙有一条闲置的外廊，修修漏处便能借用。书铺也愿在打烊后腾出半间屋，前提是学者自备纸笔。公家介入能降低门槛，也可能让读书很快变成上榜、点名、示绩的一件事。
阿荞在你废弃的草稿背面又写了一遍“永”。末笔拖得很长，像一条还没想好流向的水。
## a
外廊修了漏处，晚间借作学字，分时入席，不收强制名费，不以性别拒绝学习。你让塾师留意照明与散学归路。何素娘领了轮值的钥匙，先在名册上写自己，才写阿荞。她说母亲也没把字认全。第一夜灯不够亮，读错了几处，笑声传到街上，比新挂的牌匾更早让人知道这里开了门。
## b
书铺允借半间，学者自备纸笔，困难者可领公用废纸。门槛低了一些，仍有人因为要挣钱、要守摊而来不了。何素娘每晚替他们带回两行字，没有把未到的人划去。掌柜发现学契的人会追问旧书里的字，索性留了两本破书。你支持的是一个能开始的小安排，它的不足也要跟着一起记录。
## c
先从秤、账、契约教起，不设额外的学馆名目。沈砚挑了最容易让人吃亏的字，塾师逐个讲解。阿荞学会“永”以后，又追问“暂”能暂多久。先生答不出所有情形，便拿两张不同的契来对读。课目虽窄，问题未必窄；你省去了一场名分争执，也得小心别让方便办成，成为永远不再扩开的理由。

# R02
那夜最先断的不是堤，是拴在巡查桩上的绳结。陆青禾摸到松绳，灯往下照，水已经从石缝里吐出细泡。她让年轻工人往后退，自己又向前试了一步。
{v02 == 1:领过足数工钱的熟手大多还在。他们认得她的手势，不需喊两次便撤到了坚地。有人主动去取备用的木料，也有人先找齐自己带来的学徒。|工班里有临时换来的人。陆青禾不得不逐个叫住，解释看着平整的地方为何不能再站。旧欠带来的空缺，此时表现为一段需要反复说完的话。}
桑九已把两条船泊在背风处。他问先接谁，程守义说先等你判定是否撤。水声很大，两个“先”仿佛都悬在没人敢负责的地方。陆青禾把绳尺抛到你脚边，说明若继续守，就需卸开邻段，让水压有出口。
{m03 == 1:春天的实测图标明后方尚有一条能走的高埂，可以先撤人再沿图复测。|前期留下的未测段横在撤退路上，灯下只能确认近处，派人探路还要时间。}
下游一户人家刚把蚕种抬回屋，听见转移便问，上次搬坏的东西谁赔。桑九没有催骂，只把船横到更近的台阶。陆青禾说水位未必越过堤顶，真正危险的是底脚先空；若天亮无事，今晚的大动干戈一定会遭人议论。
你不能等到知道她是否判断正确才决定相信她。保人、守堤、先转移住户，都需要现在便有人去做，余下的代价留到天亮记账。
## a
工人撤到坚地，险段留出警戒。半夜一片堤脚坍进水里，没有把人带走；也有未坏的段落因无人守护多受了冲刷。天亮后，陆青禾逐处重测，把误判过于谨慎的部分一并写出。你没有只挑塌掉的地方证明命令高明。人平安回来，修复仍要花钱，这两件事都真实。
## b
你付临时轮班费用，令熟手卸压，生手只运料。水从指定缺口出去，几片低田受损，主堤暂时稳住。陆青禾一夜没离开，天亮时握笔的手还在抖。你让损田户来登记，不许用“保住全县”堵住他们的开口。守住的功劳容易看见，为守住它付出的那几片田，也要有名字。
## c
桑九先接下游住户，工人只留少数察看，不再冒进补石。有人带着锅，有人扛着还没结完的蚕匾，在岸上相互让位。堤到天亮仍立着，转移的人抱怨白折腾，你安排人协助搬回。陆青禾说能被抱怨总好过只能写祭文。你记下这次撤离的耗粮，也记下哪些家庭下次需要更早的帮助。

# M04
府衙承行罗问渠在雨停后三日到县。他的靴面干净，靴底却全是泥，显然不是一路坐轿。他先问能否借水洗手，再拿出已经过期的催解文书。
文书限日把春季仓、工两项报齐。你忙于汛夜，陆青禾的验工也刚成稿，实情不难解释，期限却不会因为实情自动延后。罗问渠说府里需要能往上装订的一套数目，各县都说有难处，最后没人敢替哪一县单留一个空格。
沈砚提出先报确定部分。罗问渠点头，又说封套今晚便走，缺卷须说明补送日期。如果愿把验工日期写早几日，现有报告便看不出迟误。话说到这里，他停住，端起茶喝了一口，没有替你把那个办法说成建议。

你问若如实具报，府里会如何。罗问渠说，可能受申饬，可能准补，也可能正好撞上一位要查迟误的上官。他没有许你一定被理解。“能替县里带话，”他说，“不能替还没见过这卷的人答话。”
墙上漏雨留下的痕迹还没干。它不会因为填上一个更早的日子就消失，远在府城看纸的人却未必见得到这面墙。印泥已经调好，你得决定让他们先见到哪一部分临溪。
## a
你将汛夜处置、迟误原因与补救日期放在同一封呈文中，亲自署名。罗问渠读后指出两处含混，让你把谁何时下令写得更清楚。迟误不会被抹掉，至少也不只剩一个怠慢的结论。他走时要了一张堤图副本，说若有人肯多问一句，带着它比空口分辩有用。
## b
你先送可核的仓项与工项部分，未完验处标待补，附明确补卷日期。罗问渠拿出一份封套格式，帮沈砚把几份说明排齐。府里能收下一个有边界的未完成，你也必须准时履行余下的日期。夜间车马出城，桌上仍有待办，但不再需要假装所有事已经在三天以前做完。
## c
验工日期被提前，封套按齐件发出。罗问渠没有再端茶，等沈砚写完才盖骑缝记号。你得到了一个及时办结的记录，也接受了日后不能随意更改的先后次序。真实那夜若有人再提起，便会与此纸相撞。出门时，他说春水退得快，泥痕留得久；语气像谈路况，又不像。
