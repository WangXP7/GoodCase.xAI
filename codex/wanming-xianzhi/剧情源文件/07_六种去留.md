# E01
开春后，有人在照壁旁种了两株菜，衙役想拔掉，说官门不宜如此。你让他先问是谁种的。是修墙工的老母亲，去年儿子在这里做活，她来等过工钱，看墙根向阳，觉得空着可惜。
这一次，问是谁、为什么，已经不像一件值得大书特书的善政。沈砚习惯先给事情找人，程守义留下的值表也要求说明谁接下一手。改变很小，不足以抵抗整个年景，却能减少一个具体的人在门口被推来推去的次数。
{works >= 60:陆青禾送来第一轮水尺记录，工户自己核过，只请县衙看争议段。你终于不必为每一尺水装作比守堤的人更懂。|陆青禾带来的不是报喜，是未完段的材料清单。留任让你没法将这些问题全部交给继任，答应过的工期又回到了自己案上。}
{has_white == 1:何素娘的铺面仍在旧处。阿荞替来客读契时，偶尔会把母亲当初那张白契取出来，说明印记以外还该核哪些事实。|何素娘仍按现有安排经营，关于铺面的边界尚有该继续核的部分。你知道“留任”不能变成让她因熟识便不好意思再来催问。}
第二季用度不宽裕，邻县又来借粮。没有人因为你选择留下便保证天下从此丰足。你在新册写下可借多少，余下为何不能借，让人带着实话去，不拿一句与民休息代替数目。
傍晚，你走出门，见那两株菜已浇过水。老妇不在，墙根有一只缺口碗，像曾经盛过饭，也像只为舀水。你没有叫书吏来记，把它留在原处。
县志后来写这一任，只有几行谨慎的考语。真正继续发生的，是翌日有人带着一件未解的事来到门口，守门的人没有先问他配不配进，而是告诉他：今日开堂，先把经过说清。
春在县门外。你仍须走出去看。

# E02
赴府的船比来临溪时宽。行李装得下，卷也装得下，唯独路上遇见的人没法一同带走。罗问渠在岸边等，将你的任内办法摘要接过去，又问原始记录有没有留县。你答留了副本和可追查的出处，他才将摘要收进匣。
府里的桌面很大，能同时摊开数县的用度。第一日你便读到另一县“饥民若干”的报数，笔尖习惯性地准备圈出增减，忽然想起临溪仓外那个把外孙举在肩头的老妇。她不在这份卷里，这份卷里却一定有别的具体人。
你请报卷的书手说明熟食与生粮怎样发，书手愣住，说自己只负责抄合计。这个回答没有恶意，也正因此需要继续问。你暂缓落笔，另加一项能回到实际发放处的询问，不敢仅靠记忆里的同情替远处作决定。
{m11 == 2:临溪那套已核与待核分卷的办法被准试用，你坚持待核不是允许永久空白，每一项仍须有下一步与经手。|你的考成足以支持这次调署，但随卷仍有不同意见。到了更大的衙门，它们不会自动消失，你也没有把调令当作一张撤销旧责任的纸。}
数月后收到桑九托人带来的小包，是一截更换下来的水尺。陆青禾在上头划过旧刻度，说木朽该换，不必珍藏成不可动的遗物。你没有将它陈在正堂，放进常用的匣旁，提醒自己一项当年有用的办法，后来也会需要重新检验。
{integrity >= 65:有人劝你把临溪的迟误删出示例，以免影响推广。你留下原因与成本，因为若只有成果，别县只能学会怎样写一份同样漂亮的结果。|你知道自己的卷里也有取舍过的叙述。更高的职位增加了重新核查的能力，也更容易使你只遇见别人愿意呈上的那一部分。}
调令没有告诉你已经抵达。它只把更多人的等待，送到了你能批复的桌前。

# E03
归船过临溪最后一弯，桑九没来送。他正带一班船户核新季渡役，托人说赶不及，不必等。你听见时先有一点失落，随后觉得这或许也好：一个渡夫的日子，不必总为一位官员的去留让路。
印已经交出，手腕却仍习惯在读完纸后寻找落印的位置。家里来信问你往后怎样营生，没有夸辞官可贵，也没有责你未能更进。你在船上算路费、衣食和需偿的旧借，第一次在很久以后只以自己能承担的份额安排一季。
{trust >= 60:岸边有人托来一袋豆，没有万民伞。何素娘说收成普通，够磨几回，不是拿来替两年的事盖一个全然满意的印。你收下，也接受她仍对某些决定有不同看法。|送来的东西不多，有几户仍因旧日处置怨你。你没有为了得到一场体面离别，再请他们说一句其实并不愿说的感谢。}
离任后第二个月，县里来问一处批语的缘由。你可以只说已经移交，仍写了长信，逐项说明当时所知，哪些是后来才明白。解释不再附着权力，你无法要求接信的人采用，也不能因他未采用便私下召旧役人办事。
旧屋门槛有些高，母亲出入吃力。你找木匠商量改坡，工钱当日讲明，验完再付，不以曾做过县官便请人白帮忙。木匠报了价，你还价一次，最终照双方都肯认的数写条。县里学过的东西回到很小的地方，并未因此毫无用处。
后来有人请你写临溪任事记，你先列了一张没办完的清单。写到最下方，才添上做成的几项。你不想用退隐替所有选择洗净，也不愿因未能改尽世道便声称当年一切徒劳。
归舟无印，不是归舟无事。从此没有官门替你放大一句话，也没有官门替你挡住需要自己承担的回答。

# E04
上路时，沈砚把三件原始凭据分装，外面又套一层油纸。他不随你去，县里仍需有人核现案，但那份亲笔说明没有撤回。桑九在副单边补了船的旧号，陆青禾则教你怎样让纸避开船底返潮。
这些人并不全然同意你两年间的处置，也不因此希望证词被丢失。证据把他们暂时连在一起，连的不是一种完美无瑕的人品，而是一件事仍该按实际经过受问的共同意愿。
你循程序递卷，先得到的是收件号，不是昭雪书。廊下等候的人很多，有人等了一季，有人因为缺少一页来回奔走。你曾坐在桌内，如今坐在门外，才更明白一个“候”字可以怎样消耗路费、体力，以及人愿意再解释一次的心气。
{shadow >= 2:卷中有你自己迁就过的日期与总数。受问时不能只说后来已经改正，更不能要求别人因你肯上呈便不追此前。你把当时的决定逐一认下，再说明为何如今保留原件。|你曾留下的不齐整使整理很费力，也让几处时间能与彼此核上。受问者仍挑出你判断过早的部分，你承认证据支持到哪里，就只能说到哪里。}
第一次复核只确认了部分经手，关键命令仍待别卷相证。你没有把这点进展写成已破大案，也没有因它太小便弃卷回去。寄往临溪的信里，你注明已经查到什么、还缺什么，不许自己在远处重新变成只报好消息的人。
雪天里，一位小吏提醒你换掉磨破的封套。你取新纸时，看见最初油纸边还沾着渡口的泥。泥不值得当珍宝，纸里的姓名值得被读对。
故事停在复核继续的地方。你尚不知道最后会获得怎样的判定，甚至不保证自己能免于责问。你所保住的，是旧事没有因一份过于整齐的结案而永远失去下一次开口的可能。

# E05
你第一次以普通成员身份来相济约，当值的人请你等另一把钥匙。你习惯性说先开也无妨，对方摇头，指了指你曾经批过的条款。你只得坐下，听两名轮值者核对用途。
等候并没有羞辱你，却让你清楚自己放下的究竟是什么。过去，你的急可以成为别人必须配合的次序；如今若确有紧急情形，也须按约说明，不能把曾经掌印当作永不失效的特别身份。
何素娘请你帮忙抄字，报酬按普通抄工算。你说不要钱，她问若你长期免费做，别人还怎样凭这活谋生。你想了一会儿，领了该领的一份，另把愿意捐的写入独立账目。善意需要学的规矩，并不比用权少。
{welfare >= 60:县里的基本生计尚能支持轮值，有余力的人渐渐多些，相济约不必全靠少数几户不断垫补。|几户仍很艰难，相济约的粮也有限。你与其他成员不得不讨论先后，不因辞官便突然拥有一种不会伤人的分配答案。}
许照微来借一只桶，照例登记归还日期。桑九在出航前安排替班，阿荞发现账里有一处把你捐的纸算了两次，直接圈出，没先来顾虑你的脸面。你读到那个圈时居然松了一口气：这里的人还肯按当初希望的办法纠正你。
新任知县来问公簿，你把保管人与查账手续介绍清楚，没有替整个约抢答。对方未必喜欢一套不由他发起的安排，能否继续还要认真解释。你只能参与这种解释，不能调用旧日差役来保证自己的理想不受挑战。
傍晚，两盏灯换了新芯。轮到你关门，你将钥匙交给次日的人，没有带回家。辞官后你仍做着有限的事，所得也有限；但这些事若能由别人继续，便不必永远靠一个好官恰好留在此地。

# E06
考语送回时，纸上找不到一处难看的缺口。修堤有功，赈济得宜，旧欠妥结。你逐句读过，知道不少是真的；正因为真，删去的那些来路更难被旁人察觉。
沈砚按新总纲归档，仍把长稿留在规定的位置，没有私藏，也没有在你面前撕掉。他如今只回答你所问的部分，你不问的，他很少再像初来送簿那夜主动多说。关系没有戏剧般决裂，只少了一段原先可能继续的坦白。
罗问渠带来的调议很体面，与你接受考语的决定一起向前。无人逼你受一场立刻显现的天谴，县里也没有因为一页文书便突然堤毁粮绝。你做成的事仍在，那种一切照常，反而使这条路更容易被后人继续选择。
{has_ledger == 1:原簿仍可找到，只是如今来查的人先读结案摘要，通常读到那里就停。保存一件证据与让它真正被使用，是两件相隔很远的事。|旧簿未被完整保入正式卷，后来的抄件沿新结数整理。一个最初为了便宜行事留下的缺口，终于变成别人无需再问的常态。}
阿荞抄县里示例账时，发现一项合计与分项对不上，来问是否算错。先生解释这是不同季节归并，不必拘泥。她没有争，只把疑问写在纸背。你看见那张纸，想起两年前她问契上的“永”字为何像一只衣架，那时你很容易相信，只要教她认字，就能少受含混的亏。
后来你也学会在公文中先挑可以被理解的事。未必每次都为私利，有时是怕一个真实错误毁掉确有用处的安排，有时是没有余力再受一轮追问。理由一个接一个，像旧仓底下的空筐，总能再垫进去一只。
县志上这一任的名字写得端正。没有一个字说出你付出的代价，因为代价恰恰是：从今往后，能被写出的部分，越来越像你允许别人看到的自己。
