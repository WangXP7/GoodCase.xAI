# M05
秋粮进仓那天，沈砚发现一枚手指印横跨两张不同的纸。印纹几乎相接，数字却相差一成。前两联在县里留底，第三联随解送的人去府；如今送回的复核纸，恰好露出被压在下面的那个数。
押粮人说路上折耗常有，府县计量的斗又未必完全一样。罗问渠带来府仓的交割记号，说确有容许复点的余地，但不能因为斗有差，就容许什么差额都往里装。他把两种印记画给你看，一种是过手，一种是实收，前任卷里常被混写。
{has_boats == 1:你取出桑九的渡船副单，起运那一笔与第三联的旧数接近。它不能独自证明粮到了哪里，却说明差别并非从今日才开始。|缺少完整的运送副单，县里的判断只能从现有交割记号向前追。沈砚提醒，不要把没有找到的那一段写成已经证实的失窃。}
仓外有里老催着领回空袋。他们还要装家中留存的粮，袋若被扣在此处，一家人的秋收也跟着等。程守义建议先放无争议的部分，人和粮不能全扣住等一个答案。
罗问渠问你想把这件事办到哪一步。封存第三联，会给以后留下原始对照，但本季不齐的数要由你解释；共同复点，能让府县一起认可现状，过去仍有部分空白；用余项垫平，最容易立刻交差，却让县里的其他用途少了一笔钱。
沈砚把那枚跨纸的指印对好，又松开。他说指纹可以接在一起，两个人承担的责任未必能这样接。你要决定保留下来的，究竟是一份平整的报表，还是一处以后仍可被问起的错位。
## a
第三联封存，你在封套注明来源和经手人，另依实数分批解送。罗问渠带走迟解说明，没有带走这件原物。仓外先放回无争议的空袋，押粮人留下补问。沈砚将指印所在处用薄纸护住，叮嘱不得裁齐边缘：正是那一点不齐，才让人看见旧数被压在什么下面。
## b
府县各出经手人复点，以现量和当日交割会签，争议另附说明。罗问渠把自己的名字写进去，催解的语气终于缓下来。共同确认的结果比单方说法更站得住，复点与等候也花了公项。沈砚提醒尚不能倒推旧年全无问题，你准他在附页保留这句话，没有让会签成为一笔洗清过去的水。
## c
你从本县余项补出差额，保本季按额解送。空袋与人很快散去，府里收到的是一份干净的完成数。沈砚询问垫付列在哪项，你选了一个可以暂缓的用途。他照写，没有省略受影响的原项目；待那项用途再被问起，仍须另找钱。

# V05
县里要奖汛夜助渡的人，桑九却把赏帖退了回来。红帖将他写成带船救人的首领，字很大，下面只有三个正式渡户的名字。那夜替他解缆的嫂子、替两条船补漏的木匠、在岸上接孩子的卖鱼人，都在“等”字里。
他不反对领钱，甚至问过银何时发，因为船底正漏。他反对的是其他人必须通过他才能领。他说那夜确实是自己先到，但先到的人便能替后来所有人收钱，以后大家会抢着先报自己的名字，未必抢着先拉落水的人。
程守义解释，奖赏要有名册与保结，人数一多，核验会拖。桑九便把一块破船板放下，上面用炭写了谁在哪一段做过什么。他说这块板原该拿去烧，不值钱，若有人能证明自己记错，可以当着大家改。
{a02 == 1:新渡籍已经收了不少实际船工，补记并不必从零开始。只是那几位不常撑船的帮手，仍在格子外头。|现行渡籍仍依旧户运转，正式赏帖照着旧名字抄，并非某个书手特别偏心。桑九让你看见的，是照规矩抄也会反复漏掉同一批人。}
桑九没有催，只把那块要烧的板搁在红帖旁。
## a
你准船工公开互证，列清不同工作，不以先报的人代收全部。多列几名并没有凭空多出银子，大家须共同商定比例。争了半日，桑九所得比原帖少，他仍签了。木匠领钱先买钉，卖鱼人捏着那点银问自己的名字能否留在副单上。赏钱很快花掉，做过的事却终于不必等旁人肯再提起。
## b
红帖改为公用修船料清单，领取与用途逐次登记。桑九知道漏船能修，点头收下，又替急需现银的人问了一遍有没有别的办法。你让其另报真实困难，不借奖赏一并遮过。公物减少了争功的诱因，也无法等同每个人的工钱。这项办法留在渡口，连同它没有解决的部分一起。
## c
原册先发，补报设了明确日期，由其他在场者作证。桑九替嫂子拿了一张空表，问可否用指印代签。你说可以，他才将赏帖收回。先领的人回去得早，漏名的人仍需再来一次。程守义把补报名单贴在门侧，你嘱咐到期之后也别立刻揭掉，免得忙着维生的人错过就再无入口。

# A05
义学里来了一个说不出姓的孩子。他能背出母亲教的几句旧诗，背到末句便停，说不能讲出诗中那个字，因为那也是原家的姓。
带他来的人是何素娘。孩子随一位改嫁的妇人寄居南街，新夫家不肯让他用自己的姓，原乡那一支又不愿出保结。孩子说若入学只差一个姓，可以随便取。他这话让几个大人都笑了，何素娘没有，说将来要在纸上用一辈子的，不能只为今日方便随便给。
沈砚查了现居记录。日常抚养、街坊见证都能对应，争议集中在原乡宗族，不是孩子确实不存在。若把所有旧身份问题先解决再准记名，他可能等到过了入学年纪；若全不理会，未来涉及继承与差役时，又会有人拿今日的记名说县里已经全认了。
{v04 == 1:外廊夜学已有愿意教他的先生，只差名册该怎样写。这张本为打开门的名册，第一次碰到一个不能被简单填满的空格。|先前的借屋授字或契约课允许他暂时坐下，长期学习仍缺一份可随身带走的凭据。何素娘不愿让他永远只能凭某位先生一时心软。}
孩子望着阿荞写过的练字纸，认真问能否先用小名。你问他的小名是什么，他说“小满”，又补一句，自己并不是那一天生的，是母亲盼着家里粮能满一点。
你让沈砚另取一张纸，先把确实知道的写在最上面，不宜用一句准予入学，替孩子定下尚在争议中的全部家产归属。
## a
你依抚养、现居与互证登记小满，旧姓争议封存为另一事项，明言此凭不预断族产。先生在名册边写了可以追查的卷号，不把孩子的私事当众念完。小满领到自己的纸，先问母亲能否看懂。何素娘说看不懂也没关系，夜里有人教。他终于不需要先替大人解开所有旧结，才能学写第一个新字。
## b
你准旁听，原籍部分待原乡回文后补。小满明日能来，身份却还处在暂定一栏。何素娘要求注明若回文不来，何时再议，你给了一个期限。先生把座位留好，沈砚发出询文。等待总比当场被赶走好，却会消耗一个孩子最容易被忽视的东西：不是纸墨，是他相信明年自己仍能来这里的把握。
## c
临时寄学凭据只证明在临溪现居求学，明确不作宗族继承的依据。小满有了可带走的纸，其他争议没有被草率裁断。他练名字时把“满”字写得格外挤，仿佛少一笔就要漏。何素娘替他另垫一页废纸，说字写坏了可以重来。你让书吏也保留底本，免得将来的核验只剩孩子自己保存得好不好。

# A06
逃役人被带回时，一只鞋穿在脚上，一只藏在怀里。程守义问他逃时为何不穿，他说泥路会掉，怀里这一只还是完整的，家中弟弟往后能穿。
他叫杜成，被派往外县运料，役期尚未结束便返乡。差票无误，抓捕也无误。他的母亲病倒，家里另交过替役钱，收钱的中人却没将替役补上。杜成以为付过便能回，典史认为未办完交替便是擅离，两个说法中间有一笔没人愿主动拿出的收据。
沈砚找到一张旧纸，写的不是替役，是“代办茶资”。中人说只是答应替他询问，没有保证一定办成。杜成把怀里的鞋放到地上，说当时讲的不是这个。他说不清对方究竟用了什么字，只知道交钱以前，对方说家中有人病，官里总能通融。
程守义脸色不好。他未必拿了那笔钱，但差役中的人知道中人常在门外等着，却没人阻止。他说若只凭谁家急便准离役，明日押送的队伍会散一半。你问若人人必须先付一个不算承诺的茶资，留下来的又是哪一半人。
这不是免去全部公役便能解决的事。运料的负担仍要有人接，照护的时间也不能从病母身上退回。你可以追替役钱，调整分担；可以先给一段明确的照护假，再复核；也可用近家轻役替远役。每一种办法都需留下规则，免得下一位杜成只能重新寻找门口那个肯说“通融”的人。
## a
你查替役钱的经手与去向，禁止再以模糊茶资售卖承诺，未补的役额按实际情况重排。程守义须说明为何门外中人能长期活动，他起初不悦，后来拿出两份旧差单。杜成领回鞋去照看母亲，仍要依新安排履役。县里没有白得一份劳力，至少开始把负担和收过的钱放到同一张桌上。
## b
三日照护假立即给出，返役期限与复核责任写明，由程守义安排接替而非杜成另花钱找人。典史答应得很郑重，因为这回通融有了他必须履行的内容。三日不够让病人一定痊愈，却够重新安排照护。你嘱咐期满仍有困难可再核，不让一个本为缓急的日期，转头变成另一道无人问因的锁。
## c
你保留役期，以近家可做的轻役替外送，原队缺额另调。杜成白日做事，晚间回家，怀里的鞋不必立即交给弟弟。程守义赞同这办法，说至少不废差役规矩。你让他一并核查茶资，免得解决此人眼前的困境，便算解决了门外那桩生意。换了役处的人能喘息，收过的钱仍须有人问。

# R03
何素娘递来的纸没有写“民妇叩呈”，第一行写的是昨夜用了多少油。她说先生教过公文该怎样开头，但这不是求人办案，是有人要看账。
{v04 == 1:外廊夜学的灯油有人领多了，她起初以为是偷，问过才知多领者把一盏带回去，给白日来不了的两人补课。她不想用这一善意抹掉错记，也不愿用错记取消两人学字。|借屋授字留下的纸笔账出现差额，有人把给未到者抄写的份额算成自用。她来分清用途，希望小安排也能有查问的办法。}
纸上还有她自己的错误：第一次把一包纸按整刀算，多记了一笔。阿荞发现时，她先让女儿别出声，随后想起母女当初为一张契争了多少话，才把错处另圈出来。
她说最难的不是承认算错，是承认自己曾经想藏住。若这页拿来当女子也能理账的例子，旁人会把错误放大；若因此不写，往后所有想学理账的人便得假装从不出错，才配坐在桌旁。
小满在旁边替她研墨，衣袖卷得很高。他认得“油”字了，说与水有关。何素娘解释这油不能喝，小满便问为什么两个字都有水。屋里的人笑起来，账上那一笔不因此变对，气氛却终于不只剩下审错的人和被审的人。
何素娘说请书吏协助可以，别把她的原稿全抄没了。她想学习把账记对，也想保住自己确实学过的痕迹。
## a
你准原稿、错处与更正理由一并留存，不把错账作为夸奖或嘲讽某一类人的凭据。何素娘另写一张纠错说明，阿荞替她数了遍纸。借走的灯归还，多用的油按实记为补课。县衙没有因此得到一份完全漂亮的成绩，却留下一个普通人犯错后仍能继续参与的办法。
## b
轮值看账设为一月一换，经手与核验由不同的人做，不让能力强的人一直包揽。何素娘起初担心新来的人算不清，后来把常错的地方写成小条。她不再必须证明所有事只有自己能做好。账房钥匙下一次交出去时，也带走一套可以质疑前任的规矩，其中包括质疑她自己。
## c
沈砚每月抽空协核，保留何素娘原稿，以不同墨色注明更正。他教她将数量与单价分列，她指出衙门常用的几个简称外人看不懂。两人的纸上都添了批注。协助没有变成收回那支笔，官府的经验也得到一点来自门外的修正。她告辞时没套公文的结尾，只说下月还来。

# M06
秋收后的闸口只差一尺水，两个村却为这一尺熬了三夜。上游想留水灌冬田，下游的晚稻还泡在泥里。陆青禾把水尺读数报给你，又报明风向，说明今晚与明晨不能用同一个数来想。
{v03 == 1:魏氏春借也已到偿期。本次结算归还仓粮十六份，另付公银二份作约内折息。魏廷章带来销账凭据，先将借约结清，才谈上游放水；两件事不可混作彼此让步的代价。}
{a04 == 2:两岸轮守的记录已经积了厚厚一叠。双方仍各挑对自己有利的几日，却无法再声称整个季节都是对方私开。|此前拆埂或开小渠改变了部分水路，两岸对承担的损失记得分外清楚。陆青禾把变化后的读数另列，不拿旧图直接当今日的答案。}
魏廷章送来上游佃户的请求。他这次没有只盖自己的章，每户各按了一印。桑九则替下游带来一束尚青的稻穗，搁在岸边湿石上，半天没人去拿。
有人建议干脆等雨停，谁也别担开闸责任。陆青禾说等也是做法，水只会按等候的结果流，并不因为没人下令便不算人事。她的声音已有些哑，白日验完工，夜里又来读尺。
你问放水后能否登记损失，魏廷章说可以，但不要到赔偿时才说上游早该为全县牺牲；你问轮换开闸谁肯守，桑九说两岸各出人，他可以摆船送他们过来；若选择继续蓄水，县里能多保一批冬粮，却得承认有些下游稻田将因此错过收割。
你将那束稻穗拿起来，看见里面已经生芽。判定水该去哪不是在两种抽象利益之间取一个好听的名字，而是决定哪户人今夜可以回去睡，哪户仍须守在泥里。
## a
闸先开，下游水缓退，上游损失逐户登记。魏廷章派人监督登记，直到最后一户也报完才离开。陆青禾按计划闭闸，没有因已经开过便一泄到底。你拿到两份清单，一份是救下的田，一份是受影响的田。两份都盖印，免得来年只留第一份用来讲述这一夜的功劳。
## b
水按尺轮换，两岸各有见证，交班必须到场对读。桑九摆渡数次，最后索性留船在闸下。两边都没得到想要的全部，也都看见自己在何时得到了那一部分。陆青禾将例外处置单列，提醒后来人规矩不是让人闭眼守时辰。轮值吃力，却让争执有了能延续到你离任以后的形状。
## c
你准继续蓄水，先保冬田与储备，要求下游受损照实列报。桑九带回那束稻穗，船上没人责骂，沉默反倒让事情更重。仓里将多一批粮，不能直接退还成那些人家原先的收成。你命优先给受损户留救济入口，知道这只是弥补，不能把决定造成的损失改称他们自遭的灾。
