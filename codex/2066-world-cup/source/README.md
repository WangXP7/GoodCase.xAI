# 2066 决战世界杯

一款可直接在浏览器中游玩的 5v5 三维足球对战游戏。玩家操控中国 2066 队迎战由状态机驱动的世界明星队；原有比赛规则、三档 AI、阵型设置、实时数据、排行榜和本地生涯记录全部保留，并升级为 WebGL 3D 赛场。

## 3D 技术架构

- **Three.js**：负责球场、看台、球门、低多边形球员、灯光、阴影、广播视角相机与场景渲染。
- **Ammo.js**：作为唯一物理权威，处理足球和球员刚体、摩擦、反弹、冲量、边界与球门碰撞。比赛采用固定时间步推进，使不同帧率下的运动保持一致。
- **PixiJS**：叠加透明的赛场 HUD、选人光圈、瞄准提示和进球粒子，不干扰 Three.js 场景输入。
- **React / vinext**：管理比赛界面、设置、战绩、排行榜与本地档案，并把状态同步给三维引擎。

三套引擎共用一个动画循环：Ammo.js 先计算世界状态，Three.js 再同步并渲染 3D 实体，PixiJS 最后绘制屏幕空间特效。这样可避免视觉层与物理层各自推进导致的漂移。

## 启动游戏

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（默认 `http://localhost:3000`）。首次进入比赛时会初始化 WebGL 场景和 Ammo.js 物理世界；按钮恢复可用后即可开球。

## 操作说明

- `WASD` 或方向键：移动当前球员
- `空格`：朝三维球场中的瞄准方向射门
- `E`：智能传球
- `Q` 或 `Tab`：切换队员
- `P`：暂停或继续
- 点击己方球员：直接切换控制对象
- 鼠标 / 触控：调整瞄准方向；移动端可使用屏幕摇杆与射门、传球按钮

## 游戏功能

- 5v5 三维球场、立体球员、球门、看台、灯光与广播视角相机
- Ammo.js 足球摩擦、边界反弹、刚体碰撞、射门冲量与门线判定
- 会追球、协防、拦截、门将扑救和反击射门的 AI 对手
- 新秀、职业、传奇三档难度
- 1 / 3 / 5 分钟赛制、实时比分、暂停、进球特效和终场结算
- 2-2、1-2-1、3-1 三套阵型及四种主场球衣
- 控球率、射门、传球、扑救等实时与赛后数据
- 本地球员档案、历史战绩和带种子数据的世界排行榜
- 键盘、鼠标、触控与响应式布局支持

本地球员昵称和战绩仅保存在当前浏览器的 `localStorage` 中，不会上传个人信息。

## 验证与构建

### GitHub Pages 静态版本

```bash
npm ci
npm run build:pages
```

将 `dist-pages/` 内的文件部署到任意静态站点子目录即可运行，无需服务端、CDN 或外部 API。资源路径使用相对地址，适配 GitHub Pages 项目站点。游戏需要支持 WebGL 的现代浏览器，建议通过 HTTP(S) 打开。

在线案例：https://wangxp7.github.io/GoodCase.xAI/codex/2066-world-cup/

```bash
npm test
npm run build
```

`npm test` 会先完成生产构建，再验证服务端输出、Three.js / Ammo.js / PixiJS 集成标记，以及游戏核心能力是否仍保留。
