# 《深度调音台》设计说明

## 1. 项目目标

本项目是一份面向非技术用户的 Attention Residuals（注意力残差）交互讲解。目标不是复现模型推理，而是让用户在约 90 秒内建立三个准确认知：

1. 标准 PreNorm 残差可以从展开视角理解为：此前各层更新以固定单位系数持续进入残差流。
2. Attention Residuals 沿网络深度对先前层输出做 softmax 加权聚合，权重可随输入内容和位置变化。
3. Block AttnRes 通过“块内常规残差、块间注意力聚合”控制 Full AttnRes 在大规模训练中的额外存储与通信成本。

页面必须同时满足：

- 单个 `index.html` 文件即可交付；
- Windows、macOS、Linux 上用现代浏览器双击打开；
- 运行时不需要 Node.js、Python、服务器、CDN、字体或其他依赖；
- 支持桌面、平板、手机；
- 核心流程可用鼠标、触摸与键盘完成；
- 所有示意数据确定且可复现，便于截图回归。

## 2. 信息架构

页面采用四段递进叙事：

| 章节 | 用户问题 | 核心交互 | 学习结果 |
|---|---|---|---|
| 01 固定 vs 按需 | 过去的每一层都要一样大声吗？ | 切换输入、层数、播放/单步、手动权重 | 理解固定累加与内容相关混合的差异 |
| 02 两个注意力 | “注意力”到底在看什么？ | 在 token 轴与 depth 轴间切换 | 区分词间注意力和 Attention Residuals |
| 03 Full vs Block | 如何控制跨层聚合开销？ | 调整每块层数 | 理解块内累加、块间选择 |
| 04 证据边界 | 论文说了什么，又没说什么？ | 展开官方来源、重新体验 | 带走准确且不过度外推的结论 |

## 3. 交互设计

### 3.1 对照实验室

左右两栏共享同一个输入、深度和动画进度：

- 左栏每一路始终显示 `1×`，强调固定单位系数；
- 右栏显示总和为 `100%` 的示意权重；
- `事实召回`、`多步推理`、`回看约束` 使用三组内置确定性权重；
- 调整当前层深度时，对权重重新归一化；
- 播放、暂停、单步与重置让用户控制解释节奏；
- 方向键可在实验区域内前后单步。

“我来调”模式允许用户选择某一层并调整其权重。其余层按当前相对比例自动重分配，最终整数百分比始终精确合计为 `100%`。页面同时提示：这是对聚合过程的教学模拟，真实权重由训练后的模型计算。

### 3.2 注意力轴切换

同一视觉容器在两个状态间切换：

- `AXIS = TOKEN`：展示序列位置之间的选择；
- `AXIS = DEPTH`：展示网络层级之间的选择。

文字、布局方向和问题句同时变化，避免只靠颜色表达概念。

### 3.3 分块实验

使用 12 层玩具模型，滑杆控制每块包含 `1–4` 层：

- 每层单独成块时，对应 Full AttnRes 的逐层回看视角；
- 每块 2–4 层时，显示块内固定累加与块级表示；
- 页面同步更新块数以及 `O(Ld)` / `O(Nd)` 的概念量级。

这里的量级仅用于说明额外的深度聚合状态，不代表完整训练或推理复杂度。

## 4. 视觉系统

视觉方向为“科学编辑部 × 模拟调音台”，避免通用的霓虹 AI 风格。

### 4.1 色彩

| 用途 | 色值 | 含义 |
|---|---|---|
| 纸张背景 | `#F2EFE7` | 编辑部、手册感 |
| 正文 | `#17242C` | 高对比阅读 |
| 标准残差 | `#C5682C` | 固定、持续的累加 |
| Attention Residuals | `#087E8B` | 选择、重混合 |
| 当前层 / 关键动作 | `#D64C4C` | 当前焦点 |
| 提示 | `#B8D061` | 离线、可操作、结论标记 |

### 4.2 图形语言

- 粗描边、机械面板、轨道与刻度构成“调音台”隐喻；
- CSS 形状和 DOM 元素完成全部图形，不依赖图片或图标库；
- 轨道长度同时配合百分比文字，颜色不是唯一信息通道；
- 标题使用紧凑的大字号，正文保持舒适行长；
- 阴影使用硬边偏移，强化可操作的实体感。

### 4.3 响应式

- `> 980px`：首屏双栏、实验左右对照；
- `761–980px`：首屏上下排列，工具栏两列；
- `≤ 760px`：实验卡片上下排列、分块纵向串联、注意力轴改为纵向；
- `≤ 390px`：按钮满宽、标记与轨道进一步压缩；
- 所有关键触控目标不小于约 `44 × 44px`。

## 5. 动效与可访问性

- 首屏层轨道使用轻微呼吸与信号流动；
- 当前实验步骤在两栏同步高亮；
- Attention Residuals 权重长度使用缓动过渡；
- 分块变化使用短距离淡入；
- 动画默认不发声，不自动抢夺焦点；
- `prefers-reduced-motion: reduce` 下将持续动画和滚动缓动降为近乎即时切换；
- 所有操作使用原生 `button`、`input[type=range]`、`details`；
- 焦点轮廓始终可见；
- `aria-live` 只在离散操作完成后播报，避免滑杆拖动时连续打断读屏。

## 6. 技术方案

`index.html` 内联：

- 语义化 HTML；
- 完整 CSS；
- 原生 JavaScript；
- 全部中文文案和演示数据。

明确不使用：

- 外链 CSS、脚本、图片、字体、音视频；
- `fetch()`、XHR、WebSocket；
- ES Module 外部导入；
- 浏览器存储；
- 必须启动本地服务器的逻辑。

因此运行时只有一个要求：设备上存在支持现代 HTML/CSS/JavaScript 的浏览器。

页面暴露只读测试钩子 `window.__ATTN_RES_TEST__.getState()`，用于自动验收权重总和、模式、深度和分块状态；它不影响正常交互。

## 7. 文案与事实边界

页面使用以下约束：

- 将机制表述为“沿网络深度对先前表示做 softmax 加权聚合”；
- 将标准残差表述为论文所采用的“展开视角下固定单位权重累加”；
- 对实验结果统一使用“论文报告”“在论文实验设置中”等限定；
- 不宣称模型“永远不会遗忘”；
- 不将 Attention Residuals 等同于扩展上下文窗口；
- 不保证对任意模型、数据和任务都提升；
- 明确指出页面权重是教学示意，不是 Kimi K3 内部读数。
