# Attention Residuals · 深度调音台

一份可完全离线运行的 Attention Residuals 中文交互讲解。

## 直接运行

双击 `index.html`，或把它拖进任意现代浏览器。

不需要安装依赖、不需要启动服务器，也不需要联网。`index.html` 可以单独发送给其他人使用。

## 文件

- `index.html`：完整网站，所有 HTML、CSS、JavaScript、图形和数据均已内联；
- `DESIGN.md`：信息架构、交互、视觉、技术方案与验收标准；
- `README.md`：运行与项目说明；
- `QA.md`：自动化与视觉验收结果；
- `artifacts/`：Playwright 验收截图。

## 内容边界

页面是机制教学示意，不是模型推理器，也不读取 Kimi K3 的真实内部权重。论文效果均限定为论文所报告的实验设置。
