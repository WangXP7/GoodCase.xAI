# 极蛋农场 · Eggstreme Farming V5

由 AI Agent 独立完成的 3D 增量养成农场游戏案例，使用 Three.js 与 Ammo.js，所有运行时代码、WASM 与 3D 模型均内嵌在单个 index.html 中。

## 主要玩法

- 从零发展农场，购买鸡、升级设施并形成资源产出与消耗循环。
- 支持围绕主角旋转视角、自动收蛋器、GM 数值调节面板。
- 左下角实时日志框可拖动调整大小。
- 完全静态、无外部资源依赖，可在 GitHub Pages 或本地浏览器运行。

## 操作

- WASD：移动角色
- 鼠标拖动：旋转视角
- 页面内按钮：建造、升级、购买与 GM 调参
