# MOMENT 即刻 · 互动拍立得

一台可互动的三维拍立得。使用原生 HTML、CSS、JavaScript、WebGL2 / GLSL ES 3.00 与 Canvas 2D；无运行依赖、无 CDN、无外部图片、无需安装。

## 打开

- 双击 `start.bat`：自动启动独立后台服务，再打开相机；重复运行会复用已有服务。无 Node.js 时自动打开离线 HTML。
- 也可双击 `index.html` 直接离线运行，不需要本地服务。
- 可选：在此目录执行 `npm start`，打开 <http://127.0.0.1:4178>。
- 推荐使用支持 WebGL2 的现代桌面浏览器。WebGL2 不可用或上下文丢失时，会自动切换 CSS 相机，保留拍摄、显影、收藏及导出。

## 操作

| 操作 | 效果 |
| --- | --- |
| 拖动三维相机 | 查看机身正面、侧面及背面 |
| 滚轮 | 缩放相机 |
| 方向键（相机聚焦时） | 旋转相机视角 |
| 点击实体红色按钮、右侧快门或按空格 | 闪光、快门、吐纸并显影 |
| 拖动、轻晃显影中的相纸 | 加快模拟显影 |
| 切换场景 | 落日旷野、极光之夜、蓝调海岸 |
| 选择胶片 | 原生彩色、暖调复古、银盐黑白 |
| 拖动曝光滑块 | ±1.5 EV 的画面调整 |
| 放入自己的照片 | 本机读取并居中裁切为方形，可套用胶片和曝光 |
| 换卷 | 补充 8 张胶片，保留当前收藏 |
| 点击收藏相片 | 放大预览并导出带相纸边框的 1200 × 1440 PNG |
| Esc | 关闭相片预览 |

页面初始的三张照片标记为「样片」。新拍照片放在收藏最前面。照片仅保存在当前页面内存中，刷新会清空；请在刷新前保存需要的 PNG。导入照片仅在本机解码，不上传。模拟取景场景由代码绘制，不调用真实摄像头。

## 视觉实现

- 真实三维网格：圆角机身、多层镜头、遮光叶片、橡胶齿纹、光学玻璃、闪光扩散片、实体快门、背板与紧固件。
- 自定义 GLSL 着色：粗糙度与金属度、菲涅耳反射、镜片镀膜色、摄影棚柔光箱反射、2048² 深度阴影及 PCF 过滤。
- 程序化风景与胶片颗粒、动态取景、景深式显影、闪光和 Web Audio 快门 / 马达声。
- 支持窄屏、触摸、键盘和系统减少动态效果设置；后台标签页暂停连续场景渲染。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 中文工作台和无障碍语义 |
| `styles.css` | 摄影棚布局、响应式样式、相纸动画和 CSS 降级相机 |
| `renderer.js` | 无依赖 WebGL2 渲染器、几何与材质 |
| `app.js` | 程序化风景、交互状态、声音、显影与导出 |
| `server.cjs` | 可选本地静态服务 |
| `start-preview.ps1` | 检查并启动独立后台服务，再打开本地预览 |
| `WORK_LOG.md` | 制作和验证记录 |

原生脚本通过 `defer` 按顺序载入，不使用 ES Module 或 `fetch`，因此支持 `file://` 直接运行。

在线案例：[MOMENT 即刻 · 互动拍立得](https://wangxp7.github.io/GoodCase.xAI/codex/moment-instant-camera/)。案例收录于 [GoodCase.xAI](https://github.com/WangXP7/GoodCase.xAI)，由 AI Agent 独立实现；在线运行不需要 Node.js 或本地预览服务。

如果浏览器提示 `127.0.0.1 拒绝建立连接`，说明服务尚未启动或已经停止，重新双击 `start.bat` 即可。后台服务与本次对话分离；电脑重启后需要重新运行入口。关闭浏览器不会自动停止后台服务。

## 验证

`npm run check` 检查脚本语法，`npm test` 验证几何、投影和离线入口。额外运行检查已验证整卷拍摄、显影、换卷、参数校验和 PNG 导出。具体执行结果、复跑方式及覆盖边界见 `WORK_LOG.md`。

若浏览器支持 `document.modelContext`，页面会注册读取状态、设置相机、拍照显影、换卷四个 WebMCP 工具。不支持该接口时不影响任何用户功能。
