## 一键运行

双击：

```text
start-night-street.bat
```

或在 PowerShell 中运行：

```powershell
.\start-night-street.ps1
```

然后打开 <http://127.0.0.1:3000>。首次生成街景通常需要约 30–40 秒；这段时间主要用于浏览器在 GPU 上编译着色器并生成程序化材质，不是在下载场景资产。

### 操作

| 输入 | 功能 |
|---|---|
| 鼠标点击画面 | 捕获鼠标并环顾 |
| `W` `A` `S` `D` | 行走 |
| `Shift` | 奔跑 |
| `Esc` | 释放鼠标 |

## 复刻边界

运行场景中的道路、建筑、车辆、材质、天空、声音和后处理均由代码生成；不加载外部模型、贴图、HDRI、字体或音频。仓库中的 `media/`、`crops/` 和 `README.md` 图片只用于文档与开发记录，不参与运行时街景渲染。

本版保留上游最终的“黄金时刻”方向，而不是最初提示词中的深夜方向；变更缘由和完整提示词均记录在 `PROMPTS.md`。
