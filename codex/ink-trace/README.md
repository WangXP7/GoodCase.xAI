# 墨迹 · Ink Trace V2

由 Codex 完成的中日汉字书法工作台：单文件 HTML、逐笔动画、毛笔与模拟力度、临摹和多格式导出。

[在线运行](./index.html) · [返回案例画廊](../../index.html)

## 使用

- 在桌面浏览器打开 `index.html`；也可下载这个文件后断网使用，不需要安装或启动服务。
- 输入最多 8 个汉字或多个词语，按 Enter 或点击“落墨”。
- “中文 / 日本語”会同时切换界面语言与对应笔顺数据。
- 点击“播放笔顺”，可暂停、继续、从头书写，或关闭毛笔显示。“行笔”数值越大，播放越快。
- 支持四种纸面、横竖排版、临摹、自由手写、撤回，以及 PNG / JPG / SVG / WebM / JSON 导出。

## 实现与边界

完整应用和字库内嵌在约 25.5 MiB 的 HTML 中，无 CDN、运行时字库请求、账户或服务端依赖。常用标签 14–16px，滑块名称和数字为 16px。

动画按每个字的有序笔画轮廓与中线逐笔绘制，加入笔间提笔和移动。自动播放的力度是根据局部笔画宽度与起收笔阶段模拟的，不是实测书法家压力；手写支持设备提供的压感笔输入。字库未覆盖的字会提示并显示灰色静态字形，不编造笔顺。

中文内嵌 8,035 条字符记录（简体优先、繁体补充），日文 7,007 条记录，包含字库原有的部件记录。两种语言数据独立，不等同于覆盖全部 Unicode 汉字或所有地区的笔顺标准。

静态图片不导出毛笔指示；WebM 会按当前速度录制完整笔顺，保留当前毛笔显示设置。录制时请保持页面在前台。SVG 中已收录的汉字为矢量路径，纸面纹理为内嵌位图；印章文字与缺字回退仍可能依赖系统字体。
