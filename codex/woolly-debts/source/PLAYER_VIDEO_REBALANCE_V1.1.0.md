## 3. v1.1.0 数值曲线

### 3.1 账单主线

主线金额为：

`75 → 160 → 320 → 750 → 1,500 → 3,200 → 7,500 → 16,000 → 40,000 → 90,000 → 250,000 → 650,000 → 1,600,000 → 4,000,000 → 16,000,000 → 64,000,000 → 270,000,000`

其中 `$75 / $160 / $320 / $750` 来自初版公开锚点，`$250,000` 来自正式版社区卡关反馈，`$16,000,000` 和 2.7 亿量级来自玩家通关视频。其余节点属于插值拟合，不标成原作精确值。

### 3.2 收益阶段

基础羊掉落不直接改写，而是按已付账单数应用阶段倍率：

`1 / 1.5 / 2.3 / 7 / 14 / 30 / 70 / 160 / 370 / 850 / 2,300 / 6,500 / 18,000 / 52,000 / 180,000 / 560,000 / 1,700,000`

这样保留了早期约两至三局支付一张账单的压力，同时让后期进入万、百万、千万和亿级，不再停在几千元区间。收益倍率是为可玩性拟合的本项目参数。

### 3.3 锤具与技能价格

- 软糖锤仍保留公开面板锚点和 `$500` 价格。
- 后续锤具改为 `$2,500 / $12,500 / $150,000 / $1,500,000`，避免进入中期后所有锤具瞬间买完。
- 技能树从 `$30` 起步，逐层扩展到数十万；不再发放或消耗技能点。

## 4. 新实战循环

1. 鼠标悬停肥羊，按攻速自动挥锤并消耗体力。
2. 普通命中有概率掉零钱；击碎后爆出该羊主奖励。
3. 钱币先弹落并留在桌上；鼠标移近后才吸入现金。磁铁等级决定吸附半径。
4. 游客羊击碎后恢复 15 体力；恢复重击还能给所有击碎追加体力。
5. 电弧连锁、落石雨、范围溅射和额外羊改变目标选择与桌面密度。
6. 体力耗尽后保留 0.8 秒最后拾取窗口，再结算未拾取损失。
7. 下一天补满体力、刷新整桌肥羊并清空本局统计。
8. 用现金购买技能/锤具，支付账单后做三选一，决定下一阶段构筑。

## 5. 血条定位修复

旧实现把血条放在羊的 `Group` 内，羊转向时血条也跟着旋转，羊受击缩放时血条一起缩放，视觉上会斜、飘、压进羊毛。

新版实现：

- 血条独立挂在场景根节点，不继承羊模型旋转和受击缩放。
- 每帧根据羊的朝向，把锚点移动到实际头部前方；游客羊因帽子更高，使用单独高度。
- 血条四元数始终复制相机朝向，确保任何羊朝向下都正对屏幕。
- 背板和填充关闭深度写入，避免被羊毛切掉；填充从左侧缩短。
- 仅悬停或最近 1.45 秒受击时显示；伤害数字改到身体区域，掉落数字移到更高层，不再压住血条。

自动测试比较羊的屏幕锚点和血条屏幕点：血条必须明显高于羊，水平偏移保持在合理范围。验证截图为 `test-output/v1.1.0-02-healthbar.png`。
