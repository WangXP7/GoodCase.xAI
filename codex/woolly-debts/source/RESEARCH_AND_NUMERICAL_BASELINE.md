## 1. 结论先行

《Bills Must Be Paid》的爆发不是单一“砸猪”噱头，而是四个高转化结构叠加：

1. **零学习成本的主动输入**：鼠标悬停即自动挥锤，避免传统点击游戏的手指负担。
2. **短时随机奖励**：不同储蓄罐、钱币档位、暴击、范围与稀有头奖，让每几秒都有反馈。
3. **清晰的外部压力**：账单金额与天数把无限增量游戏切成可读的小目标。
4. **局内构筑 + 局外轮回**：付款后三选一、技能树、锤具和破产饰品让失败仍产生进度。

Steam 市场信号非常强：官方在上线不足 72 小时宣布销量超过 10 万；2026-08-11 的 SteamDB 快照显示历史同时在线峰值 8,143、24 小时峰值 3,818、当前 2,650，6,222 篇评测中 6,046 篇好评（97.2%），SteamDB 评级 93.77%。SteamDB 的第三方拥有量估算区间约 25.76 万至 35.18 万，估算并非官方销量。

GitHub 公共仓库中没有找到可信、完整、许可证允许复用的同类游戏源码。精确短语与相关关键词命中的仓库主要是攻略站、记忆读取助手、视觉跟踪器和资产研究工具。因此本项目只把公开仓库用于结构验证与工程选型，没有拷贝闭源游戏或粉丝站资产。

## 4. 玩法拆解

### 4.1 主循环

```text
悬停目标 → 自动挥锤 → 体力消耗 / 暴击 / 范围命中
       → 击碎储蓄罐 → 随机钱币 → 支付限时账单
       → 三选一增益 + 技能点 → 更高效率 → 下一张账单
       → 无法支付 → 破产结算 → 饰品永久成长 → 新轮回
```

### 4.2 官方公开内容

- 普通、游客、木质、彩糖、狂奔等差异化储蓄罐；游客类型恢复体力。
- 锤具至少区分伤害、攻速、暴击率、暴击倍率、体力消耗、命中范围。
- 账单支付后出现增益选择；技能树含握力、咖啡、健身、手腕、幸运、落石、电锤等方向。
- 正式版加入破产轮回、戒指/手环、商店装置、更多储蓄罐与锤具、下注和结局。
- Demo v0.2.7 的公开更新曾扩大 Ultra Crit 锤范围、提高 Toy Hammer 攻速，说明“范围”和“攻速”是持续调优的关键参数。

## 7. 视觉还原策略与知识产权边界

- 16:9 暖暗色俯视桌面、木纹、台灯方向光、计算器、账单纸张和杯子。

以下全部重新设计：游戏标题、肥羊造型、配色细节、桌面模型、图标、UI 布局细节、全部文案、音效、粒子、代码和数值扩展。没有使用官方媒体包图片作为运行素材。这样既保留玩家能识别的“桌面砸罐 + 账单压力”节奏，也避免重复开发者曾公开遭遇的直接换皮/重编译问题。

## 10. 后续商业化建议

1. 先做 20–30 名玩家的首轮遥测：首次付款时间、首轮破产点、各锤购买率、三选一选择率。
2. 把 `$750` 房租作为 15–25 分钟锚点，而不是照搬闭源表；依据实测调乘区。
3. 为高倍率利息设置递减或稀有度保护，避免主动输入过早失去意义。
4. 商业发布前接 Steamworks、云存档、成就、隐私说明、代码签名和原创商店素材。
5. 不用原作名称、截图、模型或近似商标营销；明确“原创主动增量肥羊游戏”。
