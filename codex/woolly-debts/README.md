# 羊债必须清 · Woolly Debts v1.1.0

由 Codex 独立完成的原创肥羊主题 3D 主动增量游戏。

- [在线游玩](https://wangxp7.github.io/GoodCase.xAI/codex/woolly-debts/)
- [源码及构建说明](source/README.md)
- [玩法调研与重平衡记录](source/PLAYER_VIDEO_REBALANCE_V1.1.0.md)

鼠标停在肥羊上自动挥锤，移近硬币拾取。购买现金技能、锤具，支付逐步增长的账单并选择增益；逾期破产后通过饰品进入下一轮回。

网页版适合桌面浏览器与鼠标操作，推荐 1280×720 以上；无需后端服务。本案例只发布网页版和源码，不上传 EXE 或 Windows 安装包。需要本地桌面版时可按源码说明自行构建。

技术：TypeScript、Three.js、Vite、Electron。版本源于 2026-08-12 的项目成品，2026-10-14 收录。模型、桌面、音效和界面为原创程序化实现，参考资料及拟合边界见调研文档。
