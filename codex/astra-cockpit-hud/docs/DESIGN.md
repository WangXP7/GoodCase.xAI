# ASTRA HUD · 设计规范 V1.0

## 设计方向

面向远航探索船的任务驾驶舱。宽幅视窗保留行星地平线，主要飞行数据悬浮在视野两侧；舰体、雷达与任务操作落在周边仪表。避免把仪表做成营销页或大量圆角卡片。

## 色彩

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--bg` | `#050B10` | 深空基础底色 |
| `--text` | `#C4DEE2` | 正文与仪表标题 |
| `--bright` | `#E2F9F8` | 主要读数与选中状态 |
| `--muted` | `#6C909C` | 英文副标题、辅助刻度 |
| `--cyan` | `#85DCE2` | 正常状态、雷达、护盾和引擎 |
| `--amber` | `#E4B077` | 导航目标、未知信号、武器通道 |

## 字体与边框

- 中文使用 Segoe UI / Microsoft YaHei；数值和英文使用本机 Bahnschrift / Consolas。
- 主速度使用大字号窄体数值，形成远距离可读的仪表层级。
- 面板为 1 像素冷灰蓝线框，四角局部加强，避免大面积辉光。
- 英文小字用于第二层仪表注释，实际操作使用中文标签。
- 能源条为离散分段，目标准星为双层圆弧、刻度和琥珀菱形。

## 组件清单

1. 顶栏：舰载品牌、星区定位、系统状态、UTC 时间。
2. 模式栏：飞行、导航、战术、工程，支持 Tab 语义与方向键。
3. 舰船完整度：结构示意、护盾、船体、燃料。
4. 推进控制：油门滑杆、速度和核心输出联动、自动驾驶开关。
5. 飞行视窗：罗盘、速度、高度、瞄准环、航点、俯仰刻度与重力。
6. 雷达：四层量程环、扫描波束、联系人与实时选中标记。
7. 航线图：局部轨道示意、当前位置、三个可选目的地。
8. 战术视图：目标识别、锁定与武器待机状态。
9. 工程视图：反应堆、输出、温度、冷却效率、诊断反馈。
10. 能源分配：引擎、护盾、武器通道和三个预设。
11. 跃迁控制：航点、距离、充能进度、跳跃完成与耗油反馈。
12. 通讯日志：最近三个事件、通道信息。
13. 状态栏：快捷键、动态效果、音效和全屏控制。

## 状态规则

- 蓝色表示正常和已选中，琥珀色表示任务目标或需要注意的信息。
- 雷达扫描期间禁用重复扫描，跃迁期间锁定航点和自动驾驶开关。
- 跃迁到达后保持已抵达状态，不自动恢复距离；选择不同航点开始新行程。
- 武器就绪只改变模拟防御状态，不自动开火，也不减少舰体或护盾。
- 动态效果可随时关闭；关闭后雷达仍保留静态信息和全部控制功能。
- 系统日志仅反映本地模拟交互，不进行对外发送。

## 响应式规则

| 宽度 | 布局 |
| --- | --- |
| 1700px 以上 | 宽幅三栏驾驶舱，扩大主准星和侧栏 |
| 1001–1699px | 左仪表 / 主视窗 / 右雷达，底部三控制台 |
| 651–1000px | 主视窗和左仪表并排；雷达移到下一行 |
| 360–650px | 主视窗优先，侧仪表、雷达与控制台向下排列 |

## 资源说明

背景是生成式原创位图。标志和飞船结构示意为项目内可编辑矢量，雷达、轨道、星点为 Canvas 绘制。没有远程运行依赖。界面组成没有使用任何现成游戏 HUD 的图形或品牌。
