## 预览服务修复

用户反馈 `127.0.0.1:4187` 返回 `ERR_CONNECTION_REFUSED`。现场检查没有发现该端口的监听服务，原临时预览进程已经结束。

新增 `启动本地预览.cmd` 和 `tools/start-preview.cjs`，以独立、隐藏后台进程启动预览服务；添加项目身份检查，重复启动时复用同一项目的服务，端口属于其他应用时不终止对方进程。更新 README 的启动和恢复说明。原离线入口继续可用。

验证结果：启动命令退出后服务仍可访问；重复启动复用同一 PID；主页面与行星背景均返回 HTTP 200。在应用内浏览器重新打开本地网址，实际确认 ASTRA 标题、HUD 画面和控件正常显示，并保留恢复后的预览标签页。
