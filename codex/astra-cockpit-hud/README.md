# ASTRA · 科幻飞船驾驶舱 HUD

一套原创深空探索飞船 HUD 交互原型。采用冰蓝仪表、琥珀色导航标记、半透明仪表面板和电影感行星背景，提供四种工作模式。

## 启动

双击 `启动驾驶舱.cmd`，或直接使用 Chrome / Edge 打开 `index.html`。无需安装、联网或构建。

需要使用 `http://127.0.0.1:4187/` 预览时，双击 `启动本地预览.cmd`。它会启动独立后台服务后打开浏览器；再次执行会复用已有服务。此方式需要本机 Node.js，缺少 Node.js 时自动打开离线版本。电脑重启后再运行该入口即可恢复预览。

如果浏览器提示 `ERR_CONNECTION_REFUSED`，说明本地预览服务未运行，重新执行 `启动本地预览.cmd` 即可；离线入口不依赖预览服务。

推荐显示尺寸：1440 × 1000、1920 × 1080；也支持平板和手机。界面根据宽度重新排列，小屏可纵向滚动。可通过右下角全屏按钮或 `F` 键进入全屏。

本项目是本地交互模拟，所有舰船数据、航点和扫描结果均为虚构演示数据。刷新页面会重置状态。

## 功能

| 模块 | 可操作内容 |
| --- | --- |
| 飞行概览 | 航向、速度、高度、目标准星、推进器功率、自动驾驶 |
| 星际导航 | 三个可选航点、轨道示意图、航程同步、完整跃迁流程 |
| 战术扫描 | 三个雷达联系人、目标切换、锁定与解除、武器就绪与待机 |
| 动力工程 | 推进器与输出联动、温度变化、12 项模拟系统诊断 |
| 能源分配 | 均衡、巡航优先、战斗优先，三路分配总和固定为 100% |
| 舰载通讯 | 最近三条操作事件，实时 UTC 时钟 |
| 辅助控制 | 音效开关、动态效果开关、全屏、键盘操作 |

跃迁前必须开启自动驾驶。充能 5 秒、通道穿越约 1.2 秒，完成后燃料减少 4 个百分点，航程归零。选择另一航点后可再次跃迁。近域扫描用时约 2.4 秒，会将未知信号确认为友方勘探探针。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `1` / `2` / `3` / `4` | 切换四种驾驶舱模式 |
| `A` | 自动驾驶开关 |
| `R` | 扫描近域空间 |
| `L` | 战术模式下锁定 / 解除目标 |
| `F` | 全屏 / 退出全屏 |
| `Tab` / `Enter` / `Space` | 聚焦并操作控件 |
| `←` / `→` | 聚焦模式栏时切换模式；聚焦推进滑杆时调整功率 |

## 修改方式

- 更换配色：修改 `styles.css` 开头的 `:root` 变量。
- 更换背景：替换 `assets/deep-space.png`，保留文件名即可。
- 修改航点：编辑 `app.js` 中的 `routes` 数组。
- 修改雷达联系人：编辑 `app.js` 中的 `contacts` 数组。
- 修改能源预设：编辑 `app.js` 中的 `powerLevels`，确保每组之和为 100。
- 所有 HUD 文本、面板、准星和仪表可独立编辑，文字未烧录进背景图。

## 技术与限制

原生 HTML / CSS / JavaScript + SVG / Canvas 2D，不使用 CDN、外部字体或第三方运行库。音效由 Web Audio 即时合成，默认静音。支持系统“减少动态效果”偏好，后台标签页暂停绘制。部分内嵌预览不允许全屏，此时请在独立浏览器中打开。

这是 HUD 设计与交互演示，不含真实飞行物理、武器战斗、外部通讯或服务器功能。
