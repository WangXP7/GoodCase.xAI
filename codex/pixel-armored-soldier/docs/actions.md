## 0. 最高原则

**连贯性高于帧数压缩、姿势夸张、剑光特效和生成速度。**

所有动作必须同时满足：

1. 不跳帧：准备、发力、接触/极值、缓冲、回收五个阶段齐全；
2. 不卡顿：不用无意义重复帧拖时间，单帧不超过 125 ms；
3. 不错位：固定 256×256 画布、75% 填充、100% 角色缩放、根节点 `(128,224)`；
4. 不滑步：承重脚接地点在相邻帧中保持不动；
5. 不瞬移：常规相邻帧躯干中心位移不超过 8 输出像素；
6. 不乱轨：剑尖沿连续圆弧或直线前进，方向反转前必须有极值/缓冲帧；
7. 不漂移：禁止逐帧自动裁边、自动居中或为避免出界而临时缩小角色；
8. 可串接：每个动作第 1 帧和最后 1 帧都回到完全相同的战斗待机基准 `G0`；
9. 先动作后特效：本轮动作帧不生成剑光、粒子、冲击波或运动模糊；
10. 逐帧生成链：每一帧同时参考“批准角色锚点 + 上一帧”，补间帧同时参考前后关键姿势，禁止把各帧当作互不相关的单图生成。

## 1. 全动作共享基准

### 1.1 画布与播放

| 项目 | 固定值 |
|---|---|
| 单帧画布 | 256×256 PNG |
| 逻辑网格 | 64×64，最终 4×最近邻放大 |

| 建议播放基准 | 60 Hz 容器内按 4–6 个刷新周期显示一张绘制帧 |
| 常用帧时长 | 67 ms、83 ms、100 ms；均接近 60 Hz 整数周期 |
| 背景 | 正式帧透明；即梦运动参考使用纯洋红抠像底 `#FF00FF` |

### 1.2 战斗待机基准 G0

- 右向轻微 3/4 侧视；
- 双脚接地，后脚约在 `x=104`，前脚约在 `x=152`；
- 根节点固定 `(128,224)`；
- 躯干中心偏移 `ΔC=(0,0)`；
- 右手握剑，剑尖斜向右下，剑身角度约 `+25°`；
- 左手持盾，盾心约在 `(178,132)`，盾面略朝右前方；
- 三格视窗灯、三枚胸甲铆钉、三枚盾面铆钉均清晰可见。

角度约定：`0°` 表示剑尖水平指向画面右侧，`-90°` 表示剑尖向上，`+90°` 表示剑尖向下。

### 1.3 相邻帧硬阈值

| 检查项 | 合格阈值 |
|---|---|
| 根节点位移 | 必须为 0 px |
| 承重脚接地点位移 | 必须为 0 逻辑像素 |
| 常规躯干中心位移 | 每帧 ≤ 8 输出像素 |
| 头盔宽高变化 | 0 逻辑像素；仅允许姿态旋转造成可见面变化 |
| 剑、盾长度变化 | 0 逻辑像素 |
| 躯干核心遮罩相邻帧重合率 | 建议 ≥ 80% |
| 全身遮罩相邻帧重合率 | 建议 ≥ 55%；突刺极值帧可单独复核 |
| 完全重复画面 | 禁止；命中停顿用帧时长表达，不复制同一帧 |
