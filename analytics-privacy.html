访问统计说明

为了解案例的使用情况，本站统计页面访问时间、案例路径、前台可见停留时长、完整公网 IP、大致地区、浏览器信息及来源页面。使用随机访客编号与会话编号，不自动获取真实姓名、邮箱或 GitHub 身份。

访问记录存储在站点管理者的独立 Cloudflare 数据库中，当前设置为长期保留，不自动过期。完整 IP 与访问明细不在公开网页或公开仓库展示，只能经管理员身份验证后读取。日报通过邮件服务投递给管理者，邮件仅含汇总。

停留时长是估算值：页面切到后台或浏览器失去焦点时暂停累计。断网、浏览器限制和拦截工具可能造成漏记。来源 URL 的查询参数与片段不会保留。

你可以停止此浏览器之后的统计。该设置使用本地存储保存；清除浏览器数据后需要重新设置。浏览器启用 Do Not Track 或 Global Privacy Control 时，本统计脚本会停止上报。停止统计不会自动删除已记录的历史数据。
