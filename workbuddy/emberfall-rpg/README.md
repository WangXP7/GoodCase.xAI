# 余烬深渊 · Emberfall

> **WorkBuddy + DeepSeek-V4.1-Flash**

一个使用 Three.js 制作的**球形开放世界 3D 动作 RPG 原型**。地图是一个可以朝任意方向
持续探索的球体，角色走到哪儿，地形与生态就在哪儿生成。除 4 个 Blender 角色模型外，
场景纹理与特效全部由代码生成。

## 玩法

- 点击地面移动，点击敌人锁定并自动释放火矢
- 四类程序化生态区域，区域净化后会在 24–58 秒内随机重生
- 近战爬兽与蛮兵、魔法远程幽魂、物理远程猎手，以及区域霸主
- BOSS 交替释放大范围物理震击与近乎全屏的魔法风暴
- 普通、稀有、史诗、传说四档随机装备掉落，装备等级随区域威胁成长
- 敌人生命、伤害、防御与数量随探索距离、净化次数及玩家等级成长
- 等级、经验、余烬、药剂、装备与球面坐标自动存档
- 单局排行榜与累计积分榜（在线提交失败时自动回退到本机本地榜）

## 操作

| 按键 | 功能 |
|---|---|
| 点击地面 | 移动 |
| 点击敌人 | 锁定并自动释放火矢 |
| `W` `A` `S` `D` | 步行移动 |
| `Shift` + WASD | 奔跑（点击远处时也会自动奔跑） |
| `空格` | 攻击最近的敌人 |
| `Q` | 吟唱余烬震环，范围伤害与击退 |
| `E` | 裂隙步，向鼠标方向闪现 |
| `F` | 吟唱铜卫结界，获得护盾 |
| `R` | 使用疗愈药剂 |
| `Esc` | 暂停 |
| 右上角 ♫ | 开 / 关音乐与音效 |

## 运行

本目录是 **Vite 生产构建产物**，`index.html` 内的资源引用均为相对路径（`./assets/…`），
直接放在任意 HTTP 服务的子目录下即可运行：

```bash
python -m http.server 8000     # 浏览器访问 http://127.0.0.1:8000/
```

源码仓库：<https://github.com/WangXP7/emberfall-rpg>

## 已知限制

- 排行榜后端（Neon）不在本目录内，线上提交会失败并自动回退到本机本地榜。
- GLB 模型加载失败时会自动回退到程序化模型。
- 首次加载需拉取约 726 KB 的 JS 包。
