# 企鹅生存 · 冰原漂流挑战

> **WorkBuddy + DeepSeek-V4.1-Flash**

Three.js 单文件 **3D 生存小游戏**：操控企鹅在不断漂移的浮冰之间捕鱼、躲避海豹。
冰块会随水流移动，站错位置就会漂出去；分数越高，节奏越快。

## 玩法

| 要素 | 说明 |
|---|---|
| 目标 | 在有限的浮冰之间移动捕鱼得分，尽可能久地活下去 |
| 威胁 | 海豹会追捕企鹅；浮冰本身也会持续漂移 |
| 资源 | 生命（Lives）、分数（Score）、倒计时（Time） |
| 难度 | 简单 / 普通 / 困难三档 |

## 操作

| 按键 | 功能 |
|---|---|
| `←` `→` / `A` `D` | 左右移动 |
| `空格` | 跳跃，用于跨到相邻浮冰 |
| 鼠标 / 触屏 | 开始游戏、重新开始 |

## 实现要点

- **Three.js r160**，通过 importmap 从 `unpkg.com` 加载，单文件自包含（HTML + CSS + 内联 ES Module）。
- **场景全程序化**：海面用分段平面 + `MeshStandardMaterial` 做波动，浮冰是低多边形圆柱体
  并按位置做随机缩放与旋转；企鹅为代码拼装的几何体，无任何模型或贴图文件。
- **雾 + 平行光 + 边缘补光**三层光照，配合 `PCFSoftShadowMap` 让浮冰在水面上有明确投影。
- HUD 与 3D 画布分离，开局前 HUD 隐藏，进入游玩后显示。

## 运行

需要经 HTTP 打开（ES Module + importmap 在 `file://` 下会被 CORS 拦截）：

```bash
cd penguin-survival
python -m http.server 8000     # 浏览器访问 http://127.0.0.1:8000/
```

## 已知限制

- 依赖 unpkg CDN 拉取 Three.js，首次打开需要联网。
- 无存档与排行榜，每次刷新重新开始。
- 触屏仅支持点击开始，未做虚拟摇杆。
