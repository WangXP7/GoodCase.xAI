# 蛇人幸存者 · Serpent Survivors

> **WorkBuddy + Step-5-Preview**

纯割草（Survivors-like）Roguelite 游戏 Demo。俯视角、单张固定战斗地图、10 分钟生存考验。
玩家操控蛇人战士在封闭黑暗废墟中自动攻击、走位躲避、捡经验升级，所有技能真实生效并互相连锁。

## 运行方式

本项目使用 ES Module + importmap 加载本地 Three.js（r160，已 vendored），**必须经 HTTP 服务打开**（`file://` 会被浏览器 CORS 拦截）：

```bash
cd snake-survivors
python -m http.server 8080        # 或任何静态服务器
# 浏览器打开 http://127.0.0.1:8080/index.html
```

零外部资源：无贴图、无模型文件、无 CDN、无音频文件——所有几何体、纹理（Canvas 程序化绘制）、
音效（WebAudio 合成）均在运行时生成。

能量随时间积累（2.4/s）并随击杀增长（1.6/击杀）。

## 四个技能与真实联动

1. **尾击**（自动）：对附近敌人扇形横扫，造成伤害并击退。升级可加范围、加段数、加伤害、附带中毒。
2. **毒瓶**：向最密敌群抛掷，落地生成持续毒液区域——身处其中持续叠毒（掉血）并被**减速**。
3. **诅咒**：以自身为中心的光环，持续削弱范围内敌人——**攻击力 -45%**、**受到伤害 +35%**（易伤放大毒伤）。
4. **蛇人召集**：消耗能量召唤 14 名族人横向冲过全图，接触即高额 burst 伤害 + 击退 + 眩晕。

**联动链**：毒液减速 → 尾击把敌人击退进毒液 → 诅咒放大毒伤 → **同时处于中毒与诅咒的敌人会剧烈爆炸，
对周围造成范围伤害并连锁引爆其他双状态敌人**（强化「剧毒共鸣」可提升爆炸伤害与触发速度）。

## 升级系统

击杀掉落经验结晶（自动磁吸拾取），升级时暂停并三选一随机强化，共 16 种、可叠加：

锐尾（伤害）/ 广尾（范围）/ 连尾（段数）/ 疾尾（冷却）/ 猛毒（毒伤+层数）/ 漫毒（范围+数量）/
存毒（持续+减速）/ 邪咒（范围+易伤）/ 长咒（持续）/ 剧毒共鸣（爆炸）/ 蛇灵庇护（召集）/ 迅捷（移速）/
强体（生命）/ 贪婪（经验）/ 磁吸（拾取）/ 余毒（尾击带毒）。

## 敌人图鉴（蘑菇节肢怪物）

程序化生成：菌盖 + 菌柄 + **3 个喇叭状口器** + **3 对触手手臂** + **3 对节肢腿**，全部 InstancedMesh 渲染。

- **近战小菇**：直扑玩家，接触攻击。
- **音波菇**：保持距离游走，**蓄力时地面出现预警圈**，随后发射精神音波环——提前走位即可躲开。
- **菇王（精英）**：大体型、周期性震地（预警圈先行），高血量高伤害，带 3D 血条。
- **音波嬷嬷（精英）**：三连发音波弹。

敌潮节奏：120s / 300s / 480s 三波精英敌潮，540s 起最终潮汐（刷新率 ×2.6），600s 生存成功。
敌人生命/速度/伤害随时间持续成长（10 分钟时生命约为初始 40 倍）。

## 完整割草循环

自动攻击 → 四面八方持续刷新 → 经验结晶 → 升级三选一 → 技能冷却 → 能量积累 → 精英敌潮 →
伤害数字（普通/毒/诅咒/爆炸/召集分色）→ 击退反馈 → 受击红晕+无敌帧闪烁 → 屏幕震动（召唤/爆炸/受击）→
技能特效（扇刃/毒液着色器/诅咒法阵/族人冲锋尘迹）→ 失败结算 / 10 分钟胜利结算 / 一键重开。

## 验证（三层）

1. **语法**：提取内联 module 脚本 `node --check` 通过。
2. **E2E 断言**（Playwright + 无头 Chromium，`node tools/verify_e2e.mjs`）：**30/30 通过**。
   覆盖：尾击真实伤害与击退、毒液区域/叠毒/DOT/减速（对照实验）、诅咒易伤与降攻、
   双状态连锁爆炸、召集灭敌与震屏、三选一升级流、远程预警先于射击、精英潮刷新、
   敌人成长曲线、伤害数字、死亡重开完整重置、10 分钟胜利、全程无 JS 报错。
3. **截图**：`shots/01..09` 覆盖菜单、战斗、毒+诅咒联动、召集、升级卡、精英潮、失败、胜利、角色特写。

技术要点：敌人/部件按类型 InstancedMesh 合批（每类型 4 个 draw call），instanceColor 实现
中毒绿/诅咒紫/双状态橙/受击白实时染色；蛇尾为 10 节世界坐标跟随链；空间哈希网格做敌人分离；
毒液/法阵/粒子均为自定义着色器；相机为正交俯视 + 创伤值震屏模型。
