# 天坛祈年殿 · 三重檐琉璃大殿

> **WorkBuddy + Step-5-Preview**

按真实建筑数据全程序化复原的北京天坛祈年殿（Hall of Prayer for Good Harvests）：
直径 32.72 米、总高 38.2 米，三重檐蓝色琉璃瓦逐层收缩作伞状，鎏金宝顶收头。
无任何外部模型与贴图素材，全部几何体、纹理（Canvas 程序化绘制）均在运行时生成。

**总耗时约 1 小时 5 分钟。**

## 建筑还原要点

- **祈谷坛**：三层汉白玉圆台基高 6 米，圭角、栏板与望柱俱全，东西南北四向出陛、每层九级踏跺
- **28 根楠木柱**：4 根龙井柱（高 19.2 米，螺旋管沥粉鎏金蟠龙，象征四季）+ 12 金柱（十二月）+ 12 檐柱（十二时辰）
- **三重檐**：蓝色琉璃瓦、反宇曲线与檐口起翘、勾头滴水、飞椽檐檩；下两层单翘重昂、上层重翘重昂斗拱
- **彩画**：龙凤和玺彩画额枋（石青枋心 + 石绿藻头 + 金线旋花）
- **细节**：龙凤藻井与顶心明镜、南面三间隔扇门（明间门钉、上棂心下裙板）、中檐与上檐之间「祈年殿」金匾、檐下宫灯
- **环境**：方砖地面、神道、坛墙与古柏

## 交互

| 操作 | 方式 |
| --- | --- |
| 旋转 / 缩放 | 拖拽 / 滚轮 · 双指旋转与缩放（触屏） |
| 昼夜切换 | 「切换夜晚」按钮（平滑过渡：星空月色、隔扇窗光、宫灯与宝顶自发光） |
| 自动旋转 / 重置视角 | 对应按钮 |

响应式多端兼容（桌面 / 平板 / 手机），昼、夜两套光照均可自由观看。

## 运行方式

单文件 + importmap 经 CDN 加载 Three.js r160，双击直接打开或任意静态服务器均可；
亦可从画廊案例查看器（`case.html`）进入。

## 验证

提取内联模块脚本 `node --check` 通过；Playwright 无头 Chromium 冒烟（无 JS 报错、
画布按视口尺寸渲染、昼夜切换生效），白天 / 夜晚 / 俯视 / 匾额 / 宝顶 / 檐口 / 移动端
共 14 张截图人工判读，迭代三轮后交付。
