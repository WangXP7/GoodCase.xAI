# 符文战线 · 三路弹幕塔防（可玩 Demo v0.3）

> **WorkBuddy + DeepSeek-V4.1-Flash**

竖版三路 · 1188 格 · 5 英雄 6 点位 · 海克斯三选一 · 单机 1v1

制作耗时约 45 分钟（单会话完成：先出 82K 字 GDD，再落地可玩 Demo v0.3，附无头 8 局模拟与全流程截图）。

## 打开

双击 `index.html`，浏览器直接跑（Chromium / Safari / 微信内置浏览器均可）。
零外部资源，全程序化绘制，无网络请求。

## 一局是什么样

```
部署(20s) → 点「开始战斗」→ 海克斯 #1 → 战斗 90s → 结算
                              ↑ Lv7 / Lv11 / Lv15 各再给一次
```

- **战场**：3 条路，每路 **11 列 × 36 行 = 396 格**，三路共 **1188 格**
- **格子**：有血、有归属色。你的子弹把敌方格打碎 → 翻成己方色；对方也在打你的
- **推进**：只能打「后方相邻是己方」的格 —— 战线必须连续，不能跳岛
- **点位**：每路 2 个固定点位（前哨 / 主阵），共 6 个，**5 个英雄，留 1 个空位**
- **前哨位**：子弹飞行距离短、会替后排挡弹，最容易死
- **打穿一路**（该路 198 格全变己方）→ 子弹开始打敌方水晶 → 水晶归零即胜

## 操作

| 操作 | 位置 |
|---|---|
| 开始战斗 | 部署界面的金色按钮 |
| 选海克斯 | 弹出三张卡，点任意一张 |
| 切换英雄 | 底部 5 张英雄卡 |
| 放大招 | 金色大招按钮（对该路前沿造成大量伤害） |
| 自动大招 | 大招按钮右侧「自动」开关 |
| 买装备 | 底部 3 张装备卡（金币够才可点） |

## 三条 build 线（当前可玩）

| 线 | 做法 | 效果 |
|---|---|---|
| 攻速弹幕 | 拿「弹幕扩充 / 无尽弹幕」+ 疾射火炮 | 单路弹道铺满，格子成片碎 |
| 技能爆发 | 拿「奥术洪流 / 双施法」+ 灭世者之帽 | 拉克丝穿透高伤，大招清一整排 |
| 毒+金币 | 拿「瘟疫 / 商业帝国」+ 贪婪之刃 | 毒伤叠层，滚出装备优势 |
