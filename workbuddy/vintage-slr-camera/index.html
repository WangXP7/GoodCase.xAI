03技术要点

全部由脚本生成，无任何外部资产。以下几条是这轮里真正决定成败的地方。

  • Eevee 玻璃必须用 DITHERED：use_raytrace_refraction 打开后能透过前镜片看到内部折射畸变；一旦改成 BLENDED，玻璃立刻退化成一块平板灰。
  • 「镜片像塑料灰球」的根因不是折射，而是环境没有结构：给 World 加一段 Generated.Z → ColorRamp 的摄影棚梯度（顶部亮带 + 中灰地平线 + 下半球不能纯黑），金属与玻璃才会真正「活」起来。
  • Eevee 里做「平色背景 + 接触阴影」的正解是地板材质用 MixShader(Emission(#E8E8E8), Diffuse)：恒定发光保证背景绝对平整无渐变，漫反射项被主体遮挡后自然形成柔和的接触阴影。
  • 曝光与背景色靠回读像素校准，而不是目测：bpy.data.images.load(png).pixels 读出的是线性值，#E8E8E8 对应线性 0.8079，采样四角比对后调发光强度即可锁定。
  • 滚花是真几何：对焦环、光圈环、快门速度盘、ASA 盘、卷片钮的齿全是 knurl() 逐齿生成的梯形齿廓星形截面环，不是法线贴图，侧光下会走出真实的高光齿列。
  • Blender 5.x 的 API 坑：倒角修改器是 use_clamp_overlap（不是 clamp_overlap）；按角度平滑用 bpy.ops.object.shade_auto_smooth()；Principled 的透射输入名已改为 Transmission Weight。
  • 手写网格后必须 recalc_face_normals，否则玻璃法线翻转会直接毁掉折射。
