## [0.1.0] · 测试版 · 2026-09-10

首个**可玩测试版**。零外部资产（图集与音频全部程序化生成）、零构建依赖，
单文件产物可直接双击运行。

### 新增 · 玩法

- **主循环**：横版侧视（深海 → 沙滩），捕食游客、规避追兵。
- **副循环**：冲浪区收集物 8 件（瓶子 10 / 星星 20 / 圆环 30），
  **仅 `surf` 状态可拾取**，拾取后立即补充以维持池恒为 8。
- **Bank or Push**：押注—结算原子性。中途死亡 → 未兑现押注**全损**；
  Bank 前置条件 = 深海 + 无锁定系绳 + 非受控状态。
- **DECOY BREACH**：冲刺穿出水面制造诱饵；**有锁定系绳的单位免疫**
  （驳回演出：瞥见 → 驳回 → 恢复，系绳纹丝不动）。
- **搁浅 QTE**：连打脱困，失败则计入全损。
- **ALARM 通缉系统**：三段档位 + 迟滞带（防抖动）。

### 新增 · 表现

- **程序化图集**（512×320，运行时烘焙）：鲨鱼、游客、救生员、摩托艇、
  直升机、收集物、UI 元素，全部逐像素绘制。
- **四层动态音乐** + 程序化音效表（WebAudio 合成，零音频文件）。
- **后期处理**：CRT 扫描线、有序抖动、去饱和、色差。

### 修复 · 发布阻断级

- **玩家用鼠标点不动任何菜单按钮** —— `input.js` 在 `pointerdown` 上无条件
  `preventDefault()`，抑制了后续原生 `click` 事件。仅键盘 Enter 可绕过。
  → 新增 `onUI()` 判定：指针落在 UI 上时放行原生事件；
  另加 `typingUI()` 放行聚焦控件的原生键盘行为（空格可激活聚焦按钮）。
- **按住空格切出窗口，切回来凭空冲刺 / 误重开** —— `onBlur()` 只清了方向键。
  → 一并清理 `dashFlag / pauseFlag / muteFlag / confirmFlag / taps`。
- **结算页损失恒显示 −0** —— 先清零 `pendingScore` 再读它。
  → 改为先记账（`lostScore / lostCount`）再清零。
- **深海区鲨鱼近乎隐形** —— 鲨鱼体色误用深藏青（灰度 17.4%），
  比深海背景（灰度 24.7%）**还暗**。
  → 按美术圣经 §4.1.3 改为背侧 `#4A5A6E`→`#6E7C8C`、腹侧 `#C7CFD8`→`#F2F5F8`，
  并补 3px `#0A0E17` 外描边（验收项 P-06）。实测前景/背景明度差 **73.4pp**。
- **硬红线① 被突破：可达 3 次/秒屏闪** —— 一次捕食跨两个 ALARM 档位时，
  档位闪无最小间隔，0.083s 内连闪 3 次（项目红线 ≤2Hz）。
  → 在 `triggerFlash()` 加统一闸门 `C.FLASH_GAP = 0.51s`
  （任意 1s 窗至多 2 闪；**视觉限频不压制音效与文字提示**）。
- **`TL.Pickups` 未定义导致启动即崩** —— `game.js` 引用早于模块落地。
  → 在 `entities.js` 补齐实现。
- **两个 404**（`/favicon.ico`）→ 内联空 favicon（`data:,`）。

### 新增 · 设置与可访问性

- 5 个正交开关可独立关闭：震屏 / 闪烁 / 扫描线抖动 / CRT / 粒子密度。
- **背景音乐独立开关**（此前该开关是空实现：`setMusicEnabled` 未真正挂起总线）。
- 色盲模式（血红→电光蓝、琥珀→金）、`prefers-reduced-motion` 自动降级。
- 暂停时挂起整个 `AudioContext`，恢复不会积压音符冲出。

### 变更

- 图集尺寸 512×256 → **512×320**（为鲨鱼外描边留白）。
- 鲨鱼图集矩形 84×40 → **100×56**（本体仍 84×40，四周 8 art px 为描边余量）；
  渲染侧按 `SHARK.DRAW_PAD` 同步补偿，**本体视觉尺寸 168×80 design px 保持不变**。
- 页面标题 → 「潮线 TIDELINE · 测试版 v0.1.0」。
