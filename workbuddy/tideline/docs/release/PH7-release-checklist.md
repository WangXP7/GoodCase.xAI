## 3. 硬红线（不可协商）

| # | 红线 | 要求 | 实测 | 判定 |
|---|---|---|---|---|
| 3.1 | 全项目闪烁 ≤2Hz | 严于 WCAG 2.3.1 的 <3Hz | 可达场景 1s 窗峰值 = **1** | ✅ |
| 3.2 | 禁硬 on/off 切换 | 一律呼吸式渐变 | `U.breath()` 全员 f ≤ 2；shader 时间量化 1.000Hz | ✅ |
| 3.3 | 5 个正交开关可独立关闭 | 震屏/闪烁/抖动/CRT/粒子 | 浏览器实测逐个生效 | ✅ |
| 3.4 | 颜色永不作为唯一信息通道 | 每处颜色信息 ≥2 个非颜色通道 | ALARM 三重编码：条（长度）+ 刻度形状 + 音效 | ✅ |
| 3.5 | 血红 / 洋红靠形态分离 | 一动一静 | 洋红=径向运动粒子；血红=静态填充/条/描边 | ✅ |
| 3.6 | 视觉限频不得削减信息 | 音效与文字提示不受限频影响 | `FLASH_GAP` 只拦视觉，`tierUp` 音与 toast 照播 | ✅ |
