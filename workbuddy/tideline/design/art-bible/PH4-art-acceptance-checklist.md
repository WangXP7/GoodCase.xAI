## 1. 像素规范性

### 1.1 🔴 阻断项

| # | 检查项 | 判定方法 | 通过标准 |
|---|---|---|---|
| **P-01** | **无抗锯齿柔边** | 放大 400% 目视；或用脚本检测颜色种类数 | 任意两个相邻像素之间**不存在中间色**。边缘像素必须属于调色板 |
| **P-02** | **色板内取色** | 调色板取证脚本（§7.1） | 表外颜色数 = **0** |
| **P-03** | **无渐变填充** | 目视 + 脚本检测水平/垂直渐变 | 明暗过渡必须是**2–3 级硬边色阶**，不得连续渐变 |
| **P-04** | **无半透明像素**（实体 sprite） | 检查 PNG 是否含 alpha=1~254 的像素 | **实体 sprite：alpha 只能为 0 或 255** |
| **P-05** | **无径向渐变光晕 / 外发光 / 模糊** | 目视 | 需要"发光"时必须用 **1px 硬边描边**或色阶环 |
| **P-06** | **描边 ≥2px，主角 3px** | 量测 | 鲨鱼描边 **3px** `#0A0E17`；其余资产 ≥2px |
| **P-07** | **整数倍缩放** | 检查导出尺寸 / 源尺寸 | 缩放倍数必须为整数（1× / 2× / 3×） |
| **P-08** | **禁止非整数倍旋转生成** | 询问生产方制作方式 | `surf` 的 −65° 侧身姿态**必须手绘**，不得由正向帧旋转生成 |

### 1.2 🟡 警告项（不阻断，需记录）

| # | 检查项 | 说明 |
|---|---|---|
| P-09 | 高饱和色面积占比 | 单资产内索引 12/13/14 合计 ≤ 该资产的 30%（全屏 ≤5% 由 §5 的组合测试兜底） |
| P-10 | 环境资产去饱和 | 全部 `env_*` 仅用索引 00/01/03/06/07/08（§5.3.4） |
| P-11 | 暗部唯一黑 | 深色一律 `#0A0E17`，不得另发明暗更深的黑 |

### 1.3 常见失败模式（给原画的对照）

| ❌ 错误 | ✅ 正确做法 |
|---|---|
| 用喷枪/柔边画笔做阴影 | 用**硬边多边形**分 2–3 级色阶 |
| 用 alpha 淡出做"柔和感" | 用**有序抖动**（§3.6 提供 4 张 8×8 图案） |
| 高斯模糊做发光 | 用 **1px 硬边描边**或**色阶环** |
| 旋转 30° 得到斜向姿态 | **手绘**。旋转必糊 |
| 直接照搬参考图的彩色海滩配色 | 环境 **100% 去饱和**，只有可交互物保留高饱和 |

## 2. 动画帧数与节奏

### 2.1 🔴 阻断项

| # | 检查项 | 判定方法 | 通过标准 |
|---|---|---|---|
| **A-01** | **帧数符合清单** | 对照 `PH4-entity-inventory.md` §3 | 逐资产帧数**完全一致**，少一帧即退回 |
| **A-02** | **帧率符合清单** | 检查元数据 / 播放实测 | 逐资产帧率**完全一致** |
| **A-03** | **角色主体锁定 12fps** | 实测 | `idle` / `swim` / `carry` / `beached` 等主体动画 = **12fps**（§9.2） |
| **A-04** | **冲击类 20–24fps** | 实测 | `dash` 24fps · `bite` 20fps · `hurt` 20fps · `thrash` 20fps |
| **A-05** | **循环动画首尾可衔接** | 首尾帧并排播放 | 循环回跳时**无跳变、无抖动** |
| **A-06** | **相位关系正确** | 播放实测 | 鲨鱼尾鳍相位**滞后身部 2 帧**（§4.1.5） |
| **A-07** | **位移量化到像素网格** | 逐帧导出坐标检查 | 所有位移为**整数 px**（2px 步进或整数倍），**禁止亚像素插值** |

### 2.2 🟡 警告项

| # | 检查项 | 说明 |
|---|---|---|
| A-08 | 缩放/旋转允许缓动 | 位移**禁止**缓动，`ease-out` 仅可用于缩放/旋转（§6.7） |
| A-09 | 定格节奏 | 12fps 的"顿挫感"是设计意图，不要为了"顺滑"加中间帧 |
| A-10 | 一次性动画不留尾帧 | `bite`/`thrash`/`breach`/`hurt` 播完立即衔接下一状态，不得停在末帧 |

### 2.3 关键动画的专项判定

| 动画 | 必须能读出什么 | 失败判据 |
|---|---|---|
| **`carry`** | ① 负重感（下沉 6px / 尾摆 −30% / 头仰 8°）② 游客四肢高频抖动 | 看不出负重 ／ 抖动被 CRT 吃掉 |
| **`beached`** | ① 侧躺 −8° ② 尾鳍**一下一下**拍打（每 2 帧一次）③ 眼睛是"茫然"不是"痛苦" | 尾鳍连续摆动（失去节拍）／ 表情变痛苦 |
| **`surf`** | ① 侧身 −65° ② 与浪线严丝合缝贴合 | 边缘糊 ／ 与浪线有缝隙 |
| **`panic`（游客）** | 手忙脚乱的**滑稽**，不是受苦 | 出现流泪 / 五官扭曲 / 求饶手势 |
| **`breach`** | 旋转 45°→0°，全游戏最爽一帧 | 旋转过程糊 ／ 水花不出 |

## 5. 可访问性校验

> ### 总原则：**颜色永不作为唯一信息通道。**
> 本清单的每一条颜色规则，都必须配一个**不依赖色觉的冗余通道**。

### 5.1 🔴 阻断项

| # | 检查项 | 判定方法 | 通过标准 |
|---|---|---|---|
| **C-01** | **灰度可辨** | 全屏去色截图，交 5 名未参与开发者 | ≥4/5 能读出该信息 |
| **C-02** | **颜色非唯一通道** | 逐条对照美术圣经 §9.8 ④ 表 | 每处颜色信息都有 ≥2 个非颜色通道 |
| **C-03** | **血红/洋红靠形态分离** | 并排播放灰度版 | 洋红 = **径向运动粒子**（动）；血红 = **静态填充/条/描边**（静） |
| **C-04** | **血红/洋红靠位置分离** | 逐帧检查 | 洋红**只**出现在鲨鱼嘴部/捕食点；血红**只**出现在 HUD/屏幕边缘/实体配色 |
| **C-05** | **威胁等级三重冗余** | 对照 §4.4 | 颜色 + **尺寸**（32→320px）+ **呼吸频率**（0→2Hz） |
| **C-06** | **稀有度四重冗余** | 对照 §7.2 | 颜色 + **尺寸**（16→28px）+ **光晕** + **粒子量**（3→20） |
| **C-07** | **ALARM 三级梯度亮度单调** | 去色亮度实测 | 炽白 90% → 琥珀 40% → 血红 25%，**单调递减** |

| **C-09** | **实体与背景明度差 ≥40%** | 分区去色实测 | 深海 8% / 浅滩 28% / 冲浪区 55% / 沙滩 82%，实体在各区均需拉开 ≥40% |

## 6. 光敏安全校验

> ### 🔴 硬红线：**闪烁 ≤2Hz，全项目禁用硬 on/off 切换，一律呼吸式渐变。**

### 6.1 🔴 阻断项

| # | 检查项 | 判定方法 | 通过标准 |
|---|---|---|---|
| **F-01** | **无硬 on/off 切换** | 代码搜索 + 逐帧检查 | **不存在** `alpha` 在 {0,1} 之间跳变的任何元素。一律 `alpha = a + b·sin(2π·f·t)` |
| **F-02** | **频率 ≤2Hz** | 代码搜索 `Math.sin(2 * Math.PI * f` 核验 f 值 | 全局 **f ≤ 2**。T4 上限 2Hz，系绳 1Hz，呼吸 0.7Hz |
| **F-03** | **无全屏高对比闪烁** | 逐帧检查 | 不存在白/黑 或 红/黑 交替 |
| **F-04** | **五个开关两两正交** | 组合测试（2⁵ = 32 种组合） | 任意组合不崩溃，**且不出现无反馈的"死区"** |
| **F-05** | **关闭震屏后仍有打击感** | 手动测试 | 关闭震屏 → 自动启用「顿帧 + 色闪」补偿 |
| **F-06** | **首次启动提示存在且不闪烁** | 手动测试 | 提示出现一次；**提示本身不得闪烁** |
| **F-07** | **`prefers-reduced-motion` 生效** | 系统设置开启后启动 | 震屏 OFF + 闪烁 OFF + 扫描线静态 + 粒子 50% |

### 6.2 五个正交开关（必须独立可关）

| # | 开关 | 默认 | 关闭后的替代反馈 | 存储键 |
|---|---|---|---|---|
| 1 | **屏幕震动** | 开 | 以「顿帧 + 色闪」替代 | `opt.shake` |
| 2 | **屏幕闪烁** | 开 | 所有闪烁改为**常亮** | `opt.flash` |
| 3 | **扫描线抖动** | 开 | 扫描线保持**静态** | `opt.jitter` |
| 4 | **CRT 后期** | FULL/LITE | → OFF | `opt.crt` |
| 5 | **粒子密度** | 100% | 100% / 50% / **0%** | `opt.particles` |

> **⚠️ 关于「受击闪白 / 色闪」为什么允许整帧切换**：
> 这两者是**单次 1–2 帧的一次性事件**，不是**周期性闪烁**。光敏性风险的诱因是**重复的频率**，不是单次的亮度变化。
> **但它们仍受 §6.1 F-04 约束**：关闭「屏幕闪烁」开关后，两者必须完全关闭。

## 8. 内容红线（黑色喜剧 · 全年龄网页分发）

> ### 一句话判断标准：
> ## **如果这一帧被截图发出去，配文会是笑话还是举报？——必须是笑话。**

### 8.1 🔴 阻断项

| # | 禁止 | 原因 |
|---|---|---|
| **B-01** | **血液、伤口、淤青、断肢** | 滑向写实即滑向残忍，喜剧立刻失效；且违反全年龄分发合规 |
| **B-02** | **痛苦扭曲的五官、流泪、求饶手势** | 让玩家从"好笑"切换到"同情"，情绪断裂 |
| **B-03** | **死亡特写**（咀嚼、撕咬、吞咽） | 概念文档 §3.3 情绪禁区：基调是《大白鲨》式的暗示与黑色幽默，不是 B 级片 |
| **B-04** | **把鲨鱼画成虐待狂**（狰狞、享受痛苦） | 鲨鱼是"**明目张胆的坏蛋**"，不是施虐者。它应该**贪吃、得意、滑稽**，不应该邪恶 |
| **B-05** | **被叼游客的受伤表现** | 不出现淤青、伤痕、血迹。**他们只是被一只鲨鱼叼着，仅此而已** |
| **B-06** | **游客剪影不可读** | 剪影**必须包含"举起的手臂"或"泳圈"**（人的通用识别符）。玩家需在 0.3 秒内判断"可捕食目标" vs "障碍物" |

### 8.2 三条正面准则（要做什么）

1. **夸张的物理性**——大字型腾空、高频抖动、滑稽的翻滚、被抛出时的缓慢旋转。**喜剧来自物理，不来自表情**（8×8px 的脸做不出微表情）
2. **对比制造笑点**——凶猛的鲨鱼 vs 慌张的小人；肃杀的追捕 vs 沙滩上晒太阳的游客；紧张的 QTE vs 一圈静止围观的剪影。**笑点在"不对等"里**
3. **冷漠的环境**——太阳照常微笑（甚至在大笑），云照常飘，海照常蓝。**世界对玩家的暴行毫无反应**，这种"无所谓"本身就是冷幽默

### 8.3 鲨鱼表情的允许范围

| ✅ 允许 | ❌ 禁止 |
|---|---|
| 贪婪（觊觎：半闭眼 + 嘴角下垂） | 狰狞 |
| 得意（弯月眼 + 微笑弧） | 享受痛苦 |
| 滑稽（茫然 "O O" 眼 + 侧躺） | 邪恶 |
| 兴奋（瞪大眼 + 全露齿） | 施虐的快感 |
