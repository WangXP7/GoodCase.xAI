## 1. 系统概述

**一句话职责**：把玩家的**贪婪程度**翻译成**屏幕上的追兵数量与质量**，并给出唯一的、连续的压力刻度。

**在核心循环中的位置**：ALARM 是贯穿全循环的**压力轴**。它不产出分数，但它决定产出的**成本**——捕食 +20（🔒）、暴露每秒累加、只有深海能清零。概念文档 §3.1 已明确：全项目的压力**统一由 ALARM 单一维度承担**（无饥饿槽、无氧气槽），因为两个反向的压力源 = 认知过载。

**本系统的四个输出量**：

| 输出 | 消费方 |
|---|---|
| `alarm` 当前值 (0–100) | GDD-07（HUD 条）、音频（动态音乐层）、美术（太阳表情） |
| `tier` 当前档位 (0–3) | 敌人生成器、音频层、HUD 配色 |
| `enemy_list` 在场敌人（含 `has_tether`） | GDD-03（DECOY BREACH 重定向的目标筛选） |
| `tether_count` 当前系绳数 | **GDD-03（Bank 前置条件）** ⭐ 关键接口 |

## 2. 设计意图（支柱闸门校验）

| 支柱 | 服务？ | 具体落点 |
|---|---|---|
| **一 · 身份反转** | ✅ | 携带状态让 ALARM 更难降：携带时速率下降 → 在浅滩/冲浪区滞留时间变长 → 累加更多；且携带产生的水花（L1）会提高被发现概率。**你的战利品确实就是你的通缉令** |
| **二 · 一局一押** | ✅ **核心** | ALARM 是押注风险的量化刻度。沙盘 §3.4：「换路点随技巧水平后移（79→100）」——**ALARM 就是玩家做估值时读的那个数字**。没有 ALARM，Bank-or-Push 无法心算 |
| **三 · 灰度一抹血色** | ✅ **主要载体** | ALARM 条是「那一抹血色」的第一宿主（美术圣经 §2.6.1 L0 主强调色，配额 ≤3%）。危险的**唯一高彩度表达**就是它 |
| **四 · 两分钟精通** | ✅ | ALARM 管理是概念文档 §2 明列的三条可练技巧轴之一（Combo 上限 / 搁浅 QTE / **ALARM 管理**）。「顶在 74 不到 75」是预判中的涌现玩法「**Alarm 冲浪**」 |

**本系统明确不做（支柱闸门砍掉的提案）**：

| 提案 | 裁决 | 理由 |
|---|---|---|
| 饥饿槽 / 氧气槽 | ❌ 拒绝 | 概念文档 §3.1 已裁决：HUNGER 逼贪婪、ALARM 逼稳健，两个反向压力源 = 认知过载 |
| 生命值 / 护盾 | ❌ 拒绝 | 生命值会摧毁支柱二：有 3 条命，赌输还有兜底，「押注」就没有牙齿 |
| ALARM 分区显示（每区一条） | ❌ 归入 Epic | 违反单一压力维度原则；HUD 元素已达上限 5 个（美术圣经 §6.1 D5 约束） |

## 3. 核心机制

### 3.1 ALARM 数值模型

```
ALARM ∈ [0, 100]，上限硬 clamp（沙盘 ALARM_cap = 100 🔒）

d(ALARM)/dt = 区域斜率(zone, state)        ← 连续项
ALARM      += 事件增量(event)              ← 离散项（瞬时）
```

#### 连续项 · 区域斜率表

| 区域 / 状态 | 斜率 | 标注 | 来源 |
|---|---|---|---|
| 深海区 · **低速或静止**（Bank 消化、潜伏） | **−4.0 /s** | 🔒 | 沙盘 `decay_wait = 4.0` |
| 深海区 · **移动中**（返程） | **−2.0 /s** | 🔒 | 沙盘 `A_deep_slope = −2.0` |
| 浅滩区 | **+2.0 /s** | 🔒 | 概念文档 §3.1「浅滩显眼处停留每秒 +2」 |
| 冲浪区 | **+0.5 /s** | 🔒 | 沙盘 `A_surf_slope = +0.5` |
| 沙滩区 | **+4.0 /s** | 🔧 | 最暴露区（明度 82%）。沙盘未单独建模，取值须满足 §3.1.1 校准约束 |
| 水面以上（`breach` 空中） | **+3.0 /s** | 🔧 | 短暂暴露。含 DECOY BREACH 的出水瞬间 |
| **搁浅 QTE 期间** | **+8.0 /s** | 🔧 | 美术圣经 §6.8.5「ALARM 飙升」。2.5 s 窗口 → **+20**，恰等于一次捕食的量 |

#### 离散项 · 事件增量表

| 事件 | 增量 | 标注 | 来源 |
|---|---|---|---|
| **捕食成功（每次咬合）** | **+20 × 目标危险系数** | 🔒 | 基准 `A_grab = 20`（概念文档 v1.0 的 +25 已下调）。**目标危险系数由 GDD-03 §3.1 定义**：泳客/冲浪者 = 1.0（→+20）、**救生员 = 2.0（→+40）** |
| **DECOY BREACH 触发** | **+8** | 🔒 | 沙盘 §4 代价项 |
| 摩托艇撞击（掉战利品） | +5 | 🔧 | |
| 眩晕 / 束缚命中 | +3 | 🔧 | |
| Bank 完成 | **重置至 0** | 🔒 | 概念文档 §2 支柱二「落袋为安，ALARM 开始衰减」→ 此处裁决为**直接归零**，见 §3.5 |

> ⚠️ **交叉引用**：捕食的**目标危险系数**（救生员 ×2.0）定义在 **GDD-03 §3.1**，本文档只消费其结果。
> ⚠️ **沙盘边界**：沙盘 §1.3 的平均战利品价值 `L = 125` 只由「泳客 100 / 冲浪者 150」得出，**救生员（300 分）与名人（500 分）在沙盘模型之外**。因此目标危险系数是一个**未建模参数**，它只影响 Standard 层的高价值目标，不影响 C1/C2/C3 的既有结论。

> ⚠️ **为什么 Bank 是「归零」而不是「衰减」**：概念文档写的是「ALARM 开始衰减」，但 Bank 发生在深海区（−4.0/s），若 Bank 后还要等 25 s 才归零，「落袋为安」的情绪释放就被稀释了。且归零给玩家一个**清晰的节奏切分**：Bank = 一轮结束、新押注开始。这直接服务支柱二「一局一押」。

#### 3.1.1 ⭐ 校准约束（交 GDD-06 关卡系统）

> **分区斜率是手段，路径净变化才是目标。**

关卡布局确定后，两条返程路径的**全程 ALARM 净变化**必须匹配沙盘参数 🔒：

| 路径 | 目标净变化 | 沙盘依据 |
|---|---|---|
| **深水返程** | **≈ −28**（−2.0/s × T_deep 14 s） | `A_deep_slope` / `T_deep` |
| **冲浪返程** | **≈ +7.5**（+0.5/s × T_surf 15 s） | `A_surf_slope` / `T_surf` |

若不达标，**调分区斜率（🔧）或调路径长度（🔧），不得改沙盘参数（🔒）**。
→ 这条约束把「关卡布局」和「数值平衡」焊死，避免关卡设计在不知情的情况下破坏 R1 结论。

**⭐ 迟滞（Hysteresis）——必须实现，否则必出 Bug**：

| 方向 | 触发阈值 |
|---|---|
| **上升** | 25 / 50 / 75 |
| **下降** | **22 / 46 / 70**（各留 3 点迟滞带） |

> **为什么必须加迟滞**：ALARM 是连续量，玩家在阈値附近（例如深海边缘进出、24.9↔25.1）会造成档位**高频抖动** → 敌人在"生成/消失"间反复横跳、音乐层反复切换、太阳表情反复变脸。这既是**认知过载**（R3），也是**光敏风险**（视觉反复突变）。3 点迟滞带成本为零，收益是消除一整类 Bug。

**跨阈值的三重提示**（美术圣经 §6.1 D5-④）：条闪一下 + 音效 + 太阳表情变化。⚠️ 关闭「屏幕闪烁」后闪烁改常亮，其余两通道保留。

### 3.3 敌人分级与生成

| 档 | ALARM | 新解锁单位 | 同时在场上限 | 生成间隔 |
|---|---|---|---|---|
| T0 | 0–24 | 无（仅 T1 漂浮障碍） | T1 ≤ 3 | — |
| T1 | 25–49 | **救生员 T2a** | T2a ≤ 2 | 6.0 s |
| T2 | 50–74 | **摩托艇 T2b** | T2a ≤ 2、T2b ≤ 2 | 5.0 s |
| T3a | 75–89 | **直升机 T3b**、**拖网渔船 T3a** | 上述 + T3b ≤ 1、T3a ≤ 1 | 8.0 s |
| T3b | 90–100 | **捕鲨队 T4** | 上述 + T4 ≤ 1 | 10.0 s |

**四条通用生成规则**：

1. **0.8 s 预警**：所有 T2+ 单位进入屏幕前 0.8 s 必须有预警（屏幕边缘方向箭头 + 低频蜂鸣）——美术圣经 §4.4 通用规则
2. **上限已满时不生成**：新单位进入**等待队列**，档位上升或现有单位离场时补位（不强行超编）
3. **深海区是敌人禁区**：任何敌人不进入 `x < x_deep_line`（= 750 px）。这是「深海 = 绝对安全区」的机制保证，也是系绳能断的唯一前提
4. **降级不立即清场**：ALARM 跌档时，已生成的单位**不消失**，只是不再补充新单位。它们按各自 AI 继续行动直到离场

> **⭐ 两条致命威胁的性质刻意不同**（避免重复、给出两种不同的应对）：
> - **直升机 = 时间压力**：纯计时，无法用走位躲避，**只能断线**（进深海潜深）
> - **捕鲨队 = 走位压力**：鱼叉是可躲避的实体弹道，**必须闪避**

### 3.5 ⭐ 锁定系绳与断线机制

> **视觉规格见美术圣经 §5.4.3（本文档不重复）。本节只定义逻辑。**
> **关键定性（美术圣经 v1.5 定稿）**：系绳是**身份标记，不是状态指示**——它是「这是一台在猎你的机器」。**致命单位（直升机 / T4）出场即带，恒常存在，不存在无系绳阶段。**

#### 可观测性判定

```
observable = !(pos.x < 750  &&  depth > 240 px)
                 └ 深海区      └ 水面下深度
```

> 主题自洽：深海明度 8%，肉眼不可穿透。玩家潜得够深就「消失」。

#### 锁定计时状态机

```
每帧更新（每个系绳单位独立）：
┌─────────────────────────────────────────────────────────┐
│ if (observable):                                        │
│     t_lock       += dt                                  │
│     break_progress = 0                                  │
│     if t_lock >= 3.0 s:  → 死亡                          │
│ else:                                                   │
│     t_lock 冻结（不变，不衰减）                            │
│     break_progress += dt / 1.5 s                        │
│     if break_progress >= 1.0:  → 系绳断裂                 │
│         t_lock = 0                                      │
│         单位 → `?` 搜索状态（持续 4.0 s）                  │
└─────────────────────────────────────────────────────────┘

`?` 搜索状态（美术圣经 §5.4.3.6）：
    在最后已知位置附近往返搜索；探照灯无规律扫动
    ├─ 重新发现玩家 → 系绳重新射出（0.15 s），t_lock 归零
    ├─ 4.0 s 未发现 → 单位离场
    └─ ⭐ 此状态下**受诱饵影响**（已失去目标，正在搜索，噪音会吸引它）
```

#### 三条关键参数的推导

| 参数 | 值 | 推导 |
|---|---|---|
| **锁定致死时长** | **3.0 s** | 🔒 概念文档 §3.1「直升机探照灯锁定满 3 秒 = 死亡」 |
| **断线所需脱离时长** | **1.5 s** | 🔧 **必须 < 3.0 s，否则"进深海必死"无解**。取 1.5 s 意味着玩家必须在 `t_lock < 1.5 s` 时进入深海——这是一个真实的技巧考验，不是免费逃生 |
| **`?` 搜索持续** | **4.0 s** | 🔧 美术圣经 §5.4.3.6 留空待本文策渊定。取值依据：长于一次深水折返（约 2 s），短于一个完整押注循环 |

> ⚠️ **死锁检查**：深海区是敌人禁区（§3.3 规则 3），玩家待在深海必然 `observable = false` → 1.5 s 后必然断线。**无死锁** ✅
> ⚠️ **张力预告映射**（美术圣经 §5.4.3.4 的脱离进度）：拉紧 = `break_progress > 0.50`（0.75 s）、临界 = `break_progress > 0.80`（1.20 s）。本文策渊的 1.5 s 与美术的百分比分段直接对应。

### 3.6 DECOY BREACH 的目标筛选（本系统提供的接口）

GDD-03 调用本系统的**重定向筛选器**：

```js
function selectDecoyTargets(enemies, blastPos, radius = 160) {
    return enemies
        .filter(e => !e.has_tether)                    // ⭐ 免疫判据（美术圣经 §5.4.2.4）
        .filter(e => dist(e.pos, blastPos) <= radius)
        .sort((a, b) => dist(a.pos, blastPos) - dist(b.pos, blastPos))
        .slice(0, 2);                                  // 🔒 最多 2 个（概念文档 §3.2）
}
// 命中者：强制重定向至爆点，停机 = 2.5 s 调查 + 2 × 往返路程 / 敌速
// 未命中者中的系绳单位：播放「瞥见—驳回」+ ✕（美术圣经 §5.4.2.2）
```

> **免疫判据不是「在空中」，而是「有系绳」**（美术圣经 §5.4.2.4 采纳本文策渊裁定）。
> 这带来两个推论，都必须执行：
> 1. 直升机与 T4 恒带系绳 → **恒免疫**，包括它们刚出场时（无例外区间）
> 2. `?` 搜索状态的单位**已断线** → **受诱饵影响**（§3.5）——这让 DECOY BREACH 在致命单位面前并非完全无用，只是**不能直接救命**

> ### 🔴 措辞警告（执行级约束 · 应林绘澄请求写入）
>
> **禁止**使用「水面的 / 天上的」「T3 / T4 免疫」描述免疫范围。**一律写「有系绳 → 免疫，无系绳 → 受影响」。**
>
> | 单位 | 按「域」（✗ 错） | 按「T3/T4」（✗ 错） | **按「锁定」（✓ 正确）** |
> |---|---|---|---|
> | 拖网渔船（T3、水面、在巡视） | 受影响 | ❌ 误判免疫 | ✅ **受影响** |
> | T4 捕鲨队（**水面**单位） | ❌ 误判受影响 | 免疫 | ✅ **免疫**（有系绳） |
> | 直升机 `?` 搜索态（已断线） | ❌ 误判免疫 | ❌ 误判免疫 | ✅ **受影响** |
>
> **为什么这是执行级约束而不只是文案偏好**：
> **措辞就是玩家的心智模型。** 按「骗不了天上的」归纳的玩家，会在 T4 捕鲨队（水面单位，但有系绳 → 免疫）面前误判，**代价是死亡**。
> 按「有没有光束连着我」判断，只需认出一个**被明确画出来的符号**——二元、无例外、对新单位可迁移（美术圣经 §5.4.2.5 测试 B 的判据）。
>

## 5. 输入与反馈

### 5.1 本系统无直接玩家输入

ALARM 与敌人系统是**纯响应系统**：玩家无法直接操作它，只能通过**位置、是否捕食、是否炸水**间接影响。这是刻意的——ALARM 必须是「行为的后果」，不能是「可管理的资源条」，否则它会从压力计退化成第四根 HUD 条。

## 6. 边缘情况

### E1 · ALARM 在阈值附近高频抖动（24.9 ↔ 25.1）

**情形**：玩家在深海边缘（x ≈ 750）来回穿越，ALARM 在 25 附近反复跨越。
**裁决**：**已由 §3.2 的迟滞解决**（上升 25 / 下降 22）。
**补充裁决**：即使在迟滞带内，**敌人的生成与销毁仍有 1.5 s 的最小存活时间**——刚生成的单位至少存活 1.5 s，不得在生成后 0.2 s 又因跌档被移除。

**理由**：这条既是**认知过载**防护（R3），也是**光敏安全**要求（§5.3）。视觉反复突变比频率超标更危险。

---

### E2 · ⭐ ALARM 满值（100）时进入 Bank，如何结算？（必答）

> **裁决：允许在满通缉状态下完成 Bank，但 Bank 的前置条件之一是「当前无任何锁定系绳」。**

**三条理由**：

1. **禁止结算会直接违反概念文档 §3.3 的情绪禁区**：*「玩家应该**主动追求**高 ALARM 状态，而不是逃避它」*。若在 ALARM 100 时剥夺结算权，玩家学到的第一件事就是「别把 ALARM 顶满」——**我们把最高的技巧段变成了禁区**，这与"围剿档是给高手的游乐场"的定位完全相反。
2. **极限逃生回 Bank 是情绪曲线的宣泄点**。概念文档 §3.3 的情绪曲线里，「逃生 → Bank 结算」是唯一的松弛段。砍掉它，整局曲线只剩爬升没有释放。
3. **惩罚已经足够重**：ALARM 100 = 围剿 II 档，直升机（3 s 锁定致死）+ 捕鲨队（鱼叉一击致死）+ 4 个 T2 同时在场。活着回到深海本身就已是技巧证明，不需要再叠加"不许结算"。

**Bank 前置条件（三条同时成立，详见 GDD-03 §3.6）**：

| # | 条件 | 在 ALARM 100 时的意义 |
|---|---|---|
| 1 | `pos.x ≤ 750`（深海区） | 正常 |
| 2 | **`tether_count == 0`** ⭐ | **这是"牙齿"所在** |
| 3 | 非 Beached / Stunned / Snared | 正常 |

**为什么条件 2 是正确的"牙齿"**：

| ALARM | 系绳情况 | Bank 体验 |
|---|---|---|
| < 75 | 无系绳单位在场 → 条件 2 **自动满足** | 进入深海即 Bank，**零额外操作** |
| 75–100 | 直升机恒带系绳 → **必须先断线** | Bank 变成一次**极限操作**，不是自动事件 |

**具体的技巧考验**：断线需要脱离观测 **1.5 s**，而锁定致死是 **3.0 s**。
→ 玩家必须在 **`t_lock < 1.5 s` 时**钻进深海并潜到 240 px 以下。
→ 若 `t_lock` 已经跑到 2.5 s 才想起跑，**跑不到深海就死了**。

> **这就是"满通缉 Bank"的答案**：它不被禁止，它被变成了一场与 3 秒计时赛跑的极限逃生。**允许，但有牙齿。**

**死锁检查**：深海区是敌人禁区（§3.3 规则 3）→ 待在深海必然 `observable = false` → 1.5 s 后必然断线 → **玩家永远有出路** ✅

---

### E3 · 系绳断裂与 Bank 完成在同帧发生

**情形**：玩家潜入深海，第 1.5 s 系绳断裂（同帧 `tether_count → 0`），而 Bank 消化计时也恰好在此帧走完。
**裁决**：**同帧内先结算系绳断裂，再判定 Bank 前置条件**。即：
```
帧序：① ALARM 更新 → ② 系绳状态更新（含断裂）→ ③ Bank 前置条件判定 → ④ 咬合/死亡判定
```
断裂在步骤 ②，Bank 在步骤 ③ → 该帧 Bank **成立**。

**理由**：玩家的意图（潜深断线）已经达成，系统不该因为一帧的时序巧合而否定它。**时序仲裁一律偏向玩家**（这是街机游戏的通用惯例，也符合概念文档 UX 铁律第一条「重试摩擦为零」的精神）。

---

### E4 · 敌人生成上限已满，但 ALARM 升档要求生成高级单位

**情形**：T2 档已有 2 救生员 + 2 摩托艇（满编 4），此时 ALARM 升至 75，需生成直升机。
**裁决**：
1. **高级单位享有生成优先级，可临时超编 1 个**（T3/T4 不受 T2 上限约束）
2. 但**全场硬上限 = 7 个**（§3.3 表 T3b 行），达到后新单位进入等待队列
3. 若直升机已在场，**不生成第二架**（§3.3 上限 T3b ≤ 1）——ALARM 100 也只有一架

**理由**：ALARM 升档是玩家能明确感知的事件，若升档了却没有新威胁出现，玩家会认为"阈值是假的"，压力刻度失去可信度。**升档必须立刻兑现**——这是 §3.2 跨阈值三重提示在玩法侧的兑现。

---

### E5 · 同一帧内多个致命事件同时满足（死亡优先级）

**情形**：`t_lock` 满 3.0 s 的同一帧，捕鲨队鱼叉命中，且搁浅 QTE 失败。
**裁决 —— 固定的优先级序列**：

| 优先级 | 死亡来源 | 理由 |
|---|---|---|
| **1（最高）** | **搁浅 QTE 失败** | 它是**玩家主动造成、且被完全展示**的失败（用户决策 D4 / 锚点 04）。若被其他死亡打断，招牌演出会被腰斩，传播价值归零 |
| 2 | 直升机锁定满 3.0 s | 它是"时间到了"，有完整的张力预告，玩家已有预期 |
| 3 | 捕鲨队鱼叉命中 | 弹道是瞬时事件，玩家已有 1.0 s telegraph |

**裁决规则**：**先发生的判定"占位"，后续同帧事件被吞掉**，只播放优先级最高的那一种死亡演出。

**理由**：不允许"死亡叠加"（既播搁浅又播锁定），那既是**认知过载**（R3），也违反美术圣经 §6.7「同一时刻最多允许一个屏幕级特效」。

---

### E6 · ALARM 已达 100，继续产生增量

**情形**：ALARM = 100 时玩家又一次捕食（+20）。
**裁决**：
1. 数值 **clamp 在 100**，不溢出、不设第二档
2. **「通缉令拉满」事件只触发一次**：太阳皱眉 + 一次性色闪 + 音效 + HUD 条满格脉冲
3. 该事件的**重复触发锁**：ALARM 必须**跌破 90** 后再次回到 100，才允许重新触发

**理由**：不设重复触发锁的话，玩家在 ALARM 100 时每次捕食都会触发一次全屏反馈——这既是**光敏风险**（短时间内多次色闪），也是**语义贬值**（"狼来了"效应，第二次就不再有压迫感）。

---

### E7 · 玩家在 `Slowed` / `Stunned` / `Snared` 状态下的 ALARM 累加

**情形**：玩家被浮标眩晕 1.5 s，位置在浅滩区。
**裁决**：**ALARM 继续按区域斜率正常累加**（眩晕不是无敌，也不是避难所）。
- 眩晕 1.5 s × 浅滩 +2.0/s = **+3.0**
- 若在沙滩区眩晕：1.5 s × +4.0/s = **+6.0**

**补充裁决**：**眩晕/束缚结束后给 0.6 s 无敌帧**，防止"浮标命中 → 眩晕 → 直升机锁定 → 必死"的连锁。

**理由**：连锁致死（chained death）是街机游戏最劝退的体验之一。眩晕已经付出了 ALARM + 时间 + 机动性的三重代价，不应该再叠加一条必死路径。**这符合概念文档 §3.1 把浮标明确归入「非致命阻碍」的定位**。

---

### E8 · 摩托艇撞击时玩家未携带任何战利品（k = 0）

**情形**：空手状态下被摩托艇撞击。
**裁决**：**不掉战利品**（无可掉），但**其余效果全部生效**：击退 0.3 s + 0.5 s 无敌 + ALARM +5。
**理由**：若空手时撞击"无效果"，玩家会学到"空手时摩托艇是安全的" → 这会催生「空手冲进去引开摩托艇」的 unintended 战术。保持击退与 ALARM 惩罚，让威胁在任何状态下都是威胁。
