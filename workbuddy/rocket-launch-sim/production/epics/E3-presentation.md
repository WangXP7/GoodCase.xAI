## ST-3.1 · 失败演出（P4 的核心）

- **关联**：S6 §3.5 / §6.6 / §6.7（U4）
- **验收标准**：
  1. 时序（±50ms，A6-9）：`t=0` 全屏**炽白闪 1 帧（非红、非序列）**；`0.02–1.20s` 火箭碎成 **8–14 个硬边几何块**（保持箭体配色、切面非柔边、独立旋转+抛物线、1.2s 内飞出屏幕）；`0.05–0.95s` **3 个硬边烟环**（环形非实心、快速扩大+淡出）；**震屏 10px/0.5s**；`0.50–1.10s` **画面完全静止**；`0.00–0.40s` 遥测数字转 Danger 色归零；`1.70s` 弹面板。
  2. 粒子 ≤ **30**（桌面）/18（移动），经**全局熔断 ≤ 420**；碎片与烟环**全用 sprite**（A6-10/A6-11）。
  3. **真空无烟环**：`h > ATM_TOP` 的失败 ⇒ 烟环数 = 0（A6-12）。
  4. 光敏合规（A6-15）：炽白闪仅 1 帧、非红、非序列；震屏 ≤2Hz。
  5. 减少动效（A6-16）：震屏×0（改 1px 位移）、炽白闪改静态高亮、粒子×0.3（30→9）。
  6. 无对象泄漏（A6-13）：连续失败重开 20 次，活跃粒子/sprite 恒定。
  7. **演出期间锁定输入**（0→1.70s `R`/`Esc`/`Space` 全部无效，A6-8）。
- **涉及文件**：新增 `src/render/present-failure.js`；改 `src/render/world.js::_handleEvents`、`src/core/constants.js`（补 `S6 = { T_EXPLOSION:1.70, T_PANEL:1.70, T_SILENCE_FROM:0.50, T_SILENCE_TO:1.10, MAX_EVIDENCE:4 }`，**替换现有硬编码 1.70/1.4/4**）
- **依赖**：E6/ST-6.2（常量抽取，先做，避免又硬编码）
- **复杂度**：L
- **测试证据路径**：新增 `tests/prototype/present-smoke.mjs`（事件计数/粒子熔断/时序）+ 截图 `shots/fail-*.png`

## ST-3.2 · 入轨确认演出

- **关联**：S5 §5.1（U3）
- **验收标准**：
  1. `tJudge+0`：物理冻结；**尾焰 0.6s 熄灭**（不是瞬间消失）；全屏**去饱和渐变 1.2s**（场景饱和度→15%，**只有遥测 UI 保持全彩**）；地球辉光弧从底部升起成唯一光源，底部补光琥珀→冰蓝（1.2s）。
  2. `tJudge+0.30`：一圈 `#5FD8E8` 1px 细环（ADD）从箭体缓慢扩散，**只出现 1 次**，1.8s。
  3. `tJudge+0.60→1.40`：**完全静止 0.8s，粒子=0**（A5-14）。
  4. `tJudge+1.40`：弹结算面板（A5-13）；此后 `R` 可重开。
- **涉及文件**：新增 `src/render/present-success.js`；改 `src/render/world.js`（尾焰熄灭 + 去饱和后处理）、`src/render/hud.js`（面板时机沿用 `judgeFreezeT`）
- **依赖**：无（可与 ST-3.1 并行）
- **复杂度**：M
- **测试证据路径**：`present-smoke.mjs`（A5-13/A5-14 时序与粒子计数）

## ST-3.3 · 分离表现（预热闪烁 + 碎片 + 换挡指针挂钩）

- **关联**：S3 §3.2 / §5.1 / §5.2（U8, U9 的表现侧）
- **验收标准**：
  1. **上级发动机预热闪烁**：`t=0.150` 起 3 次明暗（2Hz，持续 `SEP_DELAY=0.15s`）→ `t=0.350` 点火。
  2. 常量 `SEP_DELAY` 补入 `STAGE`（当前**缺失**），并 `Q_SEP_SAFE` 归属澄清（见 E6/ST-6.3）。
  3. 分离面 2px 白色闪光线贯穿箭体**持续 3 帧**；震屏 8px/0.25s；**12 个硬边小矩形碎片**（独立旋转，非柔和粒子）。
  4. 下级残骸：0.2s 内火焰 alpha→0 → 继续上升 0.3s → 翻转下落（45°/s）。
  5. 加速度指针"**换挡**"演出（先落再缓慢回升）——**依赖 ST-4.3 先建加速度读数槽**。
- **涉及文件**：`src/render/world.js`、`src/render/hud.js`、`src/core/constants.js`（`SEP_DELAY`）
- **依赖**：ST-4.3（加速度槽）
- **复杂度**：M
- **测试证据路径**：`present-smoke.mjs`（碎片数=12、闪光线 3 帧）+ 截图
