## 一、项目定位

| 项 | 内容 |
|---|---|
| **项目名** | 火箭发射模拟器（Rocket Launch Simulator · 名称待定 Q1） |
| **类型** | 2D 硬核火箭发射模拟器 |
| **核心差异化** | **不做"发射过场动画"，做"发射的驾驶考试"**——玩家是飞行员，不是观众 |
| **核心技能** | **重力转弯（Gravity Turn）**——真实、可教学、有明确技巧上限 |
| **引擎** | Phaser 3（2D 网页） |
| **平台** | TapTap 网页版 · **桌面浏览器（键鼠）** |
| **主设计基准** | **1920 × 1080（16:9 横屏）** |
| **单局时长** | 60–90 秒（基准 70s） |
| **视觉基调** | 硬核写实工程风 / 1960s 任务控制中心仪表美学 |

**一句话**：按下点火，然后亲手把这枚火箭开进轨道。

### 解决的真问题
同类 AI 复刻作品普遍止步于"按下按钮看升空表演"，新鲜感 30 秒内耗尽。本作把一次性表演改造为**可精进的技能**——重力转弯的错误时机、节流曲线、分离时机各有代价，失败可归因，因此值得再来一次。

## 三、设计支柱（4 根 · 决策取舍的最终标准）

| # | 支柱 | 含义 | 取舍用法 |
|---|---|---|---|
| **P1** | **过程即内容** | 每个阶段都有可交互的状态推进，绝不出现"播放一段动画让你看" | 砍掉所有自动化过场、一键跳过、过场 CG |
| **P2** | **可解读的深度** | 系统可硬核，但每个数值、每次失败玩家都必须看懂"为什么" | **无法可视化的系统不进 MVP** |
| **P3** | **一次发射，六十秒** | 单局 60–90s，失败后 3 秒内可重来 | 延长单局时长的内容是成本，不是内容 |
| **P4** | **失败也好看** | 失败是内容的一部分，不是需要被缓冲的惩罚 | 爆炸演出优先级等同成功流程 |

## 四、已锁定的决策

### 用户拍板（3 项）

| # | 议题 | 决策 | 连锁影响 |
|---|---|---|---|
| **Q2** | 触屏支持 | **桌面优先，触屏后置** | 输入锁键鼠；原最高技术风险（触屏配平手感）当场解除 |
| **Q3** | 单局时长 | **60–90 秒** | 心流曲线重排；分段合并 |
| **Q5** | 视觉基调 | **硬核写实工程风** | 与视觉锚点 A1 一致，美术无需返工 |

### 主理人裁决（3 项）

| # | 冲突 | 裁决 |
|---|---|---|
| **1** | **Q7 上级燃烧段 15s 违反 P1**（圆化非 MVP → 玩家无事可做） | 采纳**合并分段**方案：取消独立上级燃烧段，并入重力转弯尾部，合成连续 35–40s「重力转弯→入轨收敛」窗口。分离降级为段内节拍。**理由**：独立分段是 KSP 遗产（那里上级要做机动规划），本作单构型单 LEO 目标，分段零信息价值，只增加切换成本 |
| **2** | **A1 琥珀偏离锚点 A2**（暖色既用于火焰又用于 UI） | **采纳美术方案，认定优于机械执行锚点**。琥珀 = "能量与注意"的语义统一，让"按钮里憋着的能量"和"喷口爆发的能量"在视觉上是同一件事。但须写入可验收的 **A1-BOUND 边界规则** |
| **3** | **主设计基准 1920×1080 + 资产帧数 260→270** | **两项均签字批准**。否决 1600×900 的关键理由：纵向 900px 扣掉 HUD 后发射塔与火箭顶格，买不到"火箭上方的未至空域"——那正是横改竖之后最贵的东西。增量 10 帧（高度带 4 + 紧凑布局 6）合理 |

## 五、跨成员一致性检查结论

| 锚点 | 要求 | 美术落地 | 判定 |
|---|---|---|---|
| **A1 硬核工程蓝调** | 冷灰蓝金属、工程网格、无 Q 版糖果色 | 陶瓷白 `#F4EFE4` / 铁灰 `#5A6472` / 墨蓝 `#121A33`；禁中性灰 `#808080` 系 | ✅ 对齐 |
| **A2 冷霜金属·暖橙烈焰** | 唯一高饱和暖色留给火焰与爆炸 | 有意识偏离 → 已裁决并写入 A1-BOUND 规则 | ✅ 裁决通过 |
| **A3 遥测可读性优先** | 等宽字体、数值变化必有图形动画、不遮挡视野 | IBM Plex Mono + `tabular-nums`；4 层信息层级；火箭通道 480px 居中；指针 8% 过冲回弹（禁线性移动） | ✅ 对齐 |
| **A4 剪影与尺度** | 用剪影与相对尺度传达巨大感 | **9 条离散天空色带**（L0 地面 → L8 入轨）+ 卡门线事件线 + 地球边缘辉光弧 | ✅ 超出预期 |
| **A5 颗粒与震动** | 屏幕震动、颗粒、拖影 | 全屏 4% alpha 噪点；震屏/闪烁/扫描线三开关独立 | ✅ 对齐 |

### 主动排除的反模式（用户已知反感项）
✅ 粒子堆砌 —— 火焰主力是 **sprite 序列 + 硬边形体**，粒子仅点缀，活跃粒子 ≤420（桌面）/ 220（移动）
✅ 灰色技术演示风 —— §2.5 无彩使用规则：禁止未定义用途的中性灰
✅ 静态雕塑感 —— 入轨成功用**"静"**表达（真空无烟、去饱和至 15%、粒子归零），反高潮堆料
✅ 廉价渐变 —— 天空用离散色带而非平滑渐变，同时性能更优（仅 2 个 TileSprite 轮换）

## 六、MVP 边界（已锁定，不得擅自扩张）

**✅ 进 MVP**
- 单枚固定构型两级火箭（参数不可修改）
- 完整发射序列：T-10 倒计时 → 预冷 → 增压 → 点火 → 松绑 → 升空
- **5 个动词**：点火 / 节流 / 配平 / 分离 / 中止
- **5 个读数**：高度 / 速度 / 燃料 / 姿态 / Δv 余量（已确定化为远-近地点预测标记条）
- 简化物理：重力、推力、燃料质量变化、大气阻力
- 单一目标轨道（LEO 100km）+ 三档评级
- 失败演出（解体 / 坠海 / 中止）+ 3 秒重开
- 键鼠输入

**❌ 不进 MVP**
火箭组装 · 多目标轨道 · 天气风切变 · 排行榜/后端 · 剧情 · 涂装货币 · 教学关（改隐形引导）· **移动端触屏**

> **认知过载红线**：MVP 只暴露 5 动词 + 5 读数，加一个必须减一个。

## 七、合并后的阶段时长（v0.3 · 基准 70s）

| 阶段 | 时长 | 操作需求 | 情绪目标 |
|---|---|---|---|
| T-10 倒计时 | ~10s（可跳过） | 低 | 仪式感、唤醒 |
| 垂直上升 | ~12s | 中 | 进入心流、力量感 |
| **重力转弯 → 入轨收敛** | **~38s**（一级 25s ＋ 分离节拍 2s ＋ 上级收敛 11s） | **高** | **紧张峰值**，心流通道最窄 |
| 入轨确认 | ~10s | 低 | 释放、成就、截图时刻 |

熟练 60s（跳倒计时）／基准 70s／保守 90s（合并窗口救场拉长）。**时长即技能信号——飞得越好，这局越短。**
