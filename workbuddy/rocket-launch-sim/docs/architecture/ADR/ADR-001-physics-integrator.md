# ADR-001 · 物理积分器选型

- **状态**：已接受（Accepted）
- **日期**：Phase 3
- **决策者**：程基岩（技术/引擎）
- **关联**：ARCH-1 §4 · GDD S1 §3.1 · RT-1 §7

## 背景（Context）

本作要把弹道复现到 RT-1 的验收精度：近地点 15.09 km、MaxQ 16.47 kPa、单局 81.0 s、关机速度 2087 m/s。物理需要在**自定义力场**（万有引力均取 Planet-C 的 μ=7.2e11）上积分：引力 + 指数大气阻力 + 攻角气动恢复力矩。同时要求**确定性**（同一操控序列 → 同一结果），以支持无头闭环验证。

需要选定积分方法，以及是否复用 Phaser 内置的 Arcade Physics。

## 决策（Decision）

**自写半隐式欧拉（semi-implicit/symplectic Euler），固定步长 1/120 s。不使用 Arcade Physics，不使用 RK4。**

状态矢量 `(rx, ry, vx, vy)`，每步：
```
a   = 引力(r) + 阻力(r,v) + 推力(T,θ) / m        # 用当前状态算加速度
v  += a * dt                                      # 先更新速度
r  += v * dt                                      # 再用新速度更新位置（半隐式关键）
θ, ω 同理一阶滞后积分
```

## 备选方案（Alternatives）

| 方案 | 优点 | 为何不选 |
|---|---|---|
| **Phaser Arcade Physics** | 开箱即用、有人维护 | 为"手感"而非"精度"设计；不暴露自定义引力场；积分误差击穿 RT-1 基准；依赖渲染帧调度，无法保证确定性 |
| **RK4（四阶龙格库塔）** | 精度更高（局部 O(dt⁵)） | 每步 4 次力评估，成本 ×4；本问题力场平滑、时长短、dt 小，半隐式误差已可忽略；RT-1 参考就用半隐式，换 RK4 反而不与原基准逐位对齐，验证成本上升 |
| **Verlet / 蛙跳** | 辛性质、能量守恒好 | 半隐式欧拉已具辛性质；Verlet 需要特殊启动步，与"关机瞬间"这类非光滑事件交互更麻烦 |
| **显式欧拉** | 最简单 | **不辛**，能量系统性发散，长时程漂移，不可接受 |

## 后果（Consequences）

**正向**
- 与 RT-1 开环参考**逐位一致**（`open-loop-port-check.mjs` 通过），验证成本最低。
- 纯函数式两行公式 → 无隐藏状态/分支 → **确定性**成立。
- 零额外依赖，core 保持纯 JS，浏览器与 Node 同源。

**负向 / 代价**
- 精度上限低于 RK4：若未来引入强非线性力（如稠密大气下的复杂气动），需重新评估步长或换积分器。
- 需自行处理步长/累加器（已由 ARCH-1 §5 覆盖）。

**触发重评的条件**
- 若步长被迫放大（>1/60）或力场出现刚性项，回头评估 RK4。
