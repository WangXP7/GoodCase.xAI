## 1. 系统职责与支柱挂靠

### 1.1 一句话职责

> **提供全作唯一的环境对抗力，并制造单局的第一个情绪峰值。** S4 拥有大气密度模型、动压计算、Max-Q 事件检测。

### 1.2 支柱闸门校验

| 支柱 | 本系统如何服务 | 判定 |
|---|---|---|
| **P1 · 过程即内容** | 动压是**逐帧连续可读**的量，玩家能通过节流（V2）与配平（V3）主动管理它。Max-Q 不是过场，是玩家亲手穿越的一个坎 | ✅ 挂靠 |
| **P2 · 可解读的深度** | 动压 `q = ½ρ(h)v²·Cd·A` 的三个因子（ρ 随高度指数衰减、v 单调上升、Cd 随攻角上升）**全部有 HUD 表达**。玩家可以推理出"我应该收油门" | ✅ 挂靠 |
| **P3 · 一次发射，六十秒** | Max-Q 在 **T+19.16 s**（实测），位于前 24% 飞行时长。阻力在 **T+47.61 s**（大气顶）后完全归零，此后 33 s 是无阻力段 | ✅ 挂靠 |
| **P4 · 失败也好看** | 动压超限（> `Q_STRUCT`）触发**气动解体**，是 S6 的核心失败模式之一 | ✅ 挂靠 |

**闸门结论：S4 挂靠全部四根支柱。**

### 1.3 明确不属于 S4

- 天气 / 风切变 → **不进 MVP**（概念 §7.1），属核心体验层
- 气动加热 / 热防护 → **MVP 内不建模**（无温度结构模型，见 §6.5）
- 大气色带的视觉渲染 → 美术 §2.2 / §8.4，S4 只提供高度 → 带号的映射

## 2. 核心状态与数据结构

### 2.1 大气常量（RT-1 标定值，**不得修改**）

| 符号 | 值 | 量纲 | 说明 |
|---|---|---|---|
| `RHO0` | 1.2 | kg/m³ | 海平面密度 |
| `SCALE_H` | 2500 | m | 标高（密度 e 折高度） |
| `ATM_TOP` | 12000 | m | 大气顶（**硬截断**，高于此高度密度恒为 0） |
| `A_REF` | 10.0 | m² | 气动参考面积 |
| `CD0` | 0.25 | — | 零攻角阻力系数 |
| `CD_ALPHA` | 2.0 | — | 攻角阻力系数 |

### 2.2 阈值常量

| 符号 | 值 | 量纲 | 说明 |
|---|---|---|---|
| `Q_WARN` | 12000 | Pa | 动压**警戒**阈值（HUD 转琥珀 + 声告警） |
| `Q_STRUCT` | 30000 | Pa | 动压**结构**阈值（超过即解体） |
| `Q_SEP_SAFE` | 5000 | Pa | 安全分离动压上限（**S3 拥有此阈值**，S4 仅提供 `q` 供其判定）。S3 §9-C6 提出上调至 8000 Pa，待裁决 |
| `V_DRAG_EPS` | 0.5 | m/s | 阻力计算的速度下限（除零防护） |

> **阈值来源说明**：RT-1 实测基准弹道峰值动压 **16.47 kPa**，Falcon 9 实测约 30 kPa。
> - `Q_WARN = 12 kPa` ⇒ 基准弹道在 T+16.5 进入警戒、T+22 退出，**警戒持续约 5.5 s**。这是一个"注意到了、但不至于死"的窗口。
> - `Q_STRUCT = 30 kPa` ⇒ 是基准峰值的 1.82 倍。**基准弹道有 82% 的动压余量**，玩家只有明显乱飞（大攻角 + 不节流）才会解体。
> - 二者之间的 12→30 kPa 是**玩家可用节流主动管理的空间**。

### 2.3 运行时状态

```ts
interface AtmoState {
  rho:        number;   // 当前大气密度 kg/m³
  q:          number;   // 动压 Pa = 0.5 · rho · v²
  qMax:       number;   // 本局峰值动压 Pa
  tQMax:      number;   // 峰值动压发生时刻 s
  hQMax:      number;   // 峰值动压发生高度 m
  cd:         number;   // 当前阻力系数（含攻角项）
  dragForce:  number;   // 当前阻力大小 N
  inWarning:  boolean;  // q > Q_WARN
  maxQPassed: boolean;  // 是否已越过峰值（用于 HUD 事件触发）
  band:       0|1|2|3|4|5|6|7|8;  // 当前天空色带号（供美术层读取，见 §9-C1）
}
```

## 3. 规则与公式

### 3.1 大气密度（指数模型 + 硬截断）

```
rho(h) = (h >= ATM_TOP || h < 0) ? 0 : RHO0 · exp(−h / SCALE_H)
```

| 高度 | 密度 ρ (kg/m³) | 相对海平面 |
|---|---|---|
| 0 km | 1.200 | 100% |
| 2.5 km | 0.4414 | 36.8% |
| 5.0 km | 0.1624 | 13.5% |
| 7.5 km | 0.0597 | 5.0% |
| 10.0 km | 0.0220 | 1.83% |
| **12.0 km（大气顶）** | **0（截断）** | **0%** |

> **硬截断的必要性（RT-1 §3）**：目标轨道 15 km 只比大气顶高 3 km。若用纯指数模型不做截断，15 km 处仍有 `1.2·e^(−6) = 0.0030 kg/m³`，在 2087 m/s 下产生 `q = 0.5·0.0030·2087² = 6518 Pa` 的持续阻力 ⇒ 轨道会缓慢衰减。**MVP 内不做轨道衰减模拟**，因此必须硬截断，让 12 km 以上成为真空。

### 3.2 阻力系数（攻角相关）

```
Cd(α) = CD0 + CD_ALPHA · sin(α)²        // α = theta − gamma（攻角 rad）
```

| 攻角 α | Cd | 相对零攻角 |
|---|---|---|
| 0° | 0.25 | 1.0× |
| 5° | 0.265 | 1.06× |
| 10° | 0.310 | 1.24× |
| 20° | 0.484 | 1.94× |
| 30° | 0.750 | 3.00× |
| 45° | 1.250 | 5.00× |
| 90° | 2.250 | 9.00× |

> **设计意义**：攻角是玩家的**配平质量分**。基准弹道全程 `|α| < 0.05 rad (2.9°)`，Cd ≈ 0.25。乱打杆会让 Cd 翻倍甚至五倍，直接放大动压并吃掉 Δv。**这是"配平"这个核心技能在经济上的兑现。**

### 3.3 动压与阻力

```
q   = 0.5 · rho(h) · v²                              // Pa（**注意：动压不含 Cd**，是纯环境量）
D   = 0.5 · rho(h) · v² · Cd(α) · A_REF              // N（阻力含 Cd）
```

**为什么要区分 `q` 与 `D`**：
- `q` 是**结构载荷**的度量（玩家能死于 `q` 过大）——这是真实火箭的 Max-Q 定义。
- `D` 是**能量损失**的度量（玩家会因 `D` 大而缺 Δv）。
- 二者在 HUD 上分属两个读数槽的表达（见 S7）：`q` 走第 5 读数旁的动态告警，`D` 的效应体现在 Δv 余量的消耗速率上。

### 3.4 Max-Q 事件检测

```
// 每帧
if (q > qMax) { qMax = q; tQMax = t; hQMax = h; maxQPassed = false; }
else if (qMax > Q_WARN && q < qMax − Q_PEAK_MARGIN && !maxQPassed) {
    maxQPassed = true;
    emit('onMaxQPassed', { qMax, tQMax, hQMax });
}
```
`Q_PEAK_MARGIN = 1000 Pa`：动压需从峰值回落 1 kPa 才判定"已越过峰值"，防止在峰值平台期的浮点抖动导致事件反复触发。

**基准弹道实测**：

| 量 | 值 |
|---|---|
| 峰值动压 `qMax` | **16.47 kPa** |
| 发生时刻 `tQMax` | **T+19.16 s** |
| 发生高度 `hQMax` | **2.609 km** |
| 该时刻速度 | 279 m/s |
| 该时刻密度 | 0.4245 kg/m³ |
| 越过峰值（`q < 15.47 kPa`） | ≈ T+22.3 s |

### 3.5 大气顶事件

```
if (prevH < ATM_TOP && h >= ATM_TOP) emit('onAtmosphereExit', { t, h, v });
```
基准弹道：**T+47.61 s**，此后 `rho ≡ 0`、`D ≡ 0`、`q ≡ 0`。

> **这是一个被低估的设计资产**：大气顶之后还有 33.4 s（41% 的飞行时长）是**纯真空弹道**。玩家在这段时间里唯一的对手是重力，视野里没有云、没有动压、没有阻力——**这是"我上天了"的物理证据**，且它是免费的。S7 必须在此刻给出一个明确的事件反馈（见 §5.3）。

### 3.6 结构解体判据

```
IF q > Q_STRUCT (30000 Pa) THEN raiseFailure('DESTRUCT_AERO')
```
另有复合判据（与 S1 §6.5 同）：
```
IF |alpha| > ALPHA_STRUCT (0.35 rad) AND q > Q_STRUCT THEN raiseFailure('DESTRUCT_AERO')
```

> **MVP 声明**：**无连续结构应力模型**（S1 §6.5 已声明）。`q > 30 kPa` 是唯一的解体判据。基准弹道峰值 16.47 kPa，**永不触发**。它只在玩家明显乱飞时生效。

## 4. 玩家输入映射（键鼠）

S4 **不直接接受输入**，它通过两个动词间接被管理：

| 动词 | 键位 | 对动压的作用机理 | 有效性 |
|---|---|---|---|
| **V2 节流** | `W`/`S` 或 `↑`/`↓` | `throttle ↓` ⇒ 推力 ↓ ⇒ `v` 增速放缓 ⇒ `q = ½ρv²` 下降<br>**代价**：重力损失上升，Δv 余量下降 | **这是管理 Max-Q 的主旋钮** |
| **V3 配平** | `A`/`D` 或 `←`/`→` | 保持 `α ≈ 0` ⇒ `Cd ≈ 0.25` ⇒ `D` 最小<br>**代价**：跟随参考重力转弯需要技巧 | 次要旋钮（管的是 `D` 不是 `q`） |

### 4.1 节流对 Max-Q 的定量效果（供玩家心智模型与辅助线使用）

以 T+15 s（`h ≈ 1.59 km`，`v ≈ 216 m/s`，`q ≈ 14.8 kPa`）为例：

| 节流 | 净加速度 | 5 s 后 v | 5 s 后 h | 5 s 后 q | Δv 代价 |
|---|---|---|---|---|---|
| 1.00 | ≈ 30 m/s² | 366 m/s | 3.05 km | **16.0 kPa** | 0 |
| 0.60 | ≈ 17 m/s² | 301 m/s | 2.75 km | **11.4 kPa** | 重力损失 +65 m/s |
| 0.30 | ≈ 8 m/s² | 256 m/s | 2.55 km | **8.4 kPa** | 重力损失 +110 m/s |

> **结论（这是本系统的核心教学点）**：把节流从 1.00 收到 0.60，动压峰值从 16.0 降到 11.4 kPa（**−29%**），代价是约 65 m/s 的重力损失。而 RT-1 的 Δv 损失预算是 548 m/s——**节流是买得起的保险，但不是免费的。**
>
> **基准弹道不节流也能过（16.47 < 30 kPa）**，所以节流在 MVP 内是**优化手段而非必需手段**——这正好符合概念 §5.2「减压阀」的定位，也符合"存在多条可行路径"的自主性保障。

| 方案 | 内容 | 评估 |
|---|---|---|
| **A ✅ 采纳** | **接受 Max-Q 为"早期小坎 / 单局第一个教学点"，把真正的中段峰值交给「大气顶事件」（T+47.6 s）与「近地点爬升」（T+61.7 → 81 s）**。Max-Q 定位为"第一道测试"，演出规格**教学化**而非戏剧化：HUD 三级告警 + 座舱震动 + 越峰视觉（§5.5 V-MAXQ）+ 一次 "MAX-Q" 语音提示 | 与 RT-1 数据一致，零物理改动。**已回灌概念 §3.1 / §3.2-2 / §5.2** |

## 6. 边缘情况（≥3 条，含数值退化与除零防护）

### 6.1 `v → 0` 时的除零

`D = 0.5·ρ·v²·Cd·A` 本身无除零（`v²` 安全）。但阻力的**方向**需要 `vx/v` 与 `vy/v`：

**防护**（S1 §6.1 已定义，S4 依赖）：`v > V_DRAG_EPS = 0.5 m/s` 才计算阻力；否则 `D = 0` 且方向向量不计算。

**S4 侧的独立防护**：`rho(h)` 在 `h < 0` 时返回 0（见 §3.1），因此即使 `v` 很大，`h < 0` 也不会产生阻力。

### 6.2 `exp(−h/SCALE_H)` 的下溢与硬截断的一致性问题

浮点上 `exp(−h/2500)` 在 `h` 很大时下溢到 0，但**在 `h < 12 km` 时永不为 0**。硬截断在 `h ≥ 12 km` 处引入了一个**密度阶跃**：`h = 11.999 km` 时 `ρ = 0.00988`，`h = 12.001 km` 时 `ρ = 0`。

**后果**：若火箭在 12 km 附近上下穿越（例如末段振荡），`D` 会在 0 与 `0.5·0.00988·v²·Cd·A` 之间跳变。在 `v = 2087 m/s`、`Cd = 0.25` 时，这个跳变是 **53,500 N** 的力 —— 约 5.4 g 的瞬时加速度跳变。**会造成明显的物理抖动。**

**防护**：在 `ATM_TOP` 前后 ±300 m 的过渡带内做线性衰减：
```
RHO_FADE = 300 m
rho(h) = (h >= ATM_TOP) ? 0
       : (h >= ATM_TOP − RHO_FADE)
           ? RHO0 · exp(−h/SCALE_H) · (ATM_TOP − h)/RHO_FADE
           : RHO0 · exp(−h/SCALE_H)
```
在 `h = 12 km` 处 `ρ` 连续趋于 0；在 `h = 11.7 km` 处恢复纯指数。

> **验收**：跨 `ATM_TOP` 前后 1 s 内，`D` 的逐帧变化量 < 满推力 `T1` 的 2%（< 18 kN）。

### 6.3 `alpha` 的周期性与 `sin(α)²`

`α = theta − gamma`。若 `theta` 与 `gamma` 各自跨过 ±π 边界（例如箭体翻滚），`alpha` 可能出现接近 ±2π 的假值，使 `sin(α)²` 计算出一个物理上不存在的巨大 Cd。

**防护**：`alpha` 在使用前归一到 `[−π, π]`：
```
alpha = Math.atan2(Math.sin(theta − gamma), Math.cos(theta − gamma));
```
`sin(α)²` 天然有界于 [0,1]，因此 `Cd ∈ [0.25, 2.25]` **天然有界，不会爆炸**。但归一化是必要的——它保证 `alpha` 读数（HUD）显示的是真实攻角。

### 6.4 `qMax` 在失败重开后的残留

**防护**：`reset()` 无条件清零 `qMax / tQMax / hQMax / maxQPassed / inWarning`。

### 6.5 `q` 在真空段的恒零与 HUD 的"死读数"

T+47.6 s 之后 33.4 s（41% 飞行时长）`q ≡ 0`。若动压读数常驻，会是一个"死读数"。

**处理**：`q ≡ 0` 持续 1.2 s 后，动压读数槽**折叠隐藏**（不是变灰），把空间让给第 5 读数（轨道标记条）展开。**这是认知过载红线的动态管理：不是减少读数总数，而是让已经完成使命的读数退场。**

> **验收**：真空段（`h > 12 km` 且持续 > 1.2 s）后，HUD 上同时存在的读数槽位**不超过 5 个**。

### 6.6 「减少动效」模式下的告警

告警高亮在「减少动效」模式下改为**静态高亮**（美术 §9.3），不闪烁。
