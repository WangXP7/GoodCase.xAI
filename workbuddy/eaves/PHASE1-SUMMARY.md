## 四、设计支柱（4 根）

1. **身份反转** —— 你的战利品就是你的通缉令
2. **一局一押** —— Bank or Push，把反应游戏变成估值游戏
3. **灰度一抹血色** —— 「一抹」= 稀缺性（面积配额），非单色性
4. **两分钟精通** —— 技巧直接延长冲浪窗口（ALARM 79 → 100）

## 五、R1 数值沙盘结论（本项目迄今最关键产出）

### 原验收标准被证明自相矛盾

原标准「浅滩期望收益 ≥ 深水 × 1.5」隐含「所有状态下浅滩都更优」→ 那深水就是死内容 → **这正是 R1 本要防止的失败**。

**70 组参数扫描证明：29 个配置（41%）会通过原标准，而每一个都是真实失败案例。**

### 修订后的三条判据（须同时成立）

| 判据 | 定义 | 防什么 |
|---|---|---|
| **C1** | k=1 时冲浪/深水 ≥ 1.5 | 冲浪变死内容 |
| **C2** | 存在 k 使比值 < 1.0 | 深水变死内容（主导策略） |
| **C3** | 全局最优押注数 k ≥ 2 | Bank-or-Push 形同虚设 |

### 推荐配置（`m_surf=2.6` / `A_grab=20`）

| | 专家 | 新手 |
|---|---|---|
| k=1 比值 | 1.75 ✅ | 1.53 ✅ |
| 最优押注数 | k=2 | k=2 |
| 深水反超点 | ALARM≈100 | ALARM≈79 |

**关卡约束（改动需回跑沙盘）**：
- 冲浪路线须布置 **8 个收集物**
- 每次捕食 **ALARM +20**

**敏感性分析**：`m_surf`（收集物数量）是唯一强杠杆（±20% → 比值 ±0.35），其余为弱杠杆可放心用于手感微调。

## 六、硬红线（不可协商）

### 1. 光敏性癫痫安全

- 执行值：**2Hz**（严于 WCAG 2.3.1 要求的 <3Hz）
- **全项目禁用硬 on/off 切换**，一律改呼吸式明暗渐变（亮度突变才是主要诱因，非频率本身）
- **5 个正交开关**：震屏 / 闪烁 / 扫描线抖动 / CRT / 粒子密度
- 首次启动提示 + 7 项程序自检清单

### 2. 可访问性

- 颜色永不作为唯一信息通道
- ALARM 三重编码：进度条 + 刻度形状 + 音效
- 完整色盲 HEX 映射表（血红 → 电光蓝）
- 血红/洋红语义分离靠**形态通道**：洋红=径向运动粒子（动），血红=静态填充/条/描边（静）

## 七、关键技术决策

| 议题 | 结论 |
|---|---|
| **粒子系统** | 保留「禁止柔和粒子」禁令，不开例外。形状=硬边方块，淡出=有序抖动 dither，运动=量化到像素网格 |
| **抖动技法** | 从「光柱可选项」推广为全项目默认，仅暗角与遮罩保留真 alpha |
| **喜剧表达** | 来自物理不来自表情（8×8px 脸做不出微表情），靠姿态夸张与高频抖动 |
| **搁浅配色理论** | 强调色 = 「可能性」的信号。搁浅时无选择 → 强调色抽干，唯 QTE 圆环保留 |
| **HUD 约束** | ≤5 元素且已达上限，新增须同时说明移除哪个 |
