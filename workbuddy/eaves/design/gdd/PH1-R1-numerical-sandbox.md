## 1. 模型

### 1.1 为什么要建模而不是拍脑袋

概念文档 §3.2 把 R1 列为**最高级设计风险**：如果某条逃生路径在期望收益上永远更优，另一条就是死内容，支柱二（一局一押）的路径抉择随之瓦解。这类问题靠"感觉"判断不可靠——必须用数字说话。

### 1.2 循环结构

一次完整循环 = `潜行接近 → k 次捕食 → 返程（选路）→ 深海等待衰减 → 结算`

**推演式**：

```
得分速率 = L × k × m × (1 − p) / T_cycle

  L       平均战利品价值（泳客 100 / 冲浪者 150 → 125）
  k       本次押注捕食的游客数（Bank-or-Push 的押注量）
  m       COMBO 倍率（深水 = 1.0；冲浪 = m_surf）
  p       返程死亡概率（ALARM 与路径的函数）
  T_cycle 潜行 + 追加接近 + 返程 + 等待衰减
```

> **为什么用"得分速率"而不是"单循环期望分"**：本作是无尽押注制，一局在死亡时结束。得分速率同时包含了"这一轮赚多少"和"这一轮多快"，是唯一能横向比较不同风险策略的指标。推导：期望总分 = S·(1−p)/p，期望总时长 = T/p，相除得 **S(1−p)/T**。

### 1.3 参数（假设值，待校准）

| 参数 | 值 | 说明 |
|---|---|---|
| `L` | 125 | 平均战利品价值 |
| `T_stalk` / `A_stalk` | 8s / +5 | 潜行接近 |
| `T_approach` / `A_approach` | 5s / +5 | 追加一个目标的接近成本 |
| `T_deep` / `A_deep_slope` | 14s / −2.0 per s | 深水返程（安全，ALARM 衰减） |
| `T_surf` / `A_surf_slope` | 15s / +0.5 per s | 冲浪返程（暴露，ALARM 缓升） |
| `decay_wait` | 4.0 per s | 深海等待时的 ALARM 衰减 |
| `ALARM_cap` | 100 | 通缉度上限 |
| `p_deep(A)` | `clamp((A−40)/300, 0, 0.20)` | 深水死亡概率 |
| `p_surf(A)` | `p_beach + clamp(0.60·((A−15)/80)^2, 0, 0.60)` | 冲浪死亡概率 |
| `p_beach` | 0.03（专家）/ 0.15（新手） | 搁浅风险，**技巧相关** |

**关键设计点**：`p_surf` 中的 `p_beach`（搁浅）是**技巧项**——高手能把它从 0.15 压到 0.03。这意味着**冲浪路径的收益随玩家水平提升**，正是支柱四要的"可练的技巧轴"。

## 2. ⚠️ 核心发现：原验收标准自相矛盾

### 2.1 原标准

> 概念文档 v1.0 §3.2：**浅滩路径的期望收益 ≥ 深水路径 × 1.5，且方差显著更大。**

### 2.2 它为什么是错的

这条标准隐含"**在所有状态下**浅滩都要 ≥1.5×"。但如果浅滩在所有状态都更优，**深水就是死内容**——这正是 R1 本来要防止的失败。

**标准与其自身的目的互相矛盾。**

### 2.3 数据验证（70 组参数扫描）

| 判据 | 命中数 | 占比 |
|---|---|---|
| 扫描配置总数 | 70 | 100% |
| **C1**：低 ALARM 时比值 ≥ 1.5 | 39 | 56% |
| **C1 但非 C2**（浅滩在所有状态都更优 → **深水死内容，R1 失败**） | **29** | **41%** |
| **C1 且 C2**（存在深水反超的状态 → 无主导策略） | **10** | **14%** |

**29 个配置"通过"了 v1.0 的标准，但其中每一个都是 R1 的真实失败案例。** 这证明原标准不但无效，而且有害——它会让一个坏设计顺利过审。

### 2.4 修订后的验收标准（v1.1）

> **C1 · 低 ALARM 优势**：`k=1`（单次捕食）时，冲浪/深水期望收益比 **≥ 1.5**
> → 保证冲浪路径不是死内容
>
> **C2 · 高 ALARM 反超**：**存在**押注量 k 使比值 **< 1.0**
> → 保证深水路径不是死内容（无主导策略）
>
> **C3 · 押注有牙齿**：全局最优押注数 **k ≥ 2**
> → 保证 Bank-or-Push 决策有意义（若 k=1 恒最优，押注形同虚设）

三条**必须同时成立**，缺一不可。

## 3. 推荐配置

**`m_surf = 2.6`，`A_grab = 20`**

> 换算：`m_surf = 1 + 0.2 × C` → **冲浪路线需布置 8 个收集物**（C=8）
> `A_grab = 20`：每次捕食 ALARM +20（概念文档 v1.0 写的 +25，此处下调 5）

### 3.1 专家（p_beach = 0.03）

| k | ALARM(avg) | 深水 速率 (p) | 冲浪 速率 (p) | 比值 | 更优 |
|---|---|---|---|---|---|
| 1 | 28.8 | 5.68 (0.000) | **9.94** (0.048) | 1.75 | 冲浪 |
| **2** | 53.8 | 7.69 (0.000) | **12.72** (0.171) | 1.65 | **冲浪（全局最优）** |
| 3 | 78.8 | 7.97 (0.070) | **10.71** (0.411) | 1.34 | 冲浪 |
| 4 | 100.0 | **7.70** (0.153) | 7.63 (0.630) | 0.99 | **深水反超** ✓ |

### 3.2 新手（p_beach = 0.15）

| k | ALARM(avg) | 深水 速率 (p) | 冲浪 速率 (p) | 比值 | 更优 |
|---|---|---|---|---|---|
| 1 | 28.8 | 5.68 (0.000) | **8.69** (0.168) | 1.53 | 冲浪 |
| **2** | 53.8 | 7.69 (0.000) | **10.88** (0.291) | 1.41 | **冲浪（全局最优）** |
| 3 | 78.8 | **7.97** (0.070) | 8.53 (0.531) | 1.07 | 冲浪（勉强） |
| 4 | 100.0 | **7.70** (0.153) | 5.16 (0.750) | 0.67 | **深水反超** ✓ |

### 3.3 三条判据检验

| 判据 | 专家 | 新手 | 结论 |
|---|---|---|---|
| **C1**（k=1 比值 ≥1.5） | 1.75 ✅ | 1.53 ✅ | 通过 |
| **C2**（存在 k 使比值 <1.0） | k=4 → 0.99 ✅ | k=3 → 1.07 / k=4 → 0.67 ✅ | 通过 |
| **C3**（最优 k ≥ 2） | k=2 ✅ | k=2 ✅ | 通过 |

### 3.4 这个配置的设计含义（比数字更重要）

1. **最优策略是"押 2 个再走"** —— 押 1 个太保守（8.69–9.94），押 4 个太贪（深水反超）。这给了 Bank-or-Push 一个明确的、可学习的答案，同时保留犯错空间。
2. **换路点是可学的**：专家在 ALARM≈100 才换路，新手在 ALARM≈79 就该换。**技巧水平直接延长了冲浪窗口**，这正是"胜任感"的数值化体现。
3. **`k=4` 时冲浪被反超** —— 贪心到顶就必须走安全路线，"贪婪有代价"落地为真实数值，不是口号。
4. **冲浪路线必须放 8 个收集物** —— 这是一个具体的关卡设计约束，直接可交给关卡 GDD。

## 4. DECOY BREACH 验证

**验收标准**：期望收益 ≤ 直接突袭 × 1.2

**模型**：重定向**最多 2 个**敌人；敌人停机 = `2.5s 调查 + 2×往返/敌速`；熟练操作覆盖返程窗口约 60%；代价 = −1 体力 + ALARM +8。

| k | 直冲速率 | 诱饵速率 | 比值 | 判定 |
|---|---|---|---|---|
| 1 | 9.943 | 9.447 | **0.95** | ✅（甚至略亏） |
| 2 | 12.720 | 12.837 | 1.01 | ✅ |
| 3 | 10.709 | 11.850 | 1.11 | ✅ |
| 4 | 7.635 | 9.560 | **1.25** | ⚠️ 超标 |

### 4.1 结论

在**玩家实际会选择的区间（k=1–3）内全部达标**，且表现出良好的自我平衡特性：

- **k=1 时诱饵略亏（0.95）** —— 低 ALARM 时敌人本就少，没什么可引开的，代价白付。这是**正确的设计**：诱饵不该在低压力时无脑用。
- **k=2 几乎持平（1.01）** —— 边际选择，用不用看个人风格。
- **k=3 开始有价值（1.11）** —— 敌人多了，调度才有意义。

### 4.2 k=4 超标的处理（推荐主题化解法）

`k=4` 超标 0.05，但该状态本身已是次优解（速率 7.63 vs 全局最优 12.72），理性玩家不会主动进入。不过为稳妥起见，建议用**主题化**而非数值化手段修复：

> **裁定：直升机（T3/T4）免疫诱饵。只有水面单位（救生员、摩托艇）会被水花吸引。**

理由：
- **主题自洽** —— 直升机在空中，不会去追一个水花；它本来就靠探照灯锁定，不吃这套
- **精确生效** —— 诱导的超标恰好发生在 ALARM 79–100（直升机出场区间），豁免它等于精准掐掉超标区间
- **可教学** —— "炸水只能骗水面的人，骗不了天上的"是一句玩家一听就懂的规则
- **保留价值** —— 诱饵在 T1/T2 压力区间（k=2–3）依然有效，技巧不失效

若 playtest 后仍需数值兜底，次级杠杆：ALARM 代价 +8 → +16，或窗口覆盖率 60% → 50%。

## 5. 敏感性分析（调参杠杆排序）

基准：`m_surf=2.6, A_grab=20, expo=2.0, scale=0.60` → 比值(k=1) = 1.750

| 杠杆 | 新比值 | 变化 | 评价 |
|---|---|---|---|
| **`m_surf` +20%** | 2.100 | **+0.350** | 🔴 **最强杠杆**，线性生效 |
| **`m_surf` −20%** | 1.400 | **−0.350** | 🔴 同上 |
| **冲浪 ALARM 斜率 0.5→1.5** | 1.522 | −0.229 | 🟠 次强；调它可压缩冲浪窗口 |
| **深海衰减 4→6 /s** | 1.917 | +0.167 | 🟠 衰减越快，深水越安全 → 冲浪相对更好 |
| `A_grab` −5 | 1.843 | +0.093 | 🟡 弱 |
| `A_grab` +5 | 1.693 | −0.057 | 🟡 弱 |
| 死亡曲线指数 2.0→2.5 | 1.769 | +0.019 | 🟢 几乎无影响 |
| 死亡曲线指数 2.0→1.5 | 1.704 | −0.046 | 🟢 几乎无影响 |

**结论**：

1. **`m_surf`（冲浪路线收集物数量）是唯一需要精调的参数**，其余都是粗调。关卡设计阶段必须锁定"冲浪路线放 8 个收集物"，改动需回跑本沙盘。
2. **`A_grab` 与死亡曲线形状是弱杠杆** —— 说明模型对这些不敏感，playtest 时可优先用它们做手感微调，不易破坏平衡。
3. **深海衰减速率是隐藏杠杆** —— 它同时影响"龟缩收益"和路径比值，改动时需连同 §1 的"龟缩 = 零收益"机制一起复核。

## 6. 结论与风险

### 6.1 门控结论

| 项 | 结论 |
|---|---|
| 两条路径能否平衡？ | ✅ **能**。存在可行配置（`m_surf=2.6, A_grab=20`） |
| 是否存在主导策略？ | ✅ 无。低 ALARM 冲浪优（1.75×），ALARM 顶满深水反超（0.99×） |
| Bank-or-Push 是否有意义？ | ✅ 有。最优押注数 k=2，押 1 太保守、押 4 太贪 |
| DECOY BREACH 是否过强？ | ✅ 否（k=1–3 为 0.95–1.11）；k=4 超标 0.05，建议用"直升机免疫"主题化修复 |
| **原验收标准是否有效？** | ❌ **无效且有害**，已修订为 C1+C2+C3 三条（§2.4） |

### 6.2 残留风险

| # | 风险 | 说明 |
|---|---|---|
| S1 | **参数未经 playtest** | 死亡概率曲线、行程时间、收集物数量全是假设值。模型能证明"结构可平衡"，不能证明"数值好玩" |
| S2 | **ALARM 棘轮未建模** | 本模型假设玩家总能把 ALARM 衰减回 0。实际中"少等一会儿、让 ALARM 逐轮累积"是第三条策略轴，需要 Phase 2 用完整仿真补充 |
| S3 | **方差未量化** | 冲浪路径方差显著更大（死亡概率 0.048→0.630 vs 深水 0→0.153），符合原标准的定性要求，但未做蒙特卡洛验证 |
| S4 | **`p_beach` 技巧曲线是猜测** | 0.15→0.03 的熟练度区间需要实测；它直接决定冲浪路径对新手是否过于劝退 |

### 6.3 给 Phase 2 的交接项

1. **锁定**：冲浪路线布置 **8 个收集物**（`m_surf=2.6`），每次捕食 `ALARM +20`
2. **纳入 GDD**：`PH1-concept-doc.md` §3.2 的 R1 标准已按 C1/C2/C3 重写
3. **补做**：ALARM 棘轮策略的完整仿真（S2）
4. **补做**：`p_beach` 的实测技巧曲线（S4）—— 建议在 MVP 可玩后立刻安排 5–8 人小样本测试
5. **裁定**：DECOY BREACH 的"直升机免疫诱饵"是否需要写进美术侧敌人响应 VFX
