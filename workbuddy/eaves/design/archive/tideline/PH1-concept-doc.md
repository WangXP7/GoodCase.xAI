## 1. 游戏概述

### 1.1 Elevator Pitch

> **一句话**：
> 你是一条鲨鱼。冲上沙滩叼走游客，在救生艇包围中杀回深海——问题是，你已经叼住的那一个，要不要够胆去换下一个更大的？

**备选命名**（按推荐度排序，待用户拍板）：

| 名称 | 气质 | 备注 |
|---|---|---|
| **《潮线 TIDELINE》** | 冷峻、有地理感、暗示"越线即危险" | 首选。英文短名易记，契合复古街机卡带命名 |
| 《退潮之前》 | 有时限压迫感、略文艺 | 中文语感好，英文化较难 |
| 《BITE / 咬》 | 极简、街头涂鸦感 | 街机味最足，但信息量偏少 |

### 1.2 目标用户画像

**核心用户 · "榜单猎手"**：18–35 岁，PC + 手机双端，单局 2–15 分钟碎片时间，已在玩 Vampire Survivors / Balatro / Jetpack Joyride / Crossy Road 一类"再来一把"型游戏。Bartle 类型以 **Achiever 为主、Killer 为辅**——解锁刷分是主驱动，排行榜是复访驱动。他们决定**技巧天花板**，是我们设计深度的对象。

**次级用户 · "梗图传播者"**：15–28 岁，被"鲨鱼叼人"的黑色幽默和复古像素吸引，会截图/GIF 分享。他们决定**传播量**——因此我们必须设计"天生可截图的高光瞬间"（见 §6 锚点 02、04）。

**反目标用户**：寻求长线养成的玩家（那是 Hungry Shark 的地盘）、寻求恐怖惊吓的玩家（见 §3.3，我们不做恐惧）。

### 1.3 竞品差异化定位

| 维度 | Hungry Shark 系列 | Jetpack Joyride | Crossy Road | **《潮线》（我们）** |
|---|---|---|---|---|
| 视角 | 3D 开放海域 | 横版侧视 | 伪 3D 方格 | **横版侧视分层水体** |
| 单局时长 | 5–15 分钟 | 1–3 分钟 | 30 秒–2 分钟 | **2 分钟（含押注可延长）** |
| 核心结构 | 无尽吞噬 + 养成 | 无尽跑酷 | 无尽穿越 | **押注—结算（Push Your Luck）** |
| 决策性质 | 反应 + 资源管理 | 纯反应 | 纯反应 + 时机 | **反应 + 风险估值** |
| 玩家身份 | 掠食者（全能） | 逃亡者（喜剧） | 路人（荒诞） | **掠食者 → 猎物（身份反转）** |
| 商业化 | 重度 IAP | 轻度 IAP | 轻度 IAP | **无 IAP（网页免费）** |
| 美术 | 3D 卡通 | 2D 卡通 | 体素 | **复古灰阶 + CRT** |

**定位陈述**：

> 我们把**无尽跑酷的即时爽感**和**赌桌上的估值博弈**焊在了一起。
> 市面上的街机游戏让你"反应"，《潮线》让你在反应之外，每一秒都在回答同一个问题：**"再贪一个，还是见好就收？"**

**三条不可让渡的差异点**：

1. **身份反转**——空手时你是猎手，叼着人时你是猎物。这是市面上没有的情绪结构。
2. **原子化的押注循环**——捕食不是"积累"，是"下注—结算"。这带来了跑酷游戏罕有的策略张力。
3. **反派视角的黑色喜剧**——不恐怖、不说教、不拟人化抹黑。玩家是明目张胆的坏蛋，但也因此痛快。

## 2. 设计支柱（Design Pillars）

四根支柱，互相咬合。评审任何新功能时，先问它服务哪根支柱；服务不了的，砍。

### 支柱一 · 身份反转（Predator ↔ Prey）

- **定义**：叼走游客的那一瞬间，游戏的权力结构翻转。你从"制造恐惧的人"变成"被追捕的人"。
- **在玩法中**：携带状态下速度 −30%、转向迟钝、冲刺消耗翻倍，并持续产生**水花**——水花是可见的，会主动把救生员引过来。你手里的战利品同时是你的通缉令。
- **在界面中**：携带时整个 HUD 的强调色从琥珀（攻）切到血红（逃）；ALARM 条开始闪烁；画面边缘出现收拢的追捕指示箭头。
- **在音效中**：音乐从低沉的脉冲 Bass 切换为急促的军鼓 + 逐渐逼近的引擎声（交由阮和鸣落地）。
- **为什么是第一支柱**：它是这个游戏唯一无法被复制的东西。美术可以被抄，押注结构可以被抄，但"你越成功越脆弱"的情绪转换是《潮线》的身份。

### 支柱二 · 一局一押（One Run, One Bet）

- **定义**：捕食循环是**原子**的——潜行 → 冲刺 → 捕食 → 逃生 → 回深海结算，五步走完才算数，中途死亡则本次押注全损。
- **在玩法中**：回深海"消化"即 bank，落袋为安；带着已捕获的战利品再次冲滩则**收益按指数放大，但风险同步放大**。这是全游戏最重要的决策点。
- **在界面中**：Bank 区域有明确的视觉门槛（深海光柱 + 结算数字上浮动画）；冲滩前有一次醒目的"继续贪婪？"提示。
- **在音效中**：Bank 时是清脆的"落袋"音 + 短暂的和弦解决；贪婪冲滩时是不解决的减和弦。
- **与支柱四的张力及解法**：支柱四要求"每局必有进展"，支柱二要求"贪婪会输"。二者不冲突——**结算的是保底收益，押注的是超额收益**。失败局仍然拿到 bank 过的部分，只是没拿到赌注。这是设计好的，不是妥协。

### 支柱三 · 灰度中的一抹血色（Monochrome + One Accent）

> ⚠️ **精确定义（v1.1 修订）**：**「一抹」= 稀缺性，不是单色性。**
> 本支柱从未主张"全项目只存在一个颜色"——那既不现实也无必要。它的本体是**面积配额**：在灰场中，高彩度必须稀缺到能瞬间抓眼。是一个**稀缺度**问题，不是一个**颜色数量**问题。

- **定义**：灰黑为底，**稀缺的高彩度**承载全部关键信息。任何时刻，玩家扫一眼就能读懂"我在哪、我危险吗、我该做什么"。
- **在玩法中**：危险梯度直接映射为明度梯度——深海最暗（安全，8%）、浅滩中灰（28%）、冲浪区亮（55%）、沙滩近乎纯白（82%，最暴露）。玩家用**亮度**就能判断处境，不需要看 HUD。（量化表见美术圣经 §5.3.0）
- **在界面中**：强调色仅用于三处——ALARM 通缉条、COMBO 数字、可交互目标（游客/道具）。其余一律灰阶。像素字体，粗描边。
- **在音效中**：留白多，反馈音效短促（< 200ms），不铺满。

**强调色分级与配额**（与美术圣经 §2.6 一致，作为后续一切配色的闸门）：

| 层级 | 色 | 定位 | 面积配额 | 解锁 |
|---|---|---|---|---|
| **L0 · 主强调色（唯一）** | `#FF3B3B` 血红 | **「那一抹血色」本体**，全项目的视觉签名 | **≤ 3%**（超过即失去稀缺性） | MVP |
| **L1 · 状态色** | `#FF8A3D` 琥珀 / `#F2F5F8` 炽白 | 与血红共同构成 ALARM 的明度+色相双梯度 | 合计 ≤ 5% | MVP |
| **L2 · 功能色** | 绿 / 蓝 / 紫 | 仅功能区分，**绝不与 L0 同时大面积出现** | 计入总额 | Standard |
| **专用不占配额** | `#FF2E88` 洋红 | 捕食瞬时反馈（0.6s），语义见下 | 事件性 | MVP |

**总量硬约束**：MVP 高饱和 ≤ **5%** 屏幕面积；Standard ≤ **8%**。

**红的语义分流（避免"我危险"与"它危险"混淆）**：
- **状态红**（ALARM 条 / 屏幕边缘 / 搁浅 QTE 环 / 追捕箭头）= "**你**处境危险" → 计入 L0 配额
- **对象红**（救生员 / 高危敌人配色）= "**这个目标会反击**" → 计入 L1，且仅限条纹等小面积（≤1%）

- **可读性红线**：**同一时刻最多允许一个屏幕级特效发生**（色闪 / 震屏 / 扫描线抖动 三选一，优先级递减）。复古风 + CRT + 震屏叠在一起极易糊成一团，这是必须写进美术与程序规范的硬约束。
- **顿帧是时序事件，不是视觉特效**：它不增加视觉信息量（只是暂停逻辑），因此**不占上述三选一的名额**，可与任意一个共存。捕食瞬间 = 顿帧 + 震屏。

### 支柱四 · 两分钟精通曲线（Two-Minute Mastery Loop）

- **定义**：两分钟内给完一次完整的情绪起落；无论输赢，结束时玩家都能带走一点东西。
- **在玩法中**：单局 90–150 秒；重试摩擦趋近于零（死亡到可操作 ≤ 1.5 秒）。
- **在界面中**：结算页 ≤ 3 秒可读完，只呈现三件事——**本局得分 / 本局最亮的一刻 / 下一次的目标**。
- **在进度上**（借鉴 Jetpack Joyride 的"Addiction Engine"）：**每局同时挂 3 个微型目标**（例："叼走 1 个救生员" / "达成 8 连击" / "零搁浅逃生"）。短局也是有效局，失败也是进展。
- **自我决定论映射**：
  - **自主性 Autonomy**——逃生走深水还是浅滩、升级走哪条线、见好就收还是加注，都是玩家的真实选择
  - **胜任感 Competence**——Combo 上限、搁浅 QTE 熟练度、ALARM 管理，三条可练的技巧轴
  - **归属感 Relatedness**——本地/全球榜单、可截图的高光瞬间、每日挑战的社交货币

## 3. MDA 分析

### 3.1 Mechanics（机制）——玩家能做什么

**动词清单（Verb-First）**，按重要性排序：

| 动词 | 输入 | 说明 |
|---|---|---|
| **游 / Swim** | 方向（持续自动前进） | 鲨鱼**永不停止**，玩家控制的是方向与深度，不是"走不走" |
| **下潜 / 上浮** | 上下 | 深度决定隐蔽度与可达目标 |
| **冲刺 / Dash** | 单键 | 短时爆发，消耗体力；出水可跃起 |
| **咬 / Bite** | 冲刺命中自动触发 | 命中即叼走，进入携带状态 |
| **携带 / Carry** | 被动状态 | 全属性下降 + 产生水花（暴露） |
| **甩尾挣脱 / Thrash** | 连打 | 搁浅时的 QTE 逃脱 |
| **冲浪 / Surf** | 贴浪面自动进入 | 副循环入口，可收集道具 |
| **结算 / Bank** | 进入深海自动触发 | 押注落袋，ALARM 开始衰减 |

**鲨鱼状态机**：`巡游 Cruise` → `冲刺 Dash` → `咬合 Bite` → `携带 Carry` → (`搁浅 Beached` / `眩晕 Stunned`) → `死亡 Dead`

#### 生存模型 · 一击致命（v1.1 明确）

> ⚠️ **本作没有生命值，也没有饥饿/氧气槽。** 这是有意的，不是遗漏。

| 结论 | 理由 |
|---|---|
| **一击致命** | 生命值会**摧毁支柱二**：有 3 条命，赌输还有兜底，"押注"就没有牙齿了。街机传统（Jetpack Joyride / Crossy Road / Geometry Dash）全是一击致命——正因为重试成本极低，才撑得起"2 分钟一局 + 重试摩擦为零" |
| **无饥饿槽** | HUNGER 逼玩家**贪婪**，ALARM 逼玩家**稳健**，两个压力源把玩家往相反方向拉 = 认知过载。全项目的压力统一由 **ALARM 单一维度**承担 |
| **龟缩的解法** | ALARM 只在深海区衰减，而深海区**零分数产出** → 龟缩 = 零收益，自然惩罚，不需要第二个压力源 |

**致命事件（一击致死）**：直升机探照灯锁定满 3 秒 · 搁浅 QTE 失败 · （Standard）捕鲨队命中

**非致命阻碍（保留，避免小碰撞劝退）**：撞轮胎 = 减速 · 渔网 = 束缚 1.5s · 救生员浮标命中 = **眩晕**（不是掉血）

> **设计推论**：`hurt`（受击）在本作**不是一个状态**，只是命中瞬间的 3 帧动画，随后进入 `stunned` 循环。角色表情中"饥饿/满足"与饥饿槽无关，改绑到「空手 / 携带中或刚 Bank」两个状态。

**三个数值系统（雏形，待 Phase 2 验证）**：

1. **ALARM 通缉度（0–100）**——全局压力计。叼走游客 **+20**（沙盘校准值，v1.0 为 +25）；在浅滩显眼处停留每秒 +2；深海区衰减每秒 −4。分级触发敌人：
   - `0–24` 平静：只有游泳游客
   - `25–49` 警戒：出现**救生员**（岸上投掷浮标，命中致眩晕）
   - `50–74` 追捕：出现**摩托艇**（横向拦截，撞击掉战利品）
   - `75–100` 围剿：出现**直升机**（探照灯锁定，锁定 3 秒 = 死亡）+ 捕鲨队
2. **体力 / Stamina**——**冲刺资源，不是生存资源**。三格制，携带状态下消耗翻倍，浅滩冲浪时缓慢回复。⚠️ 与"饥饿/氧气槽"无关，不要混为一谈。
3. **COMBO 连击**——副循环计分。收集窗口 2.5 秒，倍率 `1 + 0.2 × combo 数`，上限 ×5（MVP 上限 ×3）。
   - ⚠️ **COMBO 倍率放大的是「捕食结算分」**，不是独立的收集分。**只冲浪不捕食 = 分数趋近于零**（见 §4.4 数值焊接）。
   - 🔒 **冲浪路线须布置 8 个收集物**（`m_surf = 2.6`）—— 沙盘锁定的关卡约束，改动需回跑 `PH1-R1-numerical-sandbox.md`。

**关键机制 · 搁浅（Beached）**：
在沙滩区停留超过阈值时间且速度不足时，鲨鱼**侧翻搁浅**，进入连打 QTE（示意：2.5 秒内 6 次有效输入）。QTE 期间 ALARM 飙升，游客围观（纯演出，无威胁）。成功则弹回水中；失败则死亡。

> ⚠️ **重要设计说明**：原型当前的"鲨鱼卡在沙滩上"是一个**物理/碰撞 Bug**。我建议**不要单纯修掉它，而是把它设计化**——保留这个状态，给它明确的触发条件、明确的逃脱方式、明确的后果，并配上全游戏最有戏剧性的一帧演出（见 §6 锚点 04）。一个恼人的 Bug 就此变成游戏最被记住的机制。这需要与程基岩确认碰撞层与沙滩边界的处理方式（经主理人中转）。

| 项 | 值 | 备注 |
|---|---|---|
| **鲨鱼体长** | **168 px**（@1440×864） | 🔧 **playtest 可调常量**，见下 |
| 鲨鱼巡游速度 | 6 m/s | |
| 冲刺速度 / 时长 / 冷却 | 14 m/s / 0.8s / 1.2s | |

| 道具基础分 | 瓶子 10 / 星星 20 / 圆环 30 | 主要产出为 COMBO 与货币 |

**关于鲨鱼体型的范围裁决**：「鲨鱼进化线（幼鲨 → 大白鲨 → 巨齿鲨）」归入 **Epic** 层，**MVP 与 Standard 只做单档体型**。

- 支柱闸门检验：多档成长**一根支柱都不服务**，反而稀释支柱二——体型一变，风险估值的心算基础就动摇了
- 选 168px 而非 120px：120px 下叼着的游客仅 ~35–40px，"四肢像素级抖动"（支柱一的具象化，锚点 03）读不出来
- 选 168px 而非 300px：300px 占 35% 屏高，逃生跑道被挤没
- 168px → 1440/168 = **8.6 个身长横向跑道**，864/168 = **5.1 个身长纵向水柱**

> 🔧 **因为砍到单档，体型现在是一个可调常量而不是资产承诺**——playtest 后改一个数字即可，美术侧零返工（美术圣经 §4.1.5 已按单套素材规划，省约 60% 角色素材）。

### 3.2 Dynamics（动力学）——玩家会想什么

**四个核心决策点**：

1. **Bank or Push（最重要的决策）**
   手里已有一个泳客，前方 20 米有个冲浪者（价值更高），但 ALARM 已经 60，摩托艇马上到。走还是留？
   → 这是全游戏的心跳。它把"反应游戏"变成了"估值游戏"。

2. **逃生路径的空间化风险抉择**
   回收深水有两条路：**深水路**（暗、安全、道具少、慢）vs **浅滩冲浪路**（亮、危险、道具密集、可高速冲浪）。
   → 风险与收益被映射成**地图上的左右**，玩家用身体而不是用菜单来做决策。

3. **ALARM 的主动管理**
   是否花 10 秒潜伏在深水让 ALARM 衰减，牺牲节奏换安全？
   → 给急性子玩家一个"忍"的理由，让节奏有呼吸。

4. **暴露作为资源（高阶）· DECOY BREACH / 声东击西**
   详见下方专节。

#### ⭐ DECOY BREACH / 声东击西（v1.1 新增机制）

> **修错说明**：本文 v1.0 在 §3.1 把携带水花写成**被动持续产生**，却在 Dynamics 宣称玩家可"故意制造水花引开敌人"。**被动产生的东西玩家无法主动操控，就构不成技巧**——v1.0 等于宣称了一个自己的机制不支持的涌现玩法。此处补完。

**触发**：**冲刺状态中穿出水面**（Dash + Surface Crossing，复合输入）

> 为什么不是独立按键：移动端只有 1.5 个输入自由度，塞不下新键；且出水本身就是高风险动作，天然带代价。

| 项 | **L1 · 携带拖尾（被动）** | **L2 · 炸水 DECOY BREACH（主动）** |
|---|---|---|
| 触发 | 携带状态持续 | 冲刺中穿出水面 |
| 半径 | 40 px | **160 px**（4×） |
| 粒子 | 6/秒，2–3px 方块，寿命 1.2s | **25–40**，3–5px 方块，径向爆发，寿命 0.6s |
| 附加 | — | 环形冲击波（1px 描边圆环，0.4s 内 0→180px） |
| 功能 | 给追兵大致方向（**debuff**） | **强制重定向敌人至爆点** |

**机制效果**：重定向**最多 2 个**敌人至爆点。敌人停机时间 = `2.5s（调查） + 2 × 往返路程 / 敌速`。
→ **重定向固定数量而非固定比例**，因此高 ALARM（敌人多）时自动衰减收益，天然自我平衡。
→ **技巧点在"在哪炸"而非"要不要炸"**：炸得离航线越远，往返路程越长，停机时间越久；但游到炸点本身也有成本。

**代价**（没有代价的技巧会退化成无脑最优解）：

| 代价 | 值 | 后果 |
|---|---|---|
| 体力 | −1 格 | 逃生段可能没冲刺可用 |
| ALARM | +8 | 制造诱饵让全局压力上升 |
| 暴露 | 出水瞬间无遮蔽 | 直升机在场时 = 锁定加速 |

**为什么它现在是真技巧**：✅ 主动输入 ✅ 空间博弈（A 点炸水 → B 点突袭） ✅ 时间窗口 ✅ 失败可能（+8 可能直接跨 75 阈值招来直升机） ✅ 可练可精（判断"值不值这一炸"正是支柱二要的估值能力）

**范围**：**Standard**。MVP 里携带水花是纯 debuff，已足够支撑支柱一；但两级水花的视觉规格现在就定，美术从一开始按两级设计。

**防主导策略验收**：**DECOY BREACH 期望收益 ≤ 直接突袭 × 1.2**（数值沙盘已验证，见 §8.1 R1 与 `PH1-R1-numerical-sandbox.md`）

**涌现玩法预判**：**声东击西**（DECOY BREACH 的空间调度）、**贴浪极限**（在搁浅阈值边缘反复试探，换最高速冲浪连击，风险自找收益自担）、**连击搭桥**（先冲浪攒 COMBO 再叼人，用倍率放大结算分）、**Alarm 冲浪**（故意把 ALARM 顶在 74 不到 75，刷高难敌人换高价值目标）。后三条是我们希望玩家自己发现、并在社群传播的东西。

**风险登记 · 主导策略（Dominant Strategy）预警**：

> 🚨 若"深水逃生"在期望收益上永远优于"浅滩冲浪路"，浅滩路径就是死内容，支柱二的抉择随之瓦解——反之亦然。

**⚠️ v1.1 修订：原验收标准作废。** 原文写的是"浅滩期望收益 ≥ 深水 × 1.5"，但这隐含"在所有状态下浅滩都更优"，而那恰恰意味着**深水变成死内容**——标准与其自身目的互相矛盾。

> **数值验证（70 组参数扫描，见 `PH1-R1-numerical-sandbox.md` §2）**：
> 39/70 配置满足原标准（≥1.5×），但其中 **29 个是浅滩在所有状态都更优的真实失败案例**。
> 换言之，原标准会让一个坏设计顺利过审——它不但无效，而且有害。

**修订后的硬性验收标准（三条必须同时成立）**：

| 判据 | 定义 | 防的是什么 |
|---|---|---|
| **C1 · 低 ALARM 优势** | `k=1`（单次捕食）时，冲浪 / 深水期望收益比 **≥ 1.5** | 冲浪路径变死内容 |
| **C2 · 高 ALARM 反超** | **存在**押注量 k 使比值 **< 1.0** | 深水路径变死内容（主导策略） |
| **C3 · 押注有牙齿** | 全局最优押注数 **k ≥ 2** | Bank-or-Push 形同虚设 |

**沙盘结论（✅ 已通过）**：推荐配置 `m_surf=2.6`（冲浪路线布置 **8 个收集物**）、`A_grab=20`（每次捕食 ALARM +20）。

| | 专家 | 新手 |
|---|---|---|
| k=1 比值 | 1.75 ✅ | 1.53 ✅ |
| 最优押注数 | **k=2** | **k=2** |
| 深水反超点 | ALARM≈100 | ALARM≈79 |

→ 最优策略是"**押 2 个再走**"；换路点随技巧水平后移（79→100），技巧直接延长冲浪窗口。详见 `PH1-R1-numerical-sandbox.md`。

**明确的情绪禁区**：
- ❌ **不做恐惧（Fear）**。我们不是恐怖游戏。追捕的紧张是"刺激的紧张"，不是"吓人的紧张"。区别在于：玩家应该**主动追求**高 ALARM 状态，而不是逃避它。

- ❌ **不说教**。不做环保主题、不做海洋保护彩蛋说教。玩家就是反派，爽就完了。

### 4.2 主循环（Primary Loop）· 90–150 秒

**潜行 → 冲刺 → 捕食 → 逃生 → 结算**

- **潜行**：从深海出发，在暗处观察。此阶段无威胁，是"读盘"时间——玩家在扫描目标价值、追兵位置、ALARM 余量。
- **冲刺**：一次爆发性突进。出水瞬间是全游戏最爽的一帧（见 §6 锚点 02）。
- **捕食**：命中即进入携带状态，**身份在此刻反转**。
- **逃生**：核心压力段。速度下降、水花暴露、追兵收拢。玩家在此选择路径与是否加注。
- **结算**：回到深海，战利品落袋，ALARM 衰减，进入押注决策点。

**循环的自增强**：每一轮循环结束，ALARM 基础值提升一档，敌人等级提升，但目标价值也提升。玩家必须不断精进才能维持收益——这是难度的自然爬升，不需要额外设计。

### 4.3 副循环（Secondary Loop）· 嵌套在主循环之内

**冲浪 → 收集 → 连击 → 升级 → 解锁**

关键设计：**副循环不是独立小游戏，它就长在主循环的逃生路径上。**

- 逃生途中经过冲浪区时，贴浪面自动进入 **Surf Mode**，鲨鱼侧身滑行
- 冲浪路径上分布瓶子 / 星星 / 圆环，按**弧线轨迹**排布（天然引导最优路线，形成"节拍"）
- 每收集一个，COMBO +1，倍率上升，数字字号逐次放大、颜色由琥珀转向炽白
- **COMBO 倍率直接放大本次捕食的结算分**——这就是两个循环的焊点

### 4.4 双循环如何交织（防支柱漂移的关键）

> 🚨 **风险登记 · 双循环割裂**：若收集只是"顺路捡捡"，玩家会直接无视它，副循环沦为装饰，开发与美术投入全部白费。

**三道焊接工艺**：

1. **空间焊接**——收集物**只**生成在逃生路径上。你想收集就得冒险，想安全就两手空空。收集与安全**互斥**。
2. **数值焊接**——COMBO 倍率放大的是**捕食结算分**，不是独立的收集分。只冲浪不捕食 = 分数趋近于零；只捕食不冲浪 = 拿不到超额收益。
3. **货币焊接**——双货币分驱：
   - 🩸 **Biomass（生物量）**——来自捕食，驱动**鲨鱼能力树**（速度、咬合力、体力、挣脱速度）
   - 🐚 **Trinket（拾珍）**——来自收集，驱动**冲浪装备树**（连击窗口延长、道具磁吸、倍率上限提升）
   - 两棵树**互相解锁**——能力树需要少量拾珍才能升满，反之亦然。任何一条腿走路都会撞墙。

## 6. 视觉锚点

> 本节是给美术（林绘澄）的**情绪板文字版**。五个锚点定义了这个游戏"看起来是什么感觉"。详细色板、像素规格、动画帧数由 `design/art-bible/art-bible.md` 承接。

### 锚点 01 · 深蓝边境的静默（The Threshold）

屏幕左侧三分之二是近乎墨色的深灰蓝，像素化的光柱从水面斜切而下，在暗处形成几道柔和的梯形。鲨鱼的剪影半隐在暗部，只有背鳍的轮廓和一只反光的眼睛是亮的。右侧远处，一条极细的琥珀色横线——那是沙滩，是诱惑，也是死地。

**情绪**：屏息。这是玩家的呼吸点，也是每一次赌博的起点。
**设计功能**：让玩家在安全时感受到"对岸的光"的吸引力。没有这一帧的静，就没有后面冲刺的爽。

### 锚点 02 · 破水瞬间（The Breach）

鲨鱼冲出水面，身体与水面的浪尖呈 30 度角。水花不是柔和的粒子，而是**大块的粗白像素方块**向外炸开，边缘锐利。一个游客的剪影被抛在空中，四肢张开。屏幕震动 4 帧，CRT 扫描线在这一瞬间骤然加粗。整个画面的色彩从灰蓝瞬间压成**高对比黑白 + 一抹血红**。

**情绪**：爆发。全游戏最爽的一帧。
**设计功能**：这是**天生的截图/GIF 素材**——次级用户传播的核心资产，必须做到最好。

### 锚点 03 · 叼着人的逃亡（The Getaway）

鲨鱼嘴里叼着一个挣扎的小人，小人的四肢以像素级幅度高频抖动（不需要精细动画，抖就对了）。身后三道白色 V 形尾迹正在收拢，那是快艇。鲨鱼身后的水花拖尾在暗色海面上连成一条显眼的亮线——**你自己的暴露轨迹**。HUD 右上角的 ALARM 条正在闪红。

**情绪**：身份反转的具象化。爽，但手心出汗。
**设计功能**：一帧讲清三个信息——我拿到了什么、谁在追我、我有多显眼。

### 锚点 04 · 搁浅（Beached）

鲨鱼侧躺在沙滩上，尾鳍一下一下拍打沙面，扬起小簇沙尘。画面几乎只剩**灰与白两色**——没有水，没有掩护，无处可藏。周围是一圈围观游客的剪影（静止、滑稽、不构成威胁）。屏幕中央一个 QTE 圆环正在收缩，边缘的强调色从琥珀转为血红。

**情绪**：脆弱、滑稽、命悬一线。全游戏最戏剧的一帧。
**设计功能**：把失败状态变成**可传播的名场面**。这也是原型 Bug 设计化之后的产出（见 §3.1）。

### 锚点 05 · 冲浪连击（Surf Combo）

鲨鱼侧身贴着浪面滑行，浪尖卷曲成一条粗白像素弧线。一串道具（瓶 / 星 / 环）沿着浪的曲线排开，形成天然的节拍引导。每吃掉一个，屏幕中央弹出一个像素数字——`×3`、`×4`、`×5`——**字号逐次放大，颜色由琥珀渐变为炽白**。海面被拖出一道长长的亮痕。

**情绪**：心流。这是紧张之间的喘息，是"手感"的具象化。
**设计功能**：给玩家一个不需要动脑的、纯粹的节奏快感段落，与逃生段形成呼吸对比。

### UI 风格方向

**HUD 布局（极简，四角原则）**

| 位置 | 元素 | 说明 |
|---|---|---|
| 左上 | **ALARM 通缉条** | 三段式：白 → 琥珀 → 血红。带刻度线标出敌人触发阈值 |
| 右上 | **SCORE** | 像素等宽字，数字滚动插值，不大 |
| 底部中央 | **COMBO** | 大字，带衰减进度环。仅在 COMBO > 0 时出现 |
| 左下 | **体力槽** | 三格制，冲刺消耗时整格闪灭（不做平滑条，街机感） |
| 屏幕边缘 | **追捕指示箭头** | 仅高 ALARM 时出现，指示屏外敌人方位 |

**字体与排版**
- 像素字体（5×7 或 7×9 bitmap，风格参考 Press Start 2P，建议自绘以控制授权）
- 数字一律**等宽**，避免滚动时抖动
- 中文使用点阵像素中文字体，小字号下不做抗锯齿

**反馈动画风格（复古约束 · v1.1 精确化）**

| 项 | 参数 | 备注 |
|---|---|---|
| ✅ 震屏 | ≤ 6 帧，位移 ≤ 8px | 常规上限；Boss 入场可例外至 12px |
| ✅ 顿帧 Hitstop | **0.08s（≈5 帧 @60fps）** | **仅**捕食成功 / 稀有拾取 / COMBO 达成 |
| ✅ 色闪 | 整屏 palette 切换，1–2 帧 | 比闪白更有性格，是本作最有辨识度的反馈 |
| ✅ 扫描线抖动 | 仅在 ALARM 最高档，**< 3Hz** | 光敏红线 |
| ❌ 顿帧禁令 | **受击 / 被追击时绝不触发顿帧** | 逃生段顿帧会被感知成卡顿与输入延迟 |

**「禁止清单」的精确化裁决**（原文过于绝对，v1.1 修订；完整版见美术圣经 §6.7）：

| 原禁止项 | 精确化 |
|---|---|
| 柔和粒子 | 禁的是**羽化与圆形**，不是粒子本身。粒子一律 **2–5px 硬边方块** |
| 渐变发光 | 维持禁止。需要发光时用 **1px 硬边描边**或色阶环代替 |
| 平滑缓动 | **位移禁止亚像素缓动**（须量化到像素网格）；**缩放/旋转允许缓动**（不糊，反更有弹性）；alpha 用阶梯衰减 |
| 半透明叠加 | **sprite 本体禁止**（实体须 100% 不透明硬边）；**全局后期层允许**：暗角 / 遮罩 / 光柱 |

> 💡 **建议升级：用「有序抖动 Dithering」替代 alpha 半透明。** 真·复古硬件没有 alpha 混合，靠棋盘/有序网点密度表达半透过——既彻底规避"半透明破坏硬边"的矛盾，也更符合街机 authenticity。适用于光柱、探照灯、冲刺残影、屏幕水珠；暗角保留真 alpha。

**可访问性硬要求**（分级依据：美术圣经 §9.8，本作最低要求 **Standard**，目标 **Comprehensive**）

- 颜色**永不作为唯一信息通道**：ALARM 用"条 + 刻度形状 + 音效"三重编码；威胁等级与稀有度另有尺寸/粒子量冗余通道
- **五个效果必须可独立关闭**（不是打包的三档预设）：屏幕震动 / 屏幕闪烁 / 扫描线抖动 / CRT 后期 / 粒子密度
  - 关闭震屏后，以「顿帧 + 色闪」替代打击反馈
- **色盲模式**：血红 `#FF3B3B` → 电光蓝 `#00C2FF`、琥珀 → 金（全项目替换表见美术圣经 §9.8）
  - 本项目接受"一抹血色"在色盲模式下变为"一抹电蓝"——**可访问性 > 调色板纯度**；"稀缺强调"这一签名在换色后依然成立
- **首次启动光敏警告**，并提供跳转设置的按钮
- 检测到 `prefers-reduced-motion: reduce` 时自动降级并关闭震屏

> ⚠️ **已知盲点**（已交美术侧修复）：血红 `#FF3B3B` 与洋红 `#FF2E88` 的 WCAG 相对亮度**均为 25%**，灰度下无法区分。解法不靠颜色，靠**形态 + 位置通道**——洋红永远是"径向运动的粒子爆发"，血红永远是"静态填充/条/描边"。

## 7. 初步 UX 流程

### 7.1 完整流程

```
┌─────────────┐
│  载入/Attract │  极短（< 2s）。Logo + 一句标语 + 最高分
└──────┬──────┘
       ↓
┌─────────────┐
│   标题页     │  【潮线 TIDELINE】大标题
│             │  · 一句话教程（"冲、叼、逃"三个图标，无文字墙）
│             │  · [开始] 按钮（默认聚焦，回车即进）
│             │  · 次要入口：设置 / 排行榜
└──────┬──────┘
       ↓  一次点击，无加载条
┌─────────────┐
│   游戏中     │  · HUD 淡入（0.5s）
│             │  · 首次游玩：无文字教程，靠场景引导
│             │    ——第一只游客自动出现在正前方，冲刺键图标脉冲一次
│             │  · ESC / 暂停按钮 → 暂停
└──┬───────┬──┘
   │       │
   ↓       ↓
┌────────┐ ┌──────────┐
│ 暂停页  │ │ 死亡/结算 │
│ 画面降饱 │ │          │
│ 和 +     │ │ ≤3秒可读完│
│ 扫描线   │ │ 三件事：  │
│ 加重     │ │ ① 本局得分│
│ [继续]   │ │ ② 最亮一帧│
│ [设置]   │ │ ③ 下一目标│
│ [放弃]   │ │          │
└────────┘ │ [重试] ←──┼──→ 核心：≤1.5s 回到可操作
           └──────────┘   （街机游戏的生命线）
```

**UX 三条铁律**：

1. **重试摩擦为零**——死亡后玩家应该在 1.5 秒内重新控制鲨鱼。任何确认弹窗、加载条、"再看一次广告"式的阻碍都是自杀。
2. **教程隐形**——不写文字墙。第一局的关卡布局本身就是教程（目标自动出现在路径上，按键图标在需要时脉冲一次）。
3. **结算只讲三件事**——玩家在结算页的注意力窗口约 3 秒。超出这个量的信息等于没有。

**结算页 · S/A/B/C 评级（v1.1：取消星级）**

> **为什么取消星级**：星级是**关卡制**的语法，本作是单局押注制（endless run），**没有"通关"节点**。评级字母既保留街机味，又不需要"通关"这个不存在的前提。结算标题统一为 **GAME OVER**，不使用 "STAGE CLEAR"。

| 评级 | 阈值 | 颜色 | 出现时序 |
|---|---|---|---|
| **C** | 达成 1 次 Bank | `#8A97A8` 银灰 | 1.8s |
| **B** | 60% 目标分 | `#C7CFD8` 银灰亮 | 1.8s |
| **A** | 100% 目标分 | `#FFD23F` 金 | 1.8s |
| **S** | 150% 目标分 **+ 零搁浅** | `#B14CFF` 史诗紫 | 1.8s |

**范围**：评级字母 **Standard** 引入。MVP 结算只显示最终分 + 最高分，省一组结算资产。

**设置页（OPTIONS）必须包含的可访问性开关**（对齐美术圣经 §9.8 Standard 级）：

| 开关 | 默认 | 可独立关闭 |
|---|---|---|
| 屏幕震动 | 开 | ✅（关闭后以顿帧+色闪替代） |
| 屏幕闪烁（色闪/闪白/ALARM 闪烁） | 开 | ✅（关闭后改常亮） |
| 扫描线抖动 | 开 | ✅ |
| CRT 后期 | LITE/FULL | ✅ → OFF |
| 粒子密度 | 100% | ✅ 100/50/0% |
| 色盲模式 | 关 | ✅ |
| 文本缩放 | 100% | ✅ 100/125/150% |

### 7.2 移动端适配要点

**输入方案（极简，单指可玩）**

| 操作 | 触屏 | 键盘 |
|---|---|---|
| 控制深度/方向 | **单指拖拽**（相对位移控制方向） | 方向键 / WASD |
| 冲刺 | **另一指点按**（或双指点按） | 空格 |
| 挣脱（搁浅 QTE） | **连续点按**任意处 | 连打空格 |

设计原则：**鲨鱼永远自动前进**（同 Jetpack Joyride / Crossy Road），玩家只控制"往哪"。这把输入压缩到**1.5 个自由度**，是移动端能玩的前提。

**其他适配要点**
- **横屏优先，竖屏 Fallback**：横版游戏横屏体验最佳。竖屏下不强制旋转（网页强转体验差），改为提示条 + 缩窄视野的可玩降级方案
- **触摸目标 ≥ 44×44 px**，按钮间留足间距
- **零 hover 依赖**——所有交互必须可点击完成
- **性能档位**：提供"省电模式"（关闭 CRT 后处理、降低扫描线密度），低端机保 60fps
- **首次进入不请求任何权限**，最高分存 localStorage

## 9. Phase 2 系统拆解预判

进入 Phase 2 后，建议按以下顺序产出系统 GDD（**依赖顺序已排序，不可颠倒**）：

| 优先级 | 系统 | 依赖 | 关键待解问题 |
|---|---|---|---|
| **P0** | **移动与操控系统** | 无 | 鲨鱼手感（重量感、转向惯性、冲刺曲线）；搁浅判定 |
| **P0** | **ALARM 通缉与敌人系统** | 移动 | 4 级敌人 AI；ALARM 的增减速率与阈值 |
| **P0** | **捕食与携带系统** | 移动、ALARM | 携带惩罚数值；押注的指数收益公式 |
| **P1** | **冲浪收集与 COMBO 系统** | 移动 | 道具生成规则；COMBO 窗口与倍率曲线 |
| **P1** | **经济与升级系统** | 捕食、收集 | 双货币产出率；两棵树的互相解锁结构 |
| **P1** | **关卡与区域系统** | 全部 P0 | 三层水体布局；危险梯度曲线 |
| **P2** | **UI/HUD 系统** | 全部 | HUD 信息架构；结算页 |
| **P2** | **元系统**（存档/榜单/每日目标） | 经济 | 本地存储结构；3 个微型目标的设计 |

**给 Phase 2 的三条建议**：

1. **先做数值沙盘，再写文档**。§3.1 的量级参考只是锚点。建议 Phase 2 开始时先用电子表格跑一遍"深水 vs 浅滩"的期望收益模型，把 R1（主导策略）在动笔之前验证掉——数值不通，GDD 写得再漂亮也是废纸。
2. **每个系统 GDD 必须写"边缘情况"一节，至少 3 条**。特别是：携带状态下搁浅怎么办？ALARM 满值时 Bank 如何？连击窗口内死亡怎么结算？这些是原型阶段最容易出 Bug 的地方。
3. **守住"支柱闸门"**。Phase 2 会冒出大量好点子，每个都问一句"它服务哪根支柱"。服务不了的记入 Epic 层，不进当前排期。
