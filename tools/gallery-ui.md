# GoodCase.xAI 画廊展示层

本次首页与统一浏览页由 **Codex + GPT-6** 完成。原案例内容及其署名保持原样。

## 维护入口

- `gallery.json` 是上架清单。一个可见条目代表一个案例，唯一 ID 为规范化后的原入口路径。
- `tools/build_gallery.py` 继续生成根 `index.html`，并保留无 JavaScript 时的静态卡片。生成模板已加载新的展示层文件。
- `gallery-data.js` 提供中文策展标题、主题标签、少量说明补充和关联资源；新案例即使尚未润色，也会根据清单自动展示，暂列“其他作品”。
- `gallery.js` 和 `gallery.css` 负责首页筛选、搜索、排序、星系与卡片。没有构建依赖、第三方脚本或远程字体。
- `case.html`、`case.js`、`case.css` 是统一浏览页。网页以 iframe 打开原案例，Markdown 在浏览器排版。左下角始终提供返回画廊按钮，右上角可直接打开原页。原案例地址不变。
- 化学科普条目还可切换交互实验、资料核查、科普解读、贡献辨析与演示提纲。Token 看板条目为说明文档，并展示已有示例图；实际用量看板须本机生成。

## 统计口径

所有数字在运行时从同一份可见案例数组生成，禁止另外手写统计数字。

1. 总案例数按唯一入口去重，重复入口会报错；隐藏条目排除。
2. Agent、完整 Agent + 模型组合、打开方式是互斥分组，分项合计等于总数。
3. 模型及主题为多标签：每个案例在每个标签最多计一次，但可以属于多个标签。分项合计可能大于总数。
4. 模型名称沿用登记信息，未记录单列。组合项保留同一案例登记的全部模型，不人为推定模型。
5. 标签旁数字始终为全库计数；结果行显示交叉筛选及关键词检索后的实际数量。页面可展开“统计口径与全库核对表”。
