# 路人甲TM2 · 星际水族箱（3D 透明水箱交互模拟）

基于 Three.js 的可交互 3D 透明水箱：水面漂着一只黄色橡皮鸭和若干不同密度的小球，
点击/拖动水面产生连续波纹，物体随水面起伏、碰撞和漂移。

## 运行

页面使用 ES Module，需要通过本地 HTTP 服务器打开（不能直接双击 file:// 打开）：

```bash
# 方式一：Python（在 GoodCase 目录下启动时；8123 被其他项目占用时用 8124）
python -m http.server 8124
# 浏览器打开 http://127.0.0.1:8124/路人甲TM2星际水族箱/

# 方式二：Windows 下直接双击本目录内的 start.bat，然后打开 http://127.0.0.1:8000/
```

依赖已本地化在 `lib/`（three.module.js / OrbitControls.js / RoomEnvironment.js），离线可用。

## 功能对照（提示词要求）

1. **可交互 3D 透明水箱** —— 经典透明玻璃水箱 + 深绿边框，水面漂着黄色橡皮鸭
   和多个不同密度小球（ρ 0.15 ~ 0.95，浸没深度各不相同）。
2. **连续波纹** —— 点击水面溅起水花，按住拖动持续注入波纹；基于 128×128 高度场波动方程模拟，
   物体随水面起伏（浮力采样水面高度）、球与球/鸭碰撞、沿波面斜坡漂移。
3. **三种重力模式 + 参数控件** —— 地球 9.81 / 月球 1.62 / 火星 3.71 m/s²；波速与浮力动力学随
   重力真实变化；另有波浪强度、阻尼、物体数量滑杆和暂停按钮。
4. **右侧实时状态** —— 帧率 FPS、当前重力、物体总数、模拟时间，以及每个物体的
   密度 / 浸没百分比 / 速度（每 0.2s 刷新）；所有控件均真实作用于模拟。

## 技术要点

- 水面：高度场弹簧-邻域波动模型（速度随重力 √g 缩放），法线由高度梯度解析计算。
  波纹注入为零均值高斯脉冲、全场镜像边界、波幅软限幅、水位漂移自动归零——
  体积严格守恒，连续点击不会抬升水位、波浪永不失效。
- 物理：浮力 = g·(浸没占比/密度 − 1)，波面斜坡推力、水体垂直速度拖曳、按质量分配的碰撞冲量、
  边界反弹；固定 120Hz 物理子步 + 60Hz 水面子步，帧率无关。
- 渲染：ACES 色调映射、PCF 软阴影、环境反射（RoomEnvironment）、透明水面 + 水体染色。
  玻璃用经典透明材质（不用 transmission——其折射缓冲不含透明物体，水色从侧面会"隐身"）。
- 拾取：点击/拖动针对水箱内部包围盒求交（俯视精确命中水面，侧视取视线穿过水体的
  中点水柱），任意视角点水箱内的水都能产生波纹；相机降到水面高度也不例外。
- 抗冻结设计：窗口被遮挡等环境会暂停 rAF（输入事件仍在派发但画面不动，表现为"点了没反应"）。
  页面用三重兜底保证始终响应——① 定时器 watchdog 泵帧（rAF 停摆 >250ms 时接管）；
  ② 鼠标事件直接驱动出帧（pointerdown/move/up 即时渲染）；③ `setPointerCapture`
  异常捕获，指针失效也不中断泼水逻辑。帧率按真实墙钟帧数统计，遮挡降级时如实显示低位。
