# 澳洲鹈鹕的海边骑行 · Three.js

一只澳洲鹈鹕骑着青绿色旅行自行车沿海边木栈道前进。**所有形体均由代码与基础几何体（球/圆柱/圆环/方块/圆锥/点）构建，未使用任何现成 3D 模型。**

## 运行

- 直接双击 `index.html` 即可（无模块、无网络依赖，`libs/three.min.js` 为本地库 r149）；
- 或起本地服务：`python -m http.server 8000` 后访问 <http://localhost:8000>。

## 操作

| 控件 | 功能 |
| --- | --- |
| ⏸ 暂停 / ▶ 继续 | 暂停或继续骑行（含水波、海鸥等全部动态） |
| 速度滑杆 (0–3.2x) | 调节骑行速度，车轮/脚踏/踩踏频率同步变化 |
| 🌙 夜晚 / ☀ 白天 | 昼夜切换（天空、海面、灯光、星星、车灯联动渐变） |
| 🎥 自由观察 | 拖动环绕、滚轮缩放；再点一次回到侧面跟随镜头 |

键盘：`空格` 暂停 · `N` 昼夜 · `F` 自由观察 · `←/→` 调速。

## 实现要点

- **动作同步**：车轮转速 = 速度 / 轮径；曲柄按传动比 2.2 随动；双腿用两段式 IK 实时踩踏（脚始终贴在水平脚踏上），双翅用 IK 搭在车把两端，躯干随踩踏起伏，嘴里的鱼轻轻摆动。
- **持续移动的背景**：栈道木板、栏杆、灯柱、棕榈树、遮阳伞、浮标全部按行程取模循环滚动，云层慢速视差，海面顶点波动且波相随速度后退。
- **昼夜系统**：天空穹顶着色器、雾、海/沙/云颜色、光照强度、星星透明度、栈道灯与车灯光锥统一由昼夜系数插值。
