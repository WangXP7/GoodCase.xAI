# BIG SHARK · 复古街机鲨鱼觅食

复刻自复古美式卡通(1930's 橡皮管卡通 × 做旧胶片)风格的街机小游戏:
你控制一条大鲨鱼,在海里啃鱼群、冲上沙滩叼走游客、再拖着猎物弹回深海吞掉。

纯原生 Canvas 手绘,零依赖、零构建,所有画面均为程序化绘制,并叠加了
胶片噪点、暗角、闪烁、划痕与手摇放映机抖动等做旧质感。

## 运行

```bash
cd shark-arcade
python serve.py        # http://127.0.0.1:8899
```

(或任意静态服务器打开本目录;直接双击 index.html 也可以玩)

## 操作

| 按键 | 作用 |
| --- | --- |
| 鼠标移动 / WASD | 控制鲨鱼游向目标 |
| 按住左键 / 空格 / Shift | 冲刺(水中加速,消耗 BOOST) |
| 沙滩上按住冲刺 | 一蹦一蹦地弹回水中 |
| P | 暂停 |
| M | 静音 |
| R | 结束后重开 |

## 规则

- 啃鱼群 **+25**,螃蟹 **+75**,水里的泳客 **+300**
- 沙滩游客要**叼住拖回深海**才吞得下,成功 **+500**;叼太久会被挣脱
- 水母会蜇人(饥饿 -12),沙滩上停留会加速饥饿
- **HUNGER** 见底即饿死,GAME OVER;得分冲击 **HI-SCORE**(本地保存)
- 吃东西积攒经验,升满 6 格 **LV+1**,鲨鱼变大变快

## 文件

- `index.html` — 页面外壳
- `style.css` — 画布居中与暗色边框
- `game.js` — 全部游戏逻辑(渲染 / 物理 / 音频合成 / HUD / 胶片滤镜)
- `serve.py` — 带 no-store 缓存头的开发服务器(改代码刷新即生效)
