# 三重密室 · 3D 密室逃脱（Three.js）

第一人称 3D 密室逃脱：**3 个房间、6 个可交互物件、一条严格串行的谜题依赖链**。
全部资源本地化（Three.js 已下载到本目录），**离线可玩**。

## 运行方式

方式一（推荐，任选一个本地服务器）：

```bash
cd "T1密室3D游戏开发33m-74m-61m"
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/
```

方式二：直接双击 `index.html`（file:// 协议同样可玩，无任何网络依赖）。

- 建议使用 Chrome / Edge 桌面版。
- `?nolock=1` 参数：不锁定鼠标指针的兼容模式（拖动鼠标转向、点击光标处互动），适合不便使用
  Pointer Lock 的环境（也用于自动化测试）。

## 操作

| 输入 | 作用 |
|---|---|
| 鼠标移动 | 环视（点击画面锁定指针，ESC 释放） |
| W A S D | 移动 |
| ← → | 转向 |
| 鼠标点击 / E | 与准星（或光标）所指物件互动 |

## 玩法与保证

- **6 个物件**：书桌抽屉、手电筒、红色玻璃片、密码铁门、木箱、出口大门。
- **连锁依赖**：抽屉→电池 ⇒ 点亮手电筒 ⇒（照明才敢进暗室）→ 红玻璃片+手电筒=红光 ⇒ 显影密码 724 ⇒
  开密码铁门进房间3 ⇒ 木箱→金钥匙 ⇒ 出口大门通关。详见 **`依赖链.md`**（含依赖链图）。
- **每个物件点击必有反馈**；未满足条件时会明确提示"为什么现在用不了"（没电池 / 太黑 / 太远 / 看不清划痕 / 缺钥匙…）。
- **左上角始终显示「当前目标」**，随进度自动推进，玩家不会被卡死。
- **通关时长**：实测 00:48 ~ 01:01，远低于 5 分钟上限（`通关记录.md` 有逐步操作与反馈记录）。

## 实现说明（game.js 内部）

- 状态机字段：`hasBattery → flashlightLit → hasRedShard → hasRedLight → codeKnown → doorOpen → hasGoldenKey → exitOpen`，
  「当前目标」由该状态唯一推导（`currentObjective()`），保证提示与谜题进度永远一致。
- 房间 2 是真黑暗（近零环境光 + 手电筒聚光灯），门洞在无光源时把玩家位置钉在边界线上并给出提示。
- 碰撞为 AABB 圆形推挤；门的开闭会动态增删碰撞体。
- 兼容层：页面在 rAF 停摆的嵌入环境（如自动化/后台标签）里用 MessageChannel 保底驱动帧循环，
  正常桌面浏览器中该逻辑不启动。
