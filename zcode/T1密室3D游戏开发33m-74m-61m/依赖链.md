# 三重密室 · 谜题依赖链设计

> 本文件是游戏的谜题设计文档。6 个可交互物件**严格串行**成一条链，不存在任何平行谜题：
> 每一环的产出是下一环的必要条件，跳过任何一环都无法继续。

## 依赖链总图

```
 ┌───────────────┐  点击   ┌────────────────┐
```

一行摘要：**抽屉 → 电池 → 手电筒 →（照明进暗室）→ 红玻璃片 → 红光显影 724 → 密码铁门 → 金钥匙 → 出口大门**

## 为什么这是"连锁"而不是"平行"

| 环节 | 若缺少上游会怎样 |
|---|---|
| 没有电池（A） | 手电筒永远点不亮（点击时明确提示"里面空空如也"） |
| 手电筒不亮（B） | 房间 1→2 的门洞是"浓得化不开的黑"，玩家被直接推回，无法进房间 2 |
| 没进房间 2 | 拿不到货架上的红色玻璃片（C）——它只存在于房间 2 |
| 没有 B+C 组合 | 密码铁门上的划痕"普通光线下什么也看不清"，三位密码永远未知 |
| 不知道 724 | 密码铁门（D）打不开，进不了房间 3 |
| 没进房间 3 | 摸不到木箱，拿不到金钥匙 |
| 没有金钥匙 | 出口大门"被黄铜挂锁锁死"，无法通关 |

链条上任何一个节点被卡住，后面的全部节点都不可达——这就是严格的连锁依赖。

## 6 个可交互物件清单（含所有点击分支的反馈）

每个物件点击**必有反馈**；未满足使用条件时，反馈会明确说明"为什么现在用不了"。

| # | 物件 | 位置 | 前置条件 | 点击反馈（按状态） |
|---|---|---|---|---|
| O1 | 书桌抽屉 | 房间1 西侧书桌 | 无 | 未开：「抽屉『吱呀』一声滑开了——里面躺着一节旧电池！」<br>已开：「抽屉已经空了，里面什么都没有。」 |
| O2 | 手电筒 | 房间1 东侧边桌 | 电池（有电池则自动点亮） | 没电池：「你捡起手电筒晃了晃——里面空空如也，一节电池也没有。」<br>有电池：「咔哒」，一道光柱亮了！ |
| O3 | 红色玻璃片 | 房间2 货架（有微光） | 无（拾取即用） | 已点亮手电：「你顺手把它卡在手电筒前端——光变成了深红色！红光之下，一些肉眼看不见的东西会显形。」<br>未点亮（理论不可达，仍处理）：「收进了口袋。」 |
| O4 | 密码铁门 | 房间2 北墙 | 红光手电 | 无红光：「厚重的铁门纹丝不动。门上装着三位数字密码锁，门板上有几道浅浅的划痕——普通的光线下，什么也看不清。」<br>有红光：「红光扫过门板——划痕显出了三个发光的数字：7 · 2 · 4！」并自动弹出密码锁<br>密码错：「哔——哔」红灯闪两下：密码错误。<br>密码对：「咔哒——轰隆」铁门缓缓向侧面滑开！<br>已开：「铁门已经滑开了，通道就在眼前。」 |
| O5 | 木箱 | 房间3 西侧 | 无 | 未开：「箱盖『啪』地弹开——里面静静躺着一把黄铜钥匙，泛着温润的金光！」<br>已开：「箱子里已经空空如也。」 |
| O6 | 出口大门 | 房间3 北墙 | 金钥匙 | 没钥匙：「厚重的木门被一把黄铜挂锁锁死了，锁孔泛着金色的光——需要一把金钥匙。」<br>有钥匙：「金钥匙插进锁孔，旋转——『咔嚓！』……大门缓缓打开」→ 通关 |

环境交互（非谜题物件，但同样有反馈）：

- **黑暗的门洞**（房间1→2）：未点灯点击：「门洞里是一片浓得化不开的黑。没有光源就往里走，只会一头撞墙。」；强行往里走被推回：「你朝黑暗里迈了半步——里面深不见底，什么也看不见。先退回来，找个光源吧。」
- **距离规则**：看向任何物件但距离不够时，准星提示「×× —— 太远了，走近一点」；强行点击：「太远了，走近一点再操作「××」。」

## 防卡死设计：「当前目标」提示

左上角始终显示当前目标，随状态机自动推进（玩家永远不会不知道下一步做什么）：

1. 在第一个房间里四处看看，找找能带走的东西。
2. 手电筒需要一节电池才能亮——房间里找找抽屉之类的地方。
3. 举着手电筒，穿过北墙的门洞，进入黑暗的房间。
4. 储藏室里一片漆黑，找找有用的东西——货架方向似乎有微弱的反光。
5. 把红色玻璃片装到手电筒前端，组合成红光手电。
6. 用红光去照北墙的密码铁门，看看门板上的划痕藏着什么。
7. 在密码锁上输入三位密码 7 2 4。
8. 在第三个房间里找找，能打开出口大门的钥匙在哪。
9. 用金钥匙打开出口大门，逃出去！

## 通关时长

- 解谜操作总共只需 **12 次左右点击**（6 个物件各 1 次 + 密码锁 5 次按键 + 少量重复尝试）。
- 实测通关用时：**00:48 ~ 01:01**（远低于 5 分钟上限），见 `通关记录.md`。
