# NEKO PAL · 猫咪掌机 🐾

一个在浏览器里养猫的小游戏，致敬童年掌机电子宠物（拓麻歌子）：奶油色掌机外壳里是一间**CSS 3D 等距小屋**——微缩模型般的立体房间，洗衣机、沙发、猫爬架都是有厚度的"小方块"，你领养的小猫就住在这里（会自己爬上洗衣机顶睡觉，就像参考图那样）。

## 怎么玩

**直接双击 `index.html` 就能玩**（无需安装、无需联网、无需服务器）。
也可以在本目录起个静态服务器：`python -m http.server 8642` 后访问 <http://localhost:8642/>。

- 第一次进入会先**领养小猫**：5 种毛色（橘 / 灰 / 黑 / 白 / 奶牛）+ 取名。
- 用掌机上的实体按键照顾TA：
  - 🍚 **喂食**：猫粮（免费）/ 鱼肉罐头 / 小鱼干
  - 🎣 **玩耍**：逗猫棒 / 毛线球（消耗精力，涨心情）
  - 🛁 **清洁**：洗香香，泡泡浴
  - 🌙 **睡觉**：小猫会自己走上洗衣机顶趴着睡（会打呼噜冒 Zzz），也会跳上猫爬架平台
- **点一点小猫**可以摸摸头。
- 小猫头顶会冒出**愿望气泡**（2 分 30 秒内满足），奖励金币和亲密度。
- 亲密度升到 **Lv.2 ~ Lv.10** 会逐级解锁新装饰，房间越来越温馨（窗台绿植 → 沙发毯 → 相框 → 落地灯 → 鱼缸 → 爪印地毯 → …… → 猫猫大师奖杯）。
- 房间跟随**现实时间昼夜**：晚上窗外有月亮星星，屋子会变暗，让小猫早点睡吧。
- 关掉页面后小猫自己在家；回来时会结算离线期间的消耗，并收到「你回来啦」的问候。

## 保存

进度自动保存在浏览器 `localStorage`（键 `nekopal_save_v1`），每 10 秒 + 每次操作后写入。想重新领养：帮助(❔) → 重新领养。

## 玩法速览（状态规则）

| 状态 | 下降速度 | 恢复方式 |
|------|----------|----------|
| 🍚 饱食 | 约 45 分钟见底 | 喂食 |
| 💗 心情 | 约 55 分钟见底 | 玩耍 / 摸头 / 罐头小鱼干 |
| 💤 精力 | 约 85 分钟见底 | 睡觉（约 13 分钟回满） |
| 🫧 清洁 | 约 2 小时见底 | 洗澡（立即回满） |

猫不会被养死——状态见底只会不开心、一直咕咕叫提醒你。

## 技术

纯前端零依赖：HTML + CSS + 原生 JS。

- **等距小屋**：房间是一个 `rotateX(58°) rotateZ(-42°)` 的 CSS 3D 场景，地板 + 后墙围成敞开的小盒子；每件家具由顶面 / 正面 / 侧面三个面拼成微缩立方体，浏览器自动做 3D 深度排序（猫走到家具后面会被正确遮挡）。
- **猫是「立牌」（billboard）**：在 3D 空间里做逆变换始终面向镜头，走动、坐、睡、吃、玩、被摸头都是一套 SVG 姿态动画；睡觉时会"爬"上洗衣机顶（`translateZ` 升到台面）。
- 昼夜变化、挂钟指针走现实时间、WebAudio 合成音效（喵声 / 呼噜 / 金币 / 升级琶音，可静音）。
- 掌机外壳根据窗口大小自动缩放，手机上也能玩。
