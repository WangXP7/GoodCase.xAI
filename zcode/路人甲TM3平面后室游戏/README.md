# 档案层 B4（Archive Floor B4）

一款在浏览器中直接运行的 **2D 俯视角恐怖逃生游戏**。纯 HTML / CSS / JavaScript + Canvas 2D 渲染，零外部素材、零依赖、可完全离线游玩。

> 你是写字楼的夜班保安。今夜，地下四层档案库的监控里出现了一个不属于任何摄像头的黑影——闸门全部锁死，电梯断电。收集三盘监控录像带，找出三位密码，在「巡影」抓住你之前，从东侧闸门逃出去。

## 启动方式

**方式一（推荐，最简单）**：直接双击 `index.html`，用现代浏览器（Chrome / Edge / Firefox）打开即可游玩。

**方式二（本地 HTTP）**：

```bash
python server.py        # 默认端口 8123
# 或
python server.py 9000   # 指定端口
```

然后浏览器打开 `http://127.0.0.1:8123/`。`server.py` 会附带 no-cache 响应头，适合开发调试。

> 调试模式：URL 加 `?debug=1`（如 `index.html?debug=1`）显示调试面板；`?debug=1&seed=1998&autostart=1` 可跳过菜单直接以指定种子开局。

## 操作方法

| 按键 | 作用 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| `Shift`（按住） | 冲刺（消耗体力，脚步声大，容易引来它） |
| `E` | 拾取录像带 / 使用密码终端 / 开闸门 / 在长椅休息 |
| `Esc` | 暂停（继续 / 重新开始本层 / 音效设置 / 返回主菜单） |
| `M` | 静音切换 |
| 终端内 `0-9` / `Backspace` / `Enter` | 输入密码 / 删除 / 确认 |

## 游戏目标

1. **收集 3 盘录像带**——散落在地图各处，每盘记录一位密码数字及其顺序；
2. **前往「档案主机房」**，在密码终端输入三位密码（密码错误会明确提示，已收集的录像带不会丢失）；
3. **密码正确后东侧闸门解锁**，跟随绿色指示灯与 HUD 方向提示撤离；
4. 全程躲避敌对实体「巡影」：它有游荡 / 怀疑 / 追逐 / 搜索 / 攻击五种状态，能听见你的奔跑、撞墙与交互声，视线会被墙体阻挡。

失败条件：被「巡影」接触，或理智值归零（长时间待在黑暗中、离它太近、被追赶都会消耗理智；荧光灯下与安全屋内会缓慢恢复）。

## 文件结构

```
路人甲TM3平面后室游戏/
├── index.html          # 唯一入口页面（含全部样式与 DOM 结构）
├── server.py           # 可选的本地启动脚本（no-cache HTTP 服务）
├── README.md           # 本文件
├── SOURCES.md          # 素材来源与许可说明（全部为代码自生成）
├── TEST_REPORT.md      # 测试报告（Seed、通关记录、问题与修复）
├── screenshots/        # 验收测试证据截图
└── js/
    ├── config.js       # 全局常量、平衡数值、调色板
    ├── rng.js          # 种子随机数（mulberry32 + FNV-1a），保证同种子同地图
    ├── audio.js        # Web Audio 全程序化合成音效（无音频文件）
    ├── mapgen.js       # 程序化地图生成 + 连通性校验 + BFS 寻路/视线工具
    ├── player.js       # 玩家移动、碰撞、体力、声音事件
    ├── enemy.js        # 敌对实体「巡影」AI 状态机
    ├── items.js        # 录像带 / 密码终端 / 出口 / 长椅交互逻辑
    ├── lighting.js     # 光照系统（格子泛光、墙体遮挡、灯管闪烁、记忆微光）
    ├── ui.js           # HUD / 菜单 / 结算 / 终端 / 调试面板（DOM 层）
    └── game.js         # 主循环、状态机、渲染管线、输入、理智系统
```

## 特性说明

- **种子地图**：相同 Seed 生成完全相同的地图（HUD 角落与调试面板均显示 Seed 与地图指纹），方便复现与挑战。
- **无完整小地图**：普通模式只能靠走过的“记忆微光”、地面油漆房间名与灯光明暗辨认方向。
- **纯程序化素材**：所有纹理、角色、光效由 Canvas 绘制；所有音效由 Web Audio 实时合成；字体使用系统字体栈。无任何网络请求，可离线运行。
- **调试面板**（仅 `?debug=1`）：FPS、Seed、地图指纹、连通性、玩家/实体坐标与状态、寻路路线节点数、物品坐标、页面报错计数；`F1-F4` 切换网格 / 视线 / 寻路 / 物品点叠加层；`window.__B4.debug.*` 提供传送、强追、直接通关等测试钩子。
