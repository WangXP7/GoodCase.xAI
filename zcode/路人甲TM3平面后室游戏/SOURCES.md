# SOURCES.md —— 素材来源与许可

## 结论

**本项目没有使用任何外部素材、第三方库、CDN 资源或网络请求。** 全部视觉与音频内容均由项目内的代码在运行时程序化生成，因此不存在版权来源问题，游戏可完全离线运行（含 `file://` 直接打开）。

## 各类素材的生成方式

| 类别 | 来源 | 许可 |
|---|---|---|
| 地形 / 地砖 / 墙体 / 家具 / 污渍 / 潮湿地毯 | `js/game.js` `_buildStaticLayer()` 用 Canvas 2D 按种子逐格绘制 | 本项目原创（本次任务中从零编写） |
| 角色（保安）与敌对实体「巡影」 | `js/game.js` `_drawPlayer()` / `_paintShade()`，原创黑色剪影+发光眼睛的抽象怪物形象，非任何现有游戏角色 | 本项目原创 |
| 录像带 / 密码终端 / 出口闸门 / 长椅 / 荧光灯座 | `js/game.js` `_drawItems()` 与静态层绘制 | 本项目原创 |
| 光照 / 暗角 / 噪点 / 记忆微光 | `js/lighting.js` 格子泛光算法 + `js/game.js` 后处理；噪点纹理由 `createImageData` 运行时生成 | 本项目原创 |
| 全部音效（电流嗡鸣、低频环境声、行走/冲刺脚步、心跳重击、发现惊弦、拾取磁带、密码正误、解锁、死亡、胜利、幻听脚步等） | `js/audio.js` 用 Web Audio API 振荡器 / 噪声缓冲 / 滤波器 / 包络实时合成，无任何音频文件 | 本项目原创 |
| 字体 | 系统字体栈：`"Noto Sans SC", "Microsoft YaHei", "PingFang SC", sans-serif` 及等宽 `Consolas, monospace`（仅 CSS font-family 声明，不打包、不分发字体文件） | 系统随附，无再分发行为 |
| 游戏图标 / Logo | 未使用（浏览器标签显示纯文字标题） | — |

## 代码许可

本项目全部代码由本次开发任务原创编写，无复制任何商业游戏的具体地图、角色、Logo 或受版权保护的素材；玩法氛围参考"后室"（Backrooms）一类局限空间恐怖题材的通用设计语汇（昏黄荧光灯、潮湿地毯、狭窄走廊），未复制任何受保护表达。
