## 三、官方材料内部口径差异（重要）

1. **Soai 1995 的数字**：科普材料（S2）写"从 2% 起步到 87%"；科学背景（S3）写"催化剂 5% ee → 首轮 55% → 次轮 87% → 五轮至 90% 平台"。两者出自同一原始论文的不同实验条目。**交付物统一采用 S3 的精确口径**。
2. **2003 年的表述**：新闻稿（S1）称"只有一种镜像形成"；科普（S2）称"优势对映体达产物的 99.99%"；科学背景（S3）的精确内容是两条：0.00005%→>99.5%（三轮）与绝对不对称合成（18R/19S，ee 15–91%）。**交付物统一采用 S3 口径**，新闻化表述仅作背景提及。
3. **沙利度胺**：官方科普（S2）称"致害的是活性成分的镜像体"——此为该材料口径；补充文献（S5/S6）表明两对映体体内互变，"单一对映体可避免悲剧"是误传。**交付物在采用官方口径的同时附加了此注意事项**（见 04 提纲核查表 D 节）。

## 四、互动演示（03）的模型说明与参数记录

- 模型类型：Frank (1953) 模型思路的简化连续介质实现 + 分批接力（异手封存 = Kagan/Noyori"储库"机制的抽象）。
- 方程（无量纲）：
  - dR/dτ = (A/S)·κ·[R_act·(1+eemax)/2 + S_act·(1−eemax)/2] + (A/S)·k₀/2
  - dS/dτ = (A/S)·κ·[S_act·(1+eemax)/2 + R_act·(1−eemax)/2] + (A/S)·k₀/2
  - R_act = R − q·min(R,S)，S_act = S − q·min(R,S)；dA/dτ = −(生产速率)
  - ee 放大条件：q > 1 − eemax；ee 平台 ≈ 1 − (1−eemax)/q
- 参数（全部为示意值，未对真实实验拟合）：SCALE=1e5（标准投料池）、κ=0.5、k₀=0.001、dt=5×10⁻⁴、每批 24000 步；数值积分前体耗尽判据 A ≤ 1e-6·S（指数衰减不会精确归零）。
- 预设情景与页面实测输出（JavaScript 与 Python 校准脚本结果一致）：

| 预设 | 参数 | 实测各批 ee | 呼应的官方事实（仅定性） |
|---|---|---|---|
| Soai 1995 型：5% 起步 | q=0.50, eemax=0.95, A₀=80 | 52.9% → 84.0% → 89.2% | Nature 1995：5%→55%→87%→90% 平台 |
| 近乎无中生有：0.00005% | q=0.95, eemax=0.998, A₀=30 | 91.9% → 99.5% → 99.8% | Angew 2003：三轮 >99.5%，63 万倍 |
| 对照·完美复印机 | q=0, eemax=1.0 | 0.1% → 0.1% → 0.1% | 无拮抗时 ee 保持不变 |
| 对照·复印走样 | q=0, eemax=0.5, A₀=5 | 34.8% → 14.2% | Soai 1990：催化剂 86% → 产物 35%（ee 侵蚀） |
| 随机对称破缺 | ee₀=0, σ=0.2 | 获胜者随机（20 种子 R:D=11:9），末批 ~94% | 绝对不对称合成：18R/19S |

- 校准脚本：`calibrate.py`（Python 复算脚本，供复核模型行为；页面内 JavaScript 为其一致实现）。
- 页面实测（ZCode 内置浏览器，1280×900）：三个标签页渲染正常；三批接力、随机重掷、连点压力测试均通过，无控制台报错。

## 五、核查方法说明

- 所有年份、人名、数字先在 S3（科学背景 PDF，最权威）中定位原文，再与 S1/S2 交叉核对；S1/S2 与 S3 口径不一致时以 S3 为准并记录差异（见第三节）。
- 药物表述逐条核对官方口径，官方材料之外的科学习惯说法（如沙利度胺体内消旋化）单独标注补充来源（S5/S6）。
- 演示输出的数字一律标注"教学模型/示意"，与真实实验数字明确区隔。
